# 常见骗局特征库（基线参考）

用于「分析流程第 1 步」逐条匹配。非穷举；新型变种随时出现，命中特征越多风险越高。每条含：**话术 / 红旗（识别特征）/ 损害途径 / 匹配关键词**。

---

### 1. 刷单返利 / 兼职刷单
- **话术**：「足不出户日赚XXX」「垫付后连本带利返还」「前几单小额返现诱导加大投入」。
- **红旗**：先垫钱、任务群、陌生 APP 派单、以「联单 / 保证金 / 解冻」为由拒绝返款。
- **损害途径**：诱导连续转账后拉黑；APP 内余额无法提现。
- **关键词**：刷单、返利、兼职、垫付、刷销量、佣金。

### 2. 杀猪盘 / 婚恋投资
- **话术**：社交 / 婚恋平台建立感情后推荐「内部平台 / 稳赚理财 / 虚拟币」。
- **红旗**：不愿线下见面、只谈赚钱、引导到非正规投资网站、初期可小额提现诱你加仓。
- **损害途径**：充值后平台关闭 / 无法提现；情感 + 资金双重收割。
- **关键词**：杀猪盘、网恋、内部平台、带单、导师、稳赚。

### 3. 冒充公检法
- **话术**：「你涉嫌洗钱 / 通缉令 / 保密账户 / 资金清查」，要求下载会议 APP 屏幕共享、转账自证清白。
- **红旗**：自称公安却用社交软件联系、怕你挂断报警、要求「保密」不告诉家人、远程操控手机。
- **损害途径**：屏幕共享盗取验证码 → 直接转走存款；诱导贷款后转账。
- **关键词**：公检法、通缉令、安全账户、资金清查、保密。

### 4. 冒充客服 / 理赔退款
- **话术**：「订单异常 / 误开会员 / 快递丢失双倍赔」，引导关闭「自动扣费」或理赔。
- **红旗**：主动来电并报出部分订单信息博信任、要求屏幕共享、发陌生理赔链接、要求「验证资金」。
- **损害途径**：屏幕共享盗刷、诱导贷款转账、钓鱼链接窃取账号。
- **关键词**：客服、退款、理赔、误开通、百万保障、自动扣费。

### 5. 贷款 / 解冻 / 注销校园贷
- **话术**：「低息秒批」「额度已批需交保证金 / 解冻费」「不注销影响征信」。
- **红旗**：放款前先收费、以「流水不足 / 银行卡冻结」要你转账、引导贷款平台借钱转出。
- **损害途径**：收手续费后失联；诱导网贷后骗走贷款资金。
- **关键词**：贷款、解冻、保证金、注销、征信、刷流水。

### 6. 裸聊敲诈
- **话术**：社交引流 → 诱导下载恶意 APP 或视频裸聊 → 窃取通讯录 → 以群发不雅视频勒索。
- **红旗**：陌生好友主动暧昧、要求下载特定 APP、视频中诱导露脸露隐私。
- **损害途径**：敲诈勒索反复要钱；隐私威胁。
- **关键词**：裸聊、约炮、交友、通讯录、封口费。

### 7. 中奖 / 免费送 / 领红包
- **话术**：「恭喜中奖 / 免费领福利 / 助力砍价」，需先交「税费 / 运费 / 保证金」或填个人信息。
- **红旗**：天上掉馅饼、先交钱才能领、链接收集身份与银行卡信息。
- **损害途径**：骗取小额费用、盗用个人信息与卡号。
- **关键词**：中奖、免费送、红包、助力、税费、运费。

### 8. 虚假投资理财 / 虚拟币
- **话术**：「稳赚不赔 / 内幕消息 / 荐股群」，引导到自建平台或买币。
- **红旗**：承诺保本高收益、群内托儿晒盈利、平台非持牌机构、提现受阻要再缴费。
- **损害途径**：充值后平台跑路；虚拟币转移难追。
- **关键词**：荐股、内幕、虚拟币、量化、稳赚、配资。

### 9. 养老 / 保健品诈骗
- **话术**：「免费体检 / 高息养老项目 / 神医特效药」，针对老年人。
- **红旗**：情感陪伴降低戒备、夸大疗效、高息返利、要求大额预付。
- **损害途径**：高价无效产品、养老钱被骗。
- **关键词**：养老、保健品、免费体检、高息养老、神医。

### 10. AI 换脸 / 声音克隆冒充熟人
- **话术**：用 AI 合成领导 / 亲友声音或视频借钱、紧急转账。
- **红旗**：视频 / 语音「像但别扭」、理由紧急且要求避开核实、只走转账。
- **损害途径**：冒充身份骗取转账。
- **关键词**：领导借钱、熟人视频、声音像、紧急转账。

### 11. 游戏装备 / 账号交易
- **话术**：「低价出售 / 高价回收 / 私下交易更便宜」，引导脱离平台。
- **红旗**：要求先付款或先交「担保费」、发虚假交易链接、脱离官方平台。
- **损害途径**：付款后被拉黑、账号被盗。
- **关键词**：游戏装备、账号交易、低价充值、担保。

### 12. 虚假征信 / 网贷注销
- **话术**：「你的网贷记录影响征信，需注销 / 清零」，引导转账「清空额度」。
- **红旗**：主动来电、怕你核实官方、要求屏幕共享或贷款后转出。
- **损害途径**：诱导网贷资金被骗。
- **关键词**：征信、网贷、注销、额度清空。

---

> 使用方式：把用户描述中的「接触渠道 + 话术 + 要求动作」与上述任一条比对，命中 2 项以上即应判定「疑似 / 高危」。无法归类时进入 SKILL.md 第 2 步检索，或第 3 步推演。
