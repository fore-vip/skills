# 求助与举报渠道（官方 / 权威）

用于「分析流程第 5 步」。按紧急程度排序，均引用国家公开权威渠道；各地具体派出机构电话以 110 / 96110 或当地政府官网最新公布为准，不在此编造本地号码。

---

## 一、紧急求助（涉已转账 / 正被诱导转账 / 人身安全）

| 渠道 | 用途 | 说明 |
|------|------|------|
| **96110** | 全国反诈专线 | 公安部反诈骗预警劝阻电话，被呼叫请务必接听；也可主动拨打咨询举报 |
| **110** | 报警 | 已转账、正被诱导转账、人身安全受威胁时立即拨打 |
| **12381** | 涉诈预警短信 | 工信部涉诈预警劝阻短信系统，收到即提示正面临诈骗风险 |

> 黄金止损：发现转账后**立即联系涉事银行 / 支付机构客服申请紧急止付**（挂失 + 冻结收款方），并尽快到就近派出所报案领取《受案回执》，便于后续追赃。

## 二、举报渠道

| 渠道 | 适用 | 入口 |
|------|------|------|
| **国家反诈中心 APP** | 举报线索、风险自查、来电预警 | 应用商店搜索「国家反诈中心」，官方预警与举报主入口 |
| **微信举报** | 涉微信的诈骗账号 / 群 / 文章 | 聊天界面 → 右上角「…」→ 投诉 → 选择欺诈类型 |
| **支付宝举报** | 涉支付宝的诈骗交易 | 账单详情 → 投诉 → 举报欺诈 |
| **12377** | 网络违法和不良信息举报（中央网信办） | 官网 www.12377.cn / 网络举报 APP |
| **12315** | 消费纠纷 / 虚假宣传（市场监管 / 消协） | 12315 平台网站 / APP / 微信小程序 |
| **12363** | 金融消费权益（银行 / 支付机构纠纷） | 人民银行金融消费权益保护热线 |
| 黑猫投诉等平台 | 民事维权参考（非官方，不替代报警） | 仅作线索收集，警惕「代维权」二次诈骗 |

## 三、属地化求助

- **辖区派出所 / 反诈中心**：拨打 110 或 12345 市民热线转接，获取最近受理点。
- **银行 / 支付机构官方客服**：通过卡片背面、官方 APP、官网公布的号码联系（不点陌生人发的链接 / 不接「客服」回拨的陌生号码）。

## 四、使用原则

- **先电话、后文字**：任何涉及资金已转出或正被诱导，优先 96110 / 110，再补文字材料。
- **只信官方入口**：举报 / 止付一律走上表官方渠道，不轻信搜索广告里的「追回公司」「黑客找回」。
- **保留证据**：截图聊天、转账记录、对方账号、链接，便于警方与平台处置。
