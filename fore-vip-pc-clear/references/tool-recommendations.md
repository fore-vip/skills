# 工具替代推荐库（按工作性质）

环境优化阶段的推荐依据。**原则：只推荐有明确优势的替代；迁移成本 > 收益时不推荐；优先免费/开源；不推荐破解与来路不明软件。** 表格是基线推荐，最终推荐前用 WebSearch 核实工具现状（是否停更、是否有丑闻/安全问题），核实不到的标注「信息未核实」。

## 判定框架

对每个「当前工具 → 候选替代」按四维打分（优/平/劣）：

1. **效率**：启动速度、资源占用、操作步数
2. **安全**：开源程度、数据隐私、更新频率
3. **迁移成本**：数据导出、习惯改变、学习曲线
4. **生态**：跨平台、社区活跃、长期维护

三维及以上「优」且无「劣」才推荐；其余只在用户主动问时提及。

## 开发者

| 场景 | 常见现状 | 推荐替代 | 理由 |
|------|---------|---------|------|
| 压缩/解压 | 系统自带 / 收费软件 | 7-Zip（Win）、Keka（macOS） | 免费、格式全、无广告 |
| 终端 | 系统自带 Terminal/cmd | Windows Terminal + PowerShell 7 / iTerm2 + Oh My Zsh | 分屏、主题、现代 shell |
| Git GUI | 无 / 重量级 IDE | VS Code 内置 Git / Fork / lazygit | 轻量、够用 |
| API 调试 | Postman 桌面版 | Bruno / Hoppscotch | 离线、轻量、开源 |
| 截图标注 | 微信截图 | Snipaste（Win）/ CleanShot X（mac）/ Flameshot（Linux） | 贴图、长截图、延迟截 |
| Markdown | 各类在线编辑 | Typora / VS Code | 本地文件、所见即所得 |
| 包管理 | 手动下载安装 | Win: winget/scoop；mac: Homebrew；Linux: 系统包管理器 | 一键装/升级/卸载 |

## 按工作性质匹配

- **开发者**：优先推终端增强、包管理、API 工具、Docker 管理器
- **设计师/创作者**：优先推录屏、截图标注、图片处理、字体管理
- **办公/文档为主**：优先推文件搜索、PDF、卸载工具、云同步
- **游戏/高性能需求**：不推「优化大师」类全家桶（多为负优化+广告），只建议驱动更新走官方渠道

## 反推荐清单（主动提示用户卸载/替代）

| 类型 | 问题 |
|------|------|
| 各种「优化大师/清理大师」全家桶 | 负优化、弹窗广告、后台常驻 |
| 捆绑安装的浏览器/输入法 | 后台进程多、隐私风险 |
| 停更多年的老工具 | 安全漏洞无人修 |
| 来路不明的「破解版」软件 | 木马重灾区 |

## 最佳状态配置引导（推荐后必做）

1. 给出关键设置清单（如 OBS 的录制参数、Everything 的开机自启+索引、终端的主题与字体）
2. 能命令行完成的配置按风险分级执行（改配置文件 A/B 级；改默认 shell、系统代理 C 级征询）
3. 迁移引导：旧工具数据导出路径 → 新工具导入方式 → 验证一步
4. 卸载旧工具走系统正规卸载（禁用第三方强卸），卸载后用 B 级清理残留
