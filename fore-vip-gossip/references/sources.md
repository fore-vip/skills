# 信源分级与验证细则

吃瓜求证的分级标准与多平台检索策略。供 SKILL.md 主流程第 2、3 步引用。

## 一、信源分级表

| 级别 | 信源类型 | 示例 | 可支撑的标注 |
|------|----------|------|--------------|
| S 级 | 当事人/工作室官方渠道 | 官宣微博、声明函、直播间本人回应 | ✅ 已证实 |
| A 级 | 权威媒体实名报道 | 新浪娱乐、澎湃新闻、界面、央视/官方通稿 | ✅ 已证实（注明媒体） |
| B 级 | 多个独立平台一致讨论 | 微博话题 + 知乎 + 豆瓣小组同时发酵且细节一致 | ⚠️ 待核实（多源一致） |
| C 级 | 单一平台热议 / 解读向内容 | 单个营销号、B 站/小红书解读视频、豆瓣单帖 | ❓ 纯传闻 |
| D 级 | 匿名爆料 / 无出处截图 | 「我朋友是工作人员」「知情人透露」 | ❓ 纯传闻（标注查无出处） |

**判定规则**：
- B 级要升 ⚠️，需 ≥2 个**相互独立**的平台源（营销号互搬不算多源，看首发）。
- ⚠️ 升 ✅ 只有两条路：S 级回应，或 ≥2 家 A 级媒体独立报道。
- 任何级别若出现当事人否认且无新证据，降回 ❓ 并注明争议状态。

## 二、多平台检索策略

| 平台 | 检索价值 | 检索方式 |
|------|----------|----------|
| 微博 | 热度与官方回应第一现场 | 搜「人名 + 事件词」、看热搜词条、工作室账号 |
| 知乎 | 长文分析与时间线梳理 | 搜「人名/事件 + 怎么看/时间线」 |
| 豆瓣小组 | 前排吃瓜细节与争议点 | 搜小组讨论（注意多为 C/D 级信源） |
| 小红书 | 路透、现场目击与情绪向内容 | 搜人名 + 事件关键词 |
| 权威媒体 | 定锤与事实核查 | 搜人名/事件 + 新闻媒体来源限定 |
| 搜索引擎 | 兜底聚合 | 「人名 + 事件 + 回应/声明/辟谣」 |

**操作要点**：
1. 先搜「辟谣/声明/回应」再搜爆料——避免拿到已被辟谣的旧瓜当新瓜。
2. 核对时间线：营销号常见「旧瓜新炒」，比对信息最早发布时间。
3. 采集时逐条记录 `来源·时间·原始表述`，输出时只在表格里保留关键依据。

## 三、待核实标注规范

统一话术，避免暗示性定论：
- ⚠️ 待核实 → 「多源一致但无实锤，等官方回应」
- ❓ 纯传闻 → 「仅 [来源] 提及，查无实据，谨慎吃瓜」
- 查无内容 → 「暂无可靠消息，目前流传的多为无出处截图」

禁止话术：「基本可以确定」「懂的都懂」「大概率是真的」——这类表述模糊了真实性分级。
