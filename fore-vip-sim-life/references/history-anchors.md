# 时代锚点表

用途：让人物的年份「有背景」。**只查表，不臆造年份。**
一个人一生只让 3–6 个时代事件真正落在他身上，其余当背景音。

## 一、全球技术与生活变迁

| 年代 | 普及开来的东西 |
|---|---|
| 1950s | 收音机、电影下乡；发达国家电视进入家庭 |
| 1960s | 自行车、缝纫机、手表；欧美汽车普及、郊区化 |
| 1970s | 彩色电视、洗衣机、冰箱；石油危机改变能源习惯 |
| 1980s | 个人电脑、录像带、随身听；乡镇企业/制造业转移 |
| 1990s | 寻呼机、手机、网吧、互联网；集装箱贸易扩张 |
| 2000s | 宽带、数码相机、MP3、iPhone（2007）；全球供应链 |
| 2010s | 移动支付、社交媒体、网约车、外卖、共享单车；高铁与廉价航空 |
| 2020s | 短视频、远程办公、大模型应用；气候与能源转型 |

## 三、使用规则

1. **匹配人物位置**：农村、城市、阶层、受教育程度决定他「感受得到」哪些事件。
2. **不评价历史**，只写它落在具体人身上的一个后果（丢了工作、涨了房租、多了份工）。
3. **一个事件最多跨两轮**用完，不要年年提同一件事。
4. 表中没有的年份，就当作「无事之年」处理，不硬凑。
5. 人物若在此表覆盖范围外（小国、特殊地区），按所属大区的共同背景处理，并在叙事中避免具体政策细节。
