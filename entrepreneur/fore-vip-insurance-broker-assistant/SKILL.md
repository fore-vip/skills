# 保险经纪人/代理人一线展业工具

## 适用角色与场景

| 角色 | 典型场景 | 用本 SKILL 解什么问题 |
|---|---|---|
| 持证新人（刚完成执业登记） | 拿到工号不知卖哪款、怎么开口 | 用模块一选拳头产品组合、模块二选首单客群 |
| 成熟独立经纪人/团队长 | 一个客户多种需求、需批量出方案 | 用模块一+模块二出险种组合与报价速算 |
| 跨界从业者（HR/银行/医务/财税） | 想转行做保险副业，不知门槛与可行性 | 用模块三看持证路径与启动资金，用模块二选切入细分赛道 |
| 县域/社区团长/财务代理 | 想增售惠民保等政府背书产品 | 用模块三合规自检表确认能不能卖，模块四落地冷启动 |
| SMB 厂商/IT 服务商 | 想为客户增送网安险做增值服务 | 用模块二做 SMB 网安险补贴+体检+投保联动 |

## 模块一：客群诊断与险种组合设计器

按客户年龄/角色/已有保障，给出险种推荐顺序、保额建议与报价速算。

### 1.1 客户诊断 4 问（必问）

1. 年龄 + 角色（员工/家庭主妇/小微企业主/退休/带病体）
2. 已有保障（社保/团险/已购商业险/惠民保）
3. 主要担忧（医疗费/收入中断/资产传承/税务/合规处罚）
4. 月缴预算上限

### 1.2 险种推荐决策表

| 客户画像 | 推荐险种组合 | 保额/缴费建议 | 入门报价带（年缴） |
|---|---|---|---|
| 30 岁白领双职工家庭 | 百万医疗险 + 重疾险 + 定期寿险 + 个人养老金 12000 元满额 | 重疾保额 ≥ 3 倍年收入、医疗 200-400 万、定寿 10-20 倍年收入 | 8,000-25,000 元 |
| 40-60 岁中老年（已有社保） | 惠民保（当地）+ 防癌医疗险 + 意外险 + 养老年金 | 惠民保必投；防癌 100-200 万；意外 20-50 万 | 800-3,500 元 |
| 带病体/三高/已确诊慢性病 | 惠民保（无门槛）+ 慢病专属医疗险 + 特定药品险 | 惠民保必投；慢病险选既往症可保版本 | 600-2,500 元 |
| 小微企业主（数字化 + 缺 IT 安全团队） | 网安险（勒索重灾） + 雇主责任险 + 关键人定寿 + 团体医疗 | 网安险优先；雇主责任覆盖全员 | 网安险 1-8 万/家；雇主责任 800-2,000 元/人/年 |
| 高净值客户 | 终身寿险 + 增额终身寿 + 高端医疗 + 信托对接 + 个人养老金 | 终身寿年缴 ≥ 20 万起；高端医疗 600 万+ | 20 万-100 万+ |
| 三线/县城家庭 | 惠民保（必投）+ 学平险 + 百万医疗（65 岁内） + 意外 | 惠民保 49-200 元/人、学平险 100-300 元/年 | 600-3,000 元 |

### 1.3 报价速算公式

- **个人养老税金优惠**：年缴满 12,000 元，领取按 3% 单独计税；测算公式 `税收节省 = 边际税率 × 12,000`（如 10% 税率省 1,200 元/年；20% 税率省 2,400 元/年；25% 以上税率省 ≥ 3,000 元/年）
- **百万医疗险**：30 岁约 300-500 元/年；50 岁约 1,200-1,800 元/年；65 岁以上 3,000 元+ → 推惠民保补位
- **惠民保**：49-200 元/人/年，同一城市一年一投；政府补贴版（首年免费试用）务必盯紧缴纳期
- **网安险 SMB 版**：基础版年缴 1-3 万（含营业中断+数据恢复+勒索+网络责任四大场景）；制造业/医疗/教育建议高保额（500-2000 万）
- **防癌医疗险**：50-100 万保额，60 岁约 800-1,500 元/年；不限健康告知版本稍贵

## 模块二：政策红利捕获与方案包装

合规地帮客户领补贴、算税优、把"产品"转成"客户赚到的钱"。

### 2.1 五大政策红利窗口（按紧迫度排序）

| 红利窗口 | 时效与额度 | 协助动作 | 适用人群 |
|---|---|---|---|
| 个人养老金税优 | 每年 12,000 元缴存上限，缴费期 12 月底前；领取期 3% 低税率 | 用 Excel 测算「边际税率 × 12000」告知客户节省税额；协助在国家社会保险公共服务平台开户 | 10% 以上税率的工薪族 |
| 网安险试点补贴 | 济南（最高 70-90%）、陕西（13 省首年最高 80%）、苏州（5 市 6 区首批 100% 试用）、上海普陀（180 天免费 + 50% 补贴） | 锁定客户注册地，申领补贴代办作为吸引点 | 试点地区专精特新/科技型/规上工业企业 |
| 惠民保投保期 | 城市集中投保期（多为每年 11 月-次年 2 月），错过需等一年 | 提前 1 个月做社群预热；为带病体/老人专设咨询通道 | 当地基本医保参保人 |
| 慢病管理服务包 | 2025 年起多地惠民保+ 慢病管理升级 | 协助客户激活健康管理服务（线上问诊/药品折扣） | 投保惠民保的慢性病人群 |
| 雇主责任险团购 | 各保险公司团险开放季（多为 Q3-Q4） | 联合 IT/财税/产业园代办渠道打包 | 小微企业主 |

### 2.2 方案包装话术模板

**个养税优版**：「按你 20% 边际税率，每年缴 12,000 元可省 2,400 元税，30 年省 7.2 万，加投资收益累计。」
**网安险补贴版**：「你是专精特新企业，享陕西首年最高 80% 补贴，原 3 万年缴政府承担 2.4 万，实际你只付 6,000。」
**惠民保代办版**：「当地 65 岁以上老人，惠民保 99 元/年保 300 万，不限健康告知——你父母都能投。」

### 2.3 政策红利速查表（必查时效）

每月 1 号跑一遍：① 个养政策全国平台有无新额度调整；② 试点城市网安险补贴是否新增/到期；③ 本地惠民保是否进入投保期；④ 当地银保监有无新型险种备案更新。

## 模块三：持牌路径与合规自检表

守住"机构持牌、人员持证、产品备案"三道铁律，避免白鸽宝式违规。

### 3.1 持证路径速查

| 路径 | 适用 | 资金门槛 | 时间 | 备注 |
|---|---|---|---|---|
| 保险代理人（工号制） | 卖单家险企产品 | 0 元 | 2-4 周培训+考试+签约 | 佣金比例较低，需绑定 1 家险企 |
| 独立个人保险代理人 | 卖多家险企产品 | 0 元 | 4-8 周双产品线考试 | 佣金可达传统 2 倍（toubaow 数据） |
| 保险经纪公司签约（明亚/大童/梧桐树/i云保） | 卖多公司多险种 | 0 元（无注资） | 2-4 周 | 最推荐：产品线宽+合规支撑 |
| 银行代理渠道 | 卖银保产品 | 0 元 | 机构分配工号 | 个养险/储蓄险主战场 |
| 互联网平台（蚂蚁保/微保） | 卖线上产品 | 0 元 | 平台入驻审核 | 流量大但佣金低，限 C 端 |
| 自设保险经纪公司 | 想当法人 | 实收资本 50 万+ | 3-6 个月审批 | 普通人不要碰 |

### 3.2 合规一票否决清单（任何一项触线即出局）

- ❌ 无执业登记擅自推广、销售保单
- ❌ "零门槛推广""扫码入群即享分红"等承诺收益话术（白鸽宝类已被监管查处）
- ❌ 隐瞒免责条款、夸大保险责任
- ❌ 代客操作个人养老金账户
- ❌ 跨地区跨机构展业而无对应资质
- ❌ 利用惠民保做"搭售""自动续保"
- ❌ 客户为带病体/老人时不做双录（保险销售可回溯）

### 3.3 合规自检 6 问（每次展业前过一遍）

1. 我有有效执业证/工号吗？
2. 这款产品备案渠道我所在机构有销售资质吗？
3. 我是否对客户做了风险适配评估（KYC）？
4. 是否需要双录/电子投保确认？
5. 我是否向客户如实说明免责条款？
6. 收付款走的是机构对公账户吗？

### 3.4 跨界从业者补强路径

- **银行/HR**：已有客户信任背书，但需补保险基础+个税计算（3 个月内拿基金从业资格拓品类）
- **医务/药师**：健康科普能力强，但需补保险条款/核保逻辑（建议挂靠经纪公司跟单半年）
- **财税/法务**：客户付费能力强，但需补产品对比话术（推荐从惠民保+个养税优切入，快上手）
- **IT/网安**：SMB 网安险黄金资源，建议补保险中介资质，避免被保险同行截胡

## 模块四：90 天冷启动 SOP（个人经纪人实战版）

### 第 1-2 周：持证 + 选机构

- 选定 1 家经纪公司或代理人渠道，完成执业登记、产品培训、考试
- 选定「拳品组合」：参考模块一选 1-2 款主推产品（如个养+惠民保双开、或网安险 SMB 单点）
- 备齐客户告知书、产品对比表、合规话术 SOP（找所在机构索要）

### 第 3-4 周：建场域 + 测水温

- 私域：朋友圈/微信群发 5-8 条合规科普（个养税优/惠民保投保期/网安险补贴）
- 公域：开 1 个号（小红书/视频号/抖音），日更 1 条养老/保险科普
- 首单客群：从「强关系」切入（同事、亲友、邻居），用免费"税优测算""保单整理"换信任

### 第 5-8 周：跑通首单 + 沉淀素材

- 目标：完成 1-3 单投保（个人养老/百万医疗/惠民保任一）
- 关键动作：每月固定 1 次主题直播（个养/惠民保/网安险轮流）+ 1 场线下社区咨询
- 沉淀：标准化 FAQ、保险方案模板、客户案例（脱敏）3-5 份

### 第 9-12 周：复用 + 扩渠道

- 已成交客户启动续保提醒（惠民保次年 11 月、个养续缴 12 月）
- 转介绍：给老客户设计转介绍小礼盒或服务包（不要直接返佣，违合规）
- 异业合作：财税/医疗/HR/IT 渠道 BD，签转介绍协议（合规口径）

### 启动资金清单

| 项目 | 金额 | 性质 |
|---|---|---|
| 持证培训/考试 | 0 元 | 机构承担 |
| 自媒体获客（投流/工具） | 500-2,000 元/月 | 可变成本 |
| 客户宣传物料 | 200-500 元/月 | 可变成本 |
| CRM/办公 | 0-500 元/月 | 飞书/企业微信免费版起步 |
| 社群/讲座场地 | 0-1,000 元/场 | 借社区/产业园场地 |
| **总计** | **≈ 0.1-2 万** | 副业级远低于自设经纪公司 50 万 |

## 风险与红线速查

| 风险类型 | 红线 | 后果 |
|---|---|---|
| 合规 | 无资质展业、夸大收益、白鸽宝模式 | 吊销执照 + 行业禁入 + 罚款（已查处案例：白鸽宝 2025 年） |
| 现金流 | 佣金回款 T+1 至数月，前期靠本职兜底 | 误判现金流导致资金断裂 |
| 政策依赖 | 个养税优、网安险补贴、惠民保资质变动 | 红利率下降需快速调整方案 |
| 同质化竞争 | 惠民保/百万医疗同质化、价格战 | 必须做健康服务+专业背书差异化 |
| B 端获客 | 网安险 SMB 决策链长，3-6 个月 | 优先盘活既有企业人脉，不要纯内容冷启动 |
| 客户教育 | 中老年/带病体客户理解成本高 | 备可视化材料（视频/对比表），家属共决 |

## 信息源（每月跑一遍）

- 国家金融监督管理总局官网（kaixin.jrj.com.cn / circ.gov.cn）：险种备案、政策发文
- 国家社会保险公共服务平台：个人养老金产品名录、税优试算
- 中保协/保险学会：行业报告、产品对比
- IMA.前凌智库「保险」目录：最新市场分析与可行性计划
- 本地医保局/工信局：惠民保投保期、网安险补贴试点名单
