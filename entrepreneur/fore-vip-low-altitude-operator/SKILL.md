## 模块 1 — 赛道切入选型决策器

普通人能切入的 4 条路径，按"资金门槛+季节性+合规风险+回本速度"四维交叉打分。所有路径均不碰飞行安全主体责任（不自营执飞优先）。

| 路径 | 资金门槛 | 季节性 | 回本周 | 合规风险 | 核心业务 |
|---|---|---|---|---|---|
| A. 无人机植保/吊运（飞手执飞）| 5–20万 | 农业淡旺季，需组合 | 6–12月 | 需自持CAAC证 | 打药+吊运+巡检 |
| B. 物流配送区域落地合伙人（纯地面服务）| 3–10万 | 全年平稳 | 8–14月 | 不直接承担飞行责任 | 选址+商户BD+接驳 |
| C. 低空文旅策展/居间（消费侧）| 3–10万 | 节假日高峰 | 3–8月 | 供应商适航核验即可 | 供应商BD+产品分销 |
| D. 飞手培训招生代理 | 0.5–3万 | 全年 | 1–3月 | 需合作机构授权 | 招生返佣 |

**决策树**：
- 有本地农业/光伏/矿山客户资源 → A
- 有商户/园区/政府资源但无飞手证 → B
- 有短视频/景区/婚庆流量 → C
- 有教培渠道资源 → D
- 同时有本地BD + 平台资源 → B→C 联合（落地服务+文旅产品组合）

## 模块 2 — 资质合规与考证路径

### 证书对比（必读表）

| 证书 | 用途 | 报考费 | 周期 | 学历 | 备注 |
|---|---|---|---|---|---|
| CAAC超视距机长证 | 合法飞行的敲门砖，接政府/企业项目必备 | 8000–15000元 | 1–2月 | 初中+ | A路径必考 |
| AOPA驾驶员证 | 与CAAC同等效力 | 8000–15000元 | 1–2月 | 初中+ | A路径备选 |
| CAAC教员证 | 自办培训班必备 | 15000–20000元 | 1月 | 需先持CAAC机长 | D路径升阶 |

### 合规红线一票否决（任何路径都必查）

1. 无证飞行 → 罚款 +《治安管理处罚法》"黑飞"入刑风险
2. 实名登记未做 → 国标强制（2025-05-01 起）
3. 空域未报备 → 强制审批；隔离空域优先于融合空域
4. 不持有→操作他人飞机出事负主体责任
5. 飞行安全责任不签明 → 协议必须落到合同条款

### 居间/B 路径（不自营执飞）的合规配置

- 不持证、不购机、不做运营主体
- 合作方必须持《民用无人驾驶航空器运营合格证》
- 落地服务方须签三方协议：运营方×起降场×落地服务商
- 购买第三方责任险覆盖地面端（设备端由运营方自购）

## 模块 3 — 设备选型与启动预算测算器

### 设备 × 场景匹配表

| 机型 | 适配场景 | 新机价 | 二手/租赁 | 单机日作业量 |
|---|---|---|---|---|
| DJI T40/T50 农业植保 | 农业喷洒（大田）| 5–6万 | 二手3–4万 | 200–500亩 |
| DJI Mavic 3T | 巡检/测绘/应急 | 2–3万 | 1.5–2万 | 50–100公里 |
| DJI Inspire 3 | 高端航拍/文旅 | 5–8万 | 3–5万 | 接单计费 |
| 吊运型无人机（方舟/峰飞）| 光伏/矿山物资 | 3–8万 | 租赁押金 | 2000–3000元/日营收 |
| 千架级表演机（自营不推荐）| 表演 | 千架500万+ | 强烈建议外包 | — |

### 启动方案三选一（降低资金压力）

| 方案 | 适合人群 | 实际占用资金 |
|---|---|---|
| 1. 租赁/挂靠（推荐起步）| 城市合伙人、首单验证 | 押金+分成，几乎不出设备钱 |
| 2. 二手设备+加盟合作社 | 农业本地、退役军人 | 5–8万 |
| 3. 全套新机+教具 | 教培招生、有渠道方 | 15–25万 |

### 启动预算速算（B 路径落地合伙人为例）

```
启动总预算 = 场地协调押金(2–4万) + 轻办公+出行(1–2万) + 物料+账号搭建(1–2万) + 首期人力(兼职1–2万) = 3–10万
回本触发 = 单城 2–5 起降点 × 月服务 2000–5000 单 → 单点盈亏平衡
```

## 模块 4 — 本地BD与定价/分润执行清单

### 路径 A：无人机植保/吊运

| 客户类型 | 计费方式 | 单价 | 拓客动作 |
|---|---|---|---|
| 农业种植（大田）| 按亩 | 10–30元/亩 | 农资店挂单+合作社合作 |
| 光伏电站物资 | 按趟/重量 | 3000–8000元/趟 | 项目部长期框架 |
| 矿山/基建 | 按项目 | 包月 1.5–3万 | 应急名录入库 |
| 应急救援 | 政府订单 | 单次 5000–2万 | 提前入库应急管理局 |

**冷启动**: 首单免费/低价换口碑 + 抖音/视频号发作业片段 + 农资店/合作社共享客户

### 路径 B：物流配送落地合伙人

签约 → 跑通 1 条示范航线 → 复制

| 步骤 | 关键动作 | 达标指标 |
|---|---|---|
| 1. 选点（试点城市优先）| 优先深圳/上海/合肥/十堰类已开航城 | 谈下 2–3 候选起降点 |
| 2. 结盟平台 | 申请美团无人机"授权服务商"或丰翼/迅蚁区域代理 | 框架协议 |
| 3. 跑通单航线 | 配合地推 5–10 商户 + 培训地面接驳员 | 100–300 单样本 |
| 4. 报价三档 | 场地协调费 / 商户拓展佣金 / 地面运维包月 | 验证毛利 |
| 5. 复制 | 横扩商户、纵扩相邻区县 | 沉淀 SOP |

**收入构成**: 场地协调费 + 商户拓展佣金 + 地面运维包月（单城月服务 2000–5000 单时接近盈亏平衡）

### 路径 C：低空文旅策展/居间

**供应商白名单核验 SOP**: 持《通用航空经营许可证》→ 适航证 → 空域批复 → 足额险（机身/第三方/意外）→ 公安空域报备（无人机表演）

| 产品 | 单价/抽成 | 锁客方式 |
|---|---|---|
| 空中观光客单价（直升机/eVTOL/滑翔）| 500–2000元/人 | 短视频出片 + 私域复购 |
| 单场无人机秀居间抽成 | 单场 5–15万级，分10–20% | 景区年度框架 |
| 婚庆航拍跟拍 | 按场报价 | 小红书/抖音同城号 |
| 研学课程 | 人均 300–800 元 | 教委/营地分销 |

### 路径 D：飞手培训招生

- 与 CAAC/AOPA 认证机构签约，做招生代理；每推荐一人成功报名 → 返佣 1000–3000 元
- 进阶路径：先做招生 → 攒学员池 → 考教员证 → 自办培训班

## 风险与红线速查

| 风险类型 | 红线 | 必查动作 |
|---|---|---|
| 飞行安全主体责任 | 不持机执飞出事将负主体责任 | 合作方持 OC 证 + 协议明确责任 |
| 政策变动/补贴退坡 | 服务费收入为主，不依赖补贴 | 跟踪发改委低空司 + 十部门《标准体系建设指南》 |
| 平台直营挤压 | 平台不愿做的"地面苦活"才是你的位置 | 不碰执飞，做选址/地推/接驳 |
| 商户教育成本 | 单量不及预期 | MVP 先验证 1 航线/单品类再扩张 |
| 安全事件连带 | 即使居间也需保险 | 必买第三方责任险（地面端） |
| 现金流依赖大客户 | 政府/品牌单回款慢 | C 端散客做基本盘 + 大单做增量 |

## 政策窗口速查（2026 年）

- 2024 低空经济首次入政府工作报告；2026 升格"新兴支柱产业"
- 发改委低空经济发展司 2026-04 统筹空域开放与标准
- 《无人驾驶航空器飞行管理暂行条例》全面实施；"黑飞"入《治安管理处罚法》
- 新《民用航空法》2026-07-01 增设"发展促进"专章
- 美团 + 丰翼累计约 1470 条航线常态化；2025 物流单量破 1.2 亿件
- 京东物流 2026-03 启动全国低空网络，首期 50 亿

执行优先级：第一周锁定路径 → 第二个月考 CAAC 证或签平台协议 → 第三个月跑通首单样板 → 第六个月评估回本。
