# 合成脚本配置格式（compose_comic.py）

脚本读取一个 JSON，完成：裁底去水印 → 网格拼版 → 画手绘外框 → 画气泡与尾巴 → 排中文字 → 缩放输出。

运行：

```bash
python scripts/compose_comic.py <spec.json>
```

脚本内置**两道硬校验**，不通过会直接报错并给出修正建议（而不是产出一张废图）：

1. 文字块是否装得进气泡（按形状算可用高度）
2. 气泡尾巴的两个基点是否落在气泡主体内部

## 顶层字段

| 字段 | 默认 | 说明 |
|---|---|---|
| `output` | 必填 | 输出 PNG 绝对路径 |
| `panels` | 必填 | 单格数组，顺序即排版顺序（按行填充） |
| `title` | `""` | 主标题 |
| `title_accent` | `""` | `title` 中要染成强调色的片段（用于点名关键词） |
| `subtitle` | `""` | 副标题 |
| `cols` | 等于格数 | 每行格数。四格用 2，六格用 3 或 2 |
| `crop_bottom` | `100` | 裁掉底部像素数，用于清除生图自带的 `AI生成` 水印 |
| `margin` / `gap` / `title_h` | `40` / `30` / `210` | 外边距、格间距、标题区高度 |
| `font` | Hiragino Sans GB | 传 `.ttc` 会自动挑最粗字面 |
| `ink` / `accent` | `#2b2724` / `#c63a34` | 墨色与强调色 |
| `title_size` / `subtitle_size` | `92` / `36` | 标题字号 |
| `out_width` | `2400` | 最终输出宽度，传 0 保持原尺寸 |

## panels 单项

| 字段 | 说明 |
|---|---|
| `image` | 单格图片绝对路径 |
| `patches` | 可选，修补 AI 瑕疵：`[{"src":[x0,y0,x1,y1], "dst":[x,y]}]`，取样块粘贴到目标点 |
| `frame` | 外框颜色；传 `false` 关闭该格外框 |
| `bubble` | 可选，省略则该格为纯画面 |

### bubble

| 字段 | 说明 |
|---|---|
| `shape` | `ellipse`（对白）/ `roundrect`（清单、系统输出）/ `burst`（怒吼） |
| `center` | `[x, y]`，**相对本格左上角**的气泡中心 |
| `rx` / `ry` | 气泡半宽 / 半高。四格用 `470 / 135` 可稳装双层问答文案 |
| `tail` | `[[尖点],[基点1],[基点2]]`，全部相对本格左上角。尖点指向说话主体 |
| `outline` | 描边色，默认取顶层 `ink`；情绪爆发格传强调色 |
| `seed` | 抖动随机种子，固定后重跑结果一致，便于微调对比 |
| `align` | `center`（默认）或 `left`（清单式左对齐，左内边距 70px） |
| `lines` | 每行：`{"text", "size", "color", "dy", "align"}`，`dy` 为相对气泡中心的垂直偏移 |

## 坐标怎么定

1. 先看单格图，找出**留白区**（生图时已要求上方 1/3 留空）。
2. 把 `center` 放在留白区中心，`rx/ry` 让它不压到主体轮廓。
3. `tail` 尖点指向说话者（人或物），两个基点**朝气泡中心方向内收**——脚本会校验，超界会报错。
4. 跑一次，脚本会打印每格的「块宽 / 块高 / 可用高」，余量小于 20px 就调整。
5. 看输出图微调 `center` 与 `tail`，其余不用动。

## 完整示例

```json
{
  "title": "十万个为什么",
  "title_accent": "为什么",
  "subtitle": "小动物与植物 · 四堂自然观察课",
  "output": "/absolute/path/why-comic.png",
  "cols": 2,
  "crop_bottom": 100,
  "panels": [
    {
      "image": "/absolute/path/panel1.png",
      "bubble": {
        "shape": "ellipse",
        "center": [930, 190],
        "rx": 470, "ry": 135,
        "seed": 101,
        "tail": [[580, 360], [700, 250], [830, 260]],
        "lines": [
          {"text": "蜗牛为什么从不换房子？", "size": 38, "color": "#7a7164", "dy": -33},
          {"text": "因为壳是它的骨头，长在身体外面。", "size": 48, "color": "#2b2724", "dy": 29}
        ]
      }
    }
  ]
}
```

清单式（左对齐、多行等距）用 `roundrect` + 逐行给 `dy`：

```json
{
  "shape": "roundrect",
  "center": [640, 215], "rx": 440, "ry": 185,
  "align": "left",
  "tail": [[800, 462], [740, 372], [860, 366]],
  "lines": [
    {"text": "用什么格式导出？", "size": 38, "dy": -144},
    {"text": "字段怎么排序？", "size": 38, "dy": -96}
  ]
}
```
