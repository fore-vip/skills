# 叙事节奏模板

四格漫画的力量来自**节奏**，不是画面。先把每格的"职责"定死，再写台词和画面。

## 通用四幕结构

| 幕 | 职责 | 禁忌 |
|---|---|---|
| 1 | 建立场景与预期 | 不要一上来就抛笑点 |
| 2 | 加压 / 递进 / 堆叠 | 不要平铺直叙第二遍 |
| 3 | 爆发 / 峰值（视觉重音在此） | 不要提前泄底 |
| 4 | 反转 / 冷收（留余味） | 不要解释笑点 |

**第 3 格是视觉峰值**（唯一使用强调色描边的一格），**第 4 格是信息峰值**（最妙的一句放这里）。

## 主题路线（先定线，再分镜）— 强制

**每一组四格必须先确定一条「主题路线」，四格沿这条路线推进，而不是四个并列的静态瞬间。** 只定四幕职责、不定路线，结果就是四格同一构图、同一情绪、只换道具——这是本 SKILL 已实测的失败模式。

主题路线 = 一句话说明"从什么状态，经过什么变化，到什么状态"。写法：`起点 → 转折 → 终点`。

| 题材 | 主题路线示例 | 每格承担的演进任务 |
|---|---|---|
| 喜剧梗 | 正常需求 → 层层加码 → 当场爆发 → 一问打回 | 平静 → 堆叠 → 失控 → 冷收 |
| 科普问答 | 习以为常 → 提出疑问 → 反直觉真相 → 俏皮落地 | 熟悉 → 悬念 → 顿悟 → 会心 |
| 吐槽日常 | 共鸣场景 → 逐级升级 → 彻底崩溃 → 自嘲和解 | 认同 → 加压 → 顶点 → 释怀 |
| 产品说明 | 具体痛点 → 尝试无效 → 转折出现 → 克制主张 | 困扰 → 挫败 → 转机 → 清晰 |
| 情感共鸣 | 平静日常 → 细微触动 → 情绪转折 → 留白 | 静 → 动 → 涌 → 空 |

路线要写进 storyboard 的注释或分镜说明里，四格的 `scene` / `emotion` 必须能在字面上对应到路线的四个阶段。**没有路线的分镜不允许进入编译。**

**用户给的主题信息过少、定不出路线时**：先按 `brief-expansion.md` 从已有信号推演路线，输出带编号假设的剧情提案并经用户确认，再把确认过的路线填进本节模板。不要用选项题让用户自行设计路线。

## 画面演进（四格不能长一个样）— 参照模板引导

四格必须在**镜头景别、场景状态、光线色调、人物情绪**四个维度上各有差异，至少三个维度呈现可见递进。这是"剧情演进"在画面上的硬指标。

| 维度 | 第 1 格 | 第 2 格 | 第 3 格 | 第 4 格 |
|---|---|---|---|---|
| 镜头景别 | 中景 / 全景（交代） | 近景 / 俯视（加压） | 特写 / 极端特写（峰值） | 中景 / 拉远（收束） |
| 场景状态 | 初始、相对整洁 | 堆积、变乱、变多 | 聚焦到关键物件 | 归位、整洁、留白 |
| 光线色调 | 常态光（冷或柔） | 偏紧、偏暖或偏暗 | 聚光、强调色出现 | 明亮通透 / 柔和收尾 |
| 人物情绪 | 平静或困惑 | 加压、专注、皱眉 | 决断、惊讶、爆发 | 释然、克制、从容 |

**写法要点**：`scene` 字段必须显式描述景别与场景状态（如 `an overhead view`、`an extreme close-up`、`the desk now tidy`），`emotion` 字段描述该格独有的情绪。**照下面参照模板填即可**；编译器对同质只提醒不阻断，不用数值阈值卡创意。

## 提示词参照模板（无限扩展路线用）

**剧情路线可以无限生长，不用数值阈值去框。** 旧的「四维每维≥3 种取值」「scene 雷同度>0.55 直接拒绝」已降级为软提醒——编译器只在输出里提示同质，不阻断生成。真正的解法是照参照模板写：`{...}` 为可替换槽位，槽位数量、顺序、组合都可自由扩展，换题材、换角色、换情绪都能复用。

### 模板 A：过载 → 聚焦 → 收束（职场 / 说明 / 科普通用）

| 格 | 结构槽位 | scene 英文示例 | emotion 示例 |
|---|---|---|---|
| 1 | `{角色} 在 {场景}，{初始物件}，{常态光}` | A wide shot of the analyst at a tidy desk, reports stacked nearby, soft morning light. | puzzled, quiet |
| 2 | `{视角切换} 看 {场景}，{堆叠物} 变多，{紧光}` | An overhead view of the desk crowded by four piles of documents, warm tense light. | overwhelmed, leaning in |
| 3 | `{极端特写} 落在 {关键物件}，{强调光}` | An extreme close-up of the magnifying glass over one blank card, sharp highlight. | decisive, eyes bright |
| 4 | `{拉远} 看 {场景} 归位，{通透光}` | A wide pull-back of the tidy desk, the notebook closed, clear daylight. | serene, unhurried |

### 模板 B：共鸣 → 升级 → 崩点 → 自嘲（吐槽日常）

| 格 | 结构槽位 | 示例动作 |
|---|---|---|
| 1 | `{读者熟悉的场景}，{角色} 尚且从容` | 通勤地铁上刚坐下，耳机戴好 |
| 2 | `{同一场景}，{干扰} 第一次出现` | 消息弹窗连着跳，包里东西散出来 |
| 3 | `{视角收紧}，{干扰} 叠到顶点` | 极端特写：手里三台设备同时响 |
| 4 | `{拉远}，{角色} 对自己苦笑` | 原地坐正，长舒一口气 |

### 模板 C：熟悉 → 疑问 → 反直觉 → 俏皮（科普问答）

| 格 | 结构槽位 |
|---|---|
| 1 | 中景：`{常见现象}` 在日常场景里发生 |
| 2 | 近景：`{角色}` 停下动作，盯着现象 |
| 3 | 特写：`{关键细节}` 被放大，真相露出 |
| 4 | 拉远：现象恢复，`{角色}` 轻轻一笑 |

### 模板 D：平静 → 触动 → 转折 → 留白（情感共鸣）

| 格 | 结构槽位 |
|---|---|
| 1 | 全景：`{日常空间}` 安静，人物小 |
| 2 | 中景：`{细微触动}` 出现（一件旧物、一句话） |
| 3 | 特写：`{人物反应}` 的手或眼神 |
| 4 | 全远景：人物回到原位，情绪不点破 |

### 怎么用

1. 选一套模板，或把两套的槽位拼接成新路线——槽位可替换、增删、重排，没有上限。
2. 每个槽位填一个**可拍摄的物理事实**（见 `prompt-compiler.md`「scene 写法铁律」），不填抽象情绪。
3. 台词单独写，遵守字数预算，不进 prompt。
4. 编译器给同质提醒时，回到模板换一个视角或槽位；不要为了凑取值数量硬改。

## 1. 喜剧梗

铺垫 → 堆叠加压 → 爆发 → 反转冷收

- 第 2 格的"堆叠"最有效的手法：**同一句式重复多次**（清单、连问、循环）。
- 第 4 格的反转要**回扣第 3 格**（人物刚说的话被原样打回）。

实例（已落地）：提需求 → AI 连问 7 个细节 → 人暴起"CSV、UTF-8、有表头，其他你看着办！！" → AI 冷静追问"是逗号，还是分号？"

## 2. 科普问答

悬念提问 → 揭秘 → 冷知识 → 可爱反转

- 台词用**双层气泡**：问题小字灰（≤13 字）+ 答案大字墨（≤16 字）。
- 答案必须是**真知识**，且带一点反直觉——"原来是这样"比"学到了"更有传播力。
- 第 4 格可加一句拟人化的俏皮收尾（例：含羞草"五分钟后当没发生过"）。

实例（已落地）：蜗牛为什么从不换房子 / 向日葵为什么追着太阳转 / 小鸟睡树上为什么不会掉 / 蒲公英为什么能飞那么远。

## 3. 吐槽日常

共鸣 → 逐级升级 → 崩溃 → 自嘲收尾

- 第 1 格必须让读者"对，就是这样"，共鸣是这类题材的全部前提。
- 第 4 格把矛头转向自己，比指责他人更安全也更好笑。

## 4. 产品 / 价值说明

痛点具象化 → 尝试 → 转折 → 主张

- 画面里的痛点要**具体到物件**（堆成山的表格、反复弹窗），不要抽象成概念。
- 第 4 格的主张**不得出现绝对化用语**：最、第一、唯一、保证、必、100%、独家、限时。
- 能力描述只写已落地的部分，未上线的一律不写。

## 5. 情感共鸣

平静日常 → 细微触动 → 转折 → 留白

- 这类题材**少字多画面**，气泡可以少放甚至不放。
- 第 4 格宁可留白，也不要把情绪说破。

## 文案字数预算（实测阈值）

气泡用 `rx=470 / ry=135` 的椭圆时：

- 单行答案 ≤ **16 字**（48px）
- 单行问题 ≤ **13 字**（38px）
- 超了就加宽气泡或拆行——**不要缩字号硬塞**，缩到 40px 以下在手机上就吃力了。

中文宽度 ≈ 字号（1em）。英文与数字约占 0.5–0.6em，可粗略按半宽计。

## 谁是说话人：用形状区分，不用标注

| 形状 | 用途 |
|---|---|
| 抖动手绘椭圆 | 普通对白 |
| 抖动手绘圆角矩形 | 系统输出 / 清单 / 多行并列 |
| 抖动锯齿爆炸形 | 怒吼、情绪爆发（配红色描边） |
| 极小椭圆 | 虚弱、气若游丝、冷静 |
| 大椭圆 + 双层文字 | 科普问答 |

尾巴指向谁，读者就知道谁在说话——**不要写"甲方说："这类标注**。
