# 叙事节奏模板

四格漫画的力量来自**节奏**，不是画面。先把每格的"职责"定死，再写台词和画面。

## 通用四幕结构

| 幕 | 职责 | 禁忌 |
|---|---|---|
| 1 | 建立场景与预期 | 不要一上来就抛笑点 |
| 2 | 加压 / 递进 / 堆叠 | 不要平铺直叙第二遍 |
| 3 | 爆发 / 峰值（视觉重音在此） | 不要提前泄底 |
| 4 | 反转 / 冷收（留余味） | 不要解释笑点 |

**第 3 格是视觉峰值**（唯一使用强调色描边的一格），**第 4 格是信息峰值**（最妙的一句放这里）。

---

## 1. 喜剧梗

铺垫 → 堆叠加压 → 爆发 → 反转冷收

- 第 2 格的"堆叠"最有效的手法：**同一句式重复多次**（清单、连问、循环）。
- 第 4 格的反转要**回扣第 3 格**（人物刚说的话被原样打回）。

实例（已落地）：提需求 → AI 连问 7 个细节 → 人暴起"CSV、UTF-8、有表头，其他你看着办！！" → AI 冷静追问"是逗号，还是分号？"

## 2. 科普问答

悬念提问 → 揭秘 → 冷知识 → 可爱反转

- 台词用**双层气泡**：问题小字灰（≤13 字）+ 答案大字墨（≤16 字）。
- 答案必须是**真知识**，且带一点反直觉——"原来是这样"比"学到了"更有传播力。
- 第 4 格可加一句拟人化的俏皮收尾（例：含羞草"五分钟后当没发生过"）。

实例（已落地）：蜗牛为什么从不换房子 / 向日葵为什么追着太阳转 / 小鸟睡树上为什么不会掉 / 蒲公英为什么能飞那么远。

## 3. 吐槽日常

共鸣 → 逐级升级 → 崩溃 → 自嘲收尾

- 第 1 格必须让读者"对，就是这样"，共鸣是这类题材的全部前提。
- 第 4 格把矛头转向自己，比指责他人更安全也更好笑。

## 4. 产品 / 价值说明

痛点具象化 → 尝试 → 转折 → 主张

- 画面里的痛点要**具体到物件**（堆成山的表格、反复弹窗），不要抽象成概念。
- 第 4 格的主张**不得出现绝对化用语**：最、第一、唯一、保证、必、100%、独家、限时。
- 能力描述只写已落地的部分，未上线的一律不写。

## 5. 情感共鸣

平静日常 → 细微触动 → 转折 → 留白

- 这类题材**少字多画面**，气泡可以少放甚至不放。
- 第 4 格宁可留白，也不要把情绪说破。

---

## 文案字数预算（实测阈值）

气泡用 `rx=470 / ry=135` 的椭圆时：

- 单行答案 ≤ **16 字**（48px）
- 单行问题 ≤ **13 字**（38px）
- 超了就加宽气泡或拆行——**不要缩字号硬塞**，缩到 40px 以下在手机上就吃力了。

中文宽度 ≈ 字号（1em）。英文与数字约占 0.5–0.6em，可粗略按半宽计。

## 谁是说话人：用形状区分，不用标注

| 形状 | 用途 |
|---|---|
| 抖动手绘椭圆 | 普通对白 |
| 抖动手绘圆角矩形 | 系统输出 / 清单 / 多行并列 |
| 抖动锯齿爆炸形 | 怒吼、情绪爆发（配红色描边） |
| 极小椭圆 | 虚弱、气若游丝、冷静 |
| 大椭圆 + 双层文字 | 科普问答 |

尾巴指向谁，读者就知道谁在说话——**不要写"甲方说："这类标注**。
