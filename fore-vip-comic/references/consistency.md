# 风格一致性：文字锁 + 图像锁

## 两级锁，缺一不可

| 锁 | 手段 | 解决什么 | 做不到什么 |
|---|---|---|---|
| 文字锁 | 提示词编译器固定层逐字相同 | 画风、角色措辞、构图、负面约束一致 | 控制不了模型对同一句文字的视觉解释 |
| 图像锁 | `ImageGen.image1` 参考图 + `input_fidelity` | 角色长相、笔触、配色跨格稳定 | 不能替代文字锁，参考图不含场景信息 |

只用文字锁时，四格角色会"像但不是同一个"；叠加图像锁才能做到同一张脸、同一件衣服。

## 图像锁工作流

1. **先定锚点**：生成第一格并确认可用后，把它存为固定路径（如 `anchor.png`）。
2. **后续格图生图**：第 2–4 格调用 `ImageGen` 时传 `image1=<anchor.png>`，`prompt` 用编译后的完整六层 prompt，`input_fidelity` 按画风取值。
3. **场景覆盖**：`image1` 只提供风格与角色，scene 由 prompt 主导；不要指望参考图带场景。
4. **锚点不换**：一组四格从头到尾用同一张锚点。锚点崩了就整组重做，不要中途换图。

## input_fidelity 取值

| 场景 | 建议值 | 说明 |
|---|---|---|
| 角色特写多、要求同一张脸 | 高 | 贴近锚点，但 scene 改动大时可能被参考图拖回原构图 |
| 场景变化大（四格切换地点） | 中 | 保风格与角色轮廓，给场景留改写空间 |
| 水墨、彩铅等笔触重的画风 | 中 | 高保真会复制锚点纸纹，导致四格噪点重复 |
| 日式黑白线稿 | 中–高 | 线稿对保真容忍度高 |

没有实测过的取值先做两格小样对比，不要四格一次全生成——生图按张计费。

## 多参考图

`ImageGen` 支持 `image1` / `image2` / `image3`，按顺序传入：

- `image1`：角色锚点（必传）
- `image2`：画风样张（可选，当锚点格光线特殊时补充一张正常光线样张）
- `image3`：一般不用，保留给"必须复制的道具特写"

三张图会一起影响结果，传得越多 prompt 的场景自由度越低。能用一张解决就不要传两张。

## 夜景 / 暗色场景特例

锚点格是白天、某格要暗色时：

1. 在 scene 里写死色调：`pale warm cream and light blue tones, no large dark areas anywhere`。
2. prompt 追加 `keeping the same character design as the reference image`。
3. `input_fidelity` 调高一级，防止暗色把角色压变形。
4. 不要只写 `night scene`——实测会出现大块纯黑、主体被压小。

## 验收清单（交付前逐项核对）

| 项 | 检查 |
|---|---|
| 脸与发型 | 四格是否同一人 |
| 穿着与主色 | 衣服、道具颜色是否一致 |
| 笔触与纸感 | 放大后纹理是否同一风格 |
| 留白区 | 气泡位是否都在上方 1/3 |
| 无文字 | 画面里有没有模型偷画的字母、数字、印章 |
| 色调 | 有没有某一格明显偏色或过暗 |

不合格的格：两次生成不达标就换主体或换表达角度，不要第三次硬拗。改台词只需重跑合成脚本，不必重新生图。
