# 工厂侧评分卡（F1–F11）

适用：有生产现场的制造型企业。**须与企业侧评分卡合并计算**（企业侧 40% + 工厂侧 60%，可在 SKILL.md 主流程调整）。

评分标尺与打分纪律同 @references/dimensions-enterprise.md「统一评分标尺」（5 优秀 / 4 良好 / 3 合格 / 2 薄弱 / 1 危险 / 0 不适用）。

---

## F1 · 生产效能（默认权重 14）

| 评分项 | 观察点 |
|---|---|
| OEE 综合效率 | 可用率 × 性能稼动率 × 良率；是否真实采集还是拍脑袋 |
| 产能利用率 | 实际产出 / 设计产能，瓶颈工序在哪 |
| 计划达成率 | 日/周生产计划达成率，插单与急单占比 |
| 换型与切换 | 换型时间 SMED、切换损失占比 |
| 节拍与平衡 | 产线平衡率、瓶颈 CT vs 节拍 TT |
| 在制品 WIP | WIP 水平是否合理，是否存在堵塞 |

**实算指标**：OEE（世界级 ≥85%，一般离散制造 60–70%）、产能利用率、计划达成率、产线平衡率、换型时间。
**红旗**：① OEE 长期 < 50% 且无人管理；② 瓶颈工序常年吃不饱/撑死且未做产线平衡。

---

## F2 · 质量（默认权重 14）

| 评分项 | 观察点 |
|---|---|
| 一次合格率 FPY | 直通率 vs 最终合格率（返工掩盖问题） |
| 过程能力 | 关键特性 Cpk/Ppk 是否≥1.33 |
| 报废与返工 | 报废率、返工率、质量成本 COPQ 占销售额比 |
| 客诉与外部失败 | 客户端 PPM、退货率、召回与索赔 |
| 质量体系 | IQC/IPQC/OQC/FQC 是否实质运行，检验记录真实性 |
| 根因与闭环 | 8D/5Why 是否真做，重复缺陷是否复发 |
| 防错 | Poka-Yoke 与 SPC 应用程度 |

**实算指标**：FPY、报废率、COPQ/销售额（优秀 <2%，一般 5–15%）、Cpk、客诉 PPM、重复缺陷率。
**红旗**：① 关键安全特性无过程能力数据；② 批量召回或客户停线；③ 检验记录造假/后补。

---

## F3 · 设备（默认权重 10）

| 评分项 | 观察点 |
|---|---|
| 设备可靠性 | MTBF、MTTR、设备故障率趋势 |
| 保养体系 | 自主保养 + 专业保养是否落地，点检执行率与真实率 |
| 备件管理 | 关键备件可得性、备件资金占用、呆滞备件 |
| 维修能力 | 自修 vs 厂商依赖、故障知识库 |
| 预测性维护 | 是否有振动/温度/电流监测与预警 |
| 设备台账 | 台账完整、特种设备定检、仪表校准有效期 |

**实算指标**：MTBF、MTTR、计划保养达成率、突发故障停机时长占比、备件周转率。
**红旗**：① 特种设备超期未检；② 关键设备单点且无备机无备件；③ 带病运行/安全联锁被短接。

---

## F4 · 成本与精益（默认权重 12）

| 评分项 | 观察点 |
|---|---|
| 单位制造成本 | 单台/单件成本趋势，与标杆的差距 |
| 材料利用率 | 良率/损耗/边料回收，BOM 用量 vs 实际用量差异 |
| 能耗单耗 | 单位产值能耗、峰谷电利用、空载与泄漏 |
| 人工效率 | 直接/间接人员比、加班工时占比、人时产出 |
| 七大浪费 | 过量生产/等待/搬运/加工/库存/动作/不良 的识别与改善 |
| 改善机制 | 提案改善参与率、改善成果固化率 |

**实算指标**：单位制造成本、材料利用率、单位产值能耗、人工效率、改善提案人均件数。
**红旗**：① 单位成本连续 4 季度上升且无改善项目；② 主要成本项无计量（连用了多少电/料都说不清）。

---

## F5 · 交付与计划（默认权重 12）

| 评分项 | 观察点 |
|---|---|
| 准交率 OTIF | 按时足量交付率（客户口径，不是内部口径） |
| 生产周期 | 从投料到出货 Lead Time，其中增值时间占比 |
| 计划稳定性 | 计划冻结期、变更次数、插单冲击 |
| 产销协同 | S&OP 机制、销售预测准确率 |
| 齐套性 | 物料齐套率、缺料停线次数 |

**实算指标**：OTIF（优秀 ≥95%）、Lead Time、预测准确率、计划变更次数、齐套率。
**红旗**：① OTIF < 80% 且客户已扣款/罚款；② 因缺料月均停线 ≥2 次。

---

## F6 · 现场 5S/6S 与目视化（默认权重 6）

| 评分项 | 观察点 |
|---|---|
| 整理整顿 | 必需品/非必需品区分，定位定量，通道畅通 |
| 清扫清洁 | 清扫责任区、污染源治理、标准是否被维持 |
| 素养 | 员工是否自觉遵守，还是检查前突击 |
| 目视化 | 安灯/看板/标线/警示、异常是否一眼可见 |
| 审核机制 | 5S 审核频率、问题闭环率 |

> **现场判定技巧**：不看通知后的现场，看**突击时的状态**、**夜班状态**、**角落与柜子内部**。
**实算指标**：5S 审核得分、问题闭环率、通道占用率。
**红旗**：① 消防通道长期占用；② 现场跑冒滴漏无人管。

---

## F7 · EHS 安全与环保（默认权重 12，**一票项高发区**）

| 评分项 | 观察点 |
|---|---|
| 事故与险兆 | 可记录伤害率 TRIR、险兆上报数（上报多≠差，瞒报才是问题） |
| 隐患排查 | 隐患整改闭环率、闭环时效 |
| 安全行为 | 劳保佩戴、特种作业持证、上锁挂牌 LOTO、动火/受限空间作业票 |
| 消防设施 | 消防器材有效、疏散通道、演练频次 |
| 环保合规 | 排污许可证、三废处理设施运行、在线监测、危废转移联单 |
| 职业健康 | 粉尘/噪声/毒物岗位检测、体检、防护 |

**实算指标**：TRIR/LTIFR、隐患闭环率、危废合规处置率、污染物达标排放率。
**红旗（任一触发即整体降级）**：
① 近 12 个月发生重伤及以上事故或瞒报；
② 重大隐患未按期整改（如消防/危化/有限空间）；
③ 环保设施不正常运行、偷排或危废非法转移；
④ 特种作业无证上岗。

---

## F8 · 人员与技能（默认权重 7）

| 评分项 | 观察点 |
|---|---|
| 技能矩阵 | 多能工比例、关键岗位技能覆盖率 |
| 培训体系 | 上岗认证、培训学时、效果验证（不是签到表） |
| 人员结构 | 直接/间接比、年龄结构、劳务工比例 |
| 稳定性 | 一线流失率、新员工 30/90 天留存 |
| 工时与疲劳 | 月加班工时、连续上班天数、夜班安排 |

**实算指标**：多能工比例、关键岗位认证覆盖率、一线月度流失率、月人均加班工时。
**红旗**：① 一线月流失率 > 10% 且持续；② 月加班 > 80 小时或存在强迫加班；③ 关键岗位无证上岗。

---

## F9 · 工艺与工程（默认权重 7）

| 评分项 | 观察点 |
|---|---|
| 工艺稳定性 | 工艺参数是否有窗口、是否受控、变更是否验证 |
| 标准工时 | 标准工时是否测定并更新，是否与排产/计薪一致 |
| 数据准确率 | BOM 准确率、工艺路线准确率、库存与实物一致 |
| 工装夹具 | 工装完好率、快速切换支持、寿命管理 |
| 新品导入 NPI | 试产问题闭环、量产爬坡曲线、工程变更 ECN 管理 |

**实算指标**：BOM 准确率（优秀 ≥99%）、标准工时覆盖率、量产爬坡达标周期、ECN 数量与闭环率。
**红旗**：① BOM 错误导致批量错料/停线；② 工艺变更未验证即量产。

---

## F10 · 厂务与能源（默认权重 3）

| 评分项 | 观察点 |
|---|---|
| 水电气保障 | 供能稳定性、是否有双回路/备机 |
| 能耗管理 | 分表计量覆盖率、单位产值能耗趋势、峰谷套利 |
| 厂务设施 | 空压/空调/除尘/水处理运行状态与保养 |
| 碳与双碳 | 能碳台账、Scope1/2 核算、绿电与节能改造 |

**实算指标**：单位产值能耗、分表计量覆盖率、能耗成本占比、碳排放强度。
**红旗**：① 无分表计量且能耗成本不可控；② 供能中断导致停产。

---

## F11 · 仓储与物流（默认权重 3）

| 评分项 | 观察点 |
|---|---|
| 账实相符 | 循环盘点/全盘差异率 |
| 库存周转 | 原材料/在制/成品周转天数、呆滞占比 |
| FIFO | 先进先出执行、批次追溯能力 |
| 物流与包装 | 装载率、运输破损率、包装标准化与周转容器 |
| 收货发货 | 收发货准确率、装卸安全 |

**实算指标**：账实相符率（优秀 ≥99.5%）、库存周转天数、呆滞率、出货准确率。
**红旗**：① 账实差异 > 2% 且长期不处理；② 无法批次追溯（召回时无法定位范围）。
