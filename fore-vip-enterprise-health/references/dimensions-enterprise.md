# 企业侧评分卡（E1–E10）

适用：所有企业。**制造型企业在跑完本卡后，必须继续跑 @references/dimensions-factory.md。**

## 统一评分标尺

| 分 | 含义 | 判定口径 |
|:--:|------|----------|
| **5** | 优秀 | 体系化运行 ≥1 年，有数据验证，行业前 20%，能自我迭代 |
| **4** | 良好 | 制度齐全且稳定执行，指标达标，有明确改进机制 |
| **3** | 合格 | 基本达标，但靠关键人/救火，指标波动大或只统计不改善 |
| **2** | 薄弱 | 频繁出问题，无成文制度或制度形同虚设 |
| **1** | 危险 | 失控/缺失，已造成实际损失或存在重大隐患 |
| **0** | 不适用 | 该维度对本主体不适用，**不计入加权，其权重按比例重分配** |

> **打分纪律**：分数必须有证据支撑。无证据时降一档并标注「待核实」，禁止给无依据的高分。

---

## E1 · 战略与治理（默认权重 9）

| 评分项 | 观察点 |
|---|---|
| 战略清晰度 | 有 3 年目标与年度分解？全员能说清公司今年的 3 件大事吗 |
| 主业聚焦度 | 前两大业务收入占比；是否同时追 5 个以上方向 |
| 治理结构 | 股权集中度、董事会/经营会是否实质运作、一言堂程度 |
| 决策机制 | 重大投资/用人的决策流程与复盘机制；决策失误率 |
| 接班与 Continuity | 一号位若缺席 3 个月，业务是否照常运转 |

**实算指标**：前两大业务收入占比、战略项目按期达成率、一号位缺席演练结果。
**红旗**：① 实控人涉重大诉讼或股权被冻结；② 连续 2 年战略方向推倒重来；③ 一号位强依赖且无接班人。

---

## E2 · 财务健康（默认权重 17，**最高权重**）

| 评分项 | 观察点 |
|---|---|
| 盈利能力 | 毛利率/净利率 vs 行业中位；是否连续下滑 |
| 现金流 | 经营性现金流净额是否连续为正；**现金 runway 月数** |
| 资产结构 | 资产负债率、流动比率、速动比率 |
| 应收与库存 | 应收账款周转天数 DSO、逾期占比、坏账计提充分性 |
| 成本结构 | 固定成本占比（经营杠杆）、单位成本趋势 |
| 税务与账务 | 两套账/体外循环、发票合规、税务评级 |
| 融资与担保 | 有息负债成本、担保链、对赌/回购条款 |

**实算指标**：见 @references/formulas.md「财务公式库」。
**红旗（任一触发即整体降级）**：
① 现金 runway < 3 个月；
② 经营性现金流连续 2 年为负且靠融资续命；
③ 资产负债率 > 85% 或已出现债务逾期/展期；
④ 存在体外循环或重大税务稽查。

---

## E3 · 市场与销售（默认权重 13）

| 评分项 | 观察点 |
|---|---|
| 客户集中度 | 前五大客户收入占比（>50% 高危） |
| 订单与漏斗 | 线索→商机→赢单转化率、漏斗健康度、销售周期 |
| 增长质量 | 新客贡献率、老客复购率、获客成本 CAC / 客户生命周期 LTV |
| 定价权 | 能否涨价、毛利率是否被动侵蚀、价格战暴露度 |
| 渠道与品牌 | 渠道依赖度（单一平台占比）、自有流量/品牌资产 |
| 竞争位势 | 市场份额趋势、差异化是否可被快速复制 |

**实算指标**：CR5 客户集中度、复购率、CAC/LTV、销售漏斗各级转化率、市占率。
**红旗**：① 单一客户占比 > 40%；② 大客户流失且无替代；③ 收入连续 3 季度下滑且漏斗无新血。

---

## E4 · 产品与研发布局（默认权重 11）

| 评分项 | 观察点 |
|---|---|
| 产品竞争力 | 核心产品是否解决真痛点、与竞品的实测差距 |
| 研发投入 | 研发费用率、研发人员占比 vs 同行 |
| 新品贡献 | 近 1–3 年新品收入占比、新品成功率 |
| 技术壁垒 | 专利/软著/配方/工艺诀窍；被绕过的难度 |
| 产品生命周期 | 主力产品所处阶段，是否有接续梯队 |
| 需求管理 | 需求来源是否结构化、是否有需求评审与取舍机制 |

**实算指标**：研发费用率、新品收入占比、专利数（发明 vs 实用新型）、产品迭代周期。
**红旗**：① 主力产品已进入衰退期且无接续；② 核心技术人员集中离职且无文档沉淀；③ 知识产权归属存在争议。

---

## E5 · 组织与人才（默认权重 11）

| 评分项 | 观察点 |
|---|---|
| 关键人依赖 | 某个岗位/人离职是否导致业务停摆 |
| 人效 | 人均营收/人均利润 vs 同行、人机比 |
| 梯队 | 关键岗位是否有 B 角、继任者覆盖率 |
| 流失与稳定 | 主动流失率、核心人才流失率、新员工 90 天留存 |
| 激励与考核 | 绩效考核是否与目标对齐、分配是否拉开差距 |
| 文化与士气 | 员工敬业度、跨部门协作摩擦、内部信息透明度 |

**实算指标**：人均营收/利润、主动离职率、继任者覆盖率、人效三年趋势。
**红旗**：① 核心团队 1 年内流失 > 30%；② 存在集体劳动仲裁或欠薪；③ 一号位与高管层严重对立。

---

## E6 · 流程与运营（默认权重 8）

| 评分项 | 观察点 |
|---|---|
| 流程化率 | 核心业务流程是否成文（SOP 覆盖率）、是否被执行 |
| 端到端效率 | 从订单到收款/从需求到上线的周期 |
| 交付与履约 | 交付及时率、承诺兑现率、异常响应时效 |
| 例外处理 | 异常是否有升级机制，会不会反复同样问题 |
| 管理认证 | ISO9001/14001/45001、IATF16949 等是否实质运行还是买证 |

**实算指标**：SOP 覆盖率、订单交付周期、一次做对率、异常重复发生率。
**红旗**：① 核心流程无 SOP 且出错频繁；② 体系认证为「买证」状态。

---

## E7 · 供应链（默认权重 8）

| 评分项 | 观察点 |
|---|---|
| 供应商集中度 | 单一供应商/单源物料占比 |
| 供应稳定性 | 来料准时率、来料合格率、断供历史 |
| 采购成本 | 采购价格趋势、议价能力、年度降本达成 |
| 库存健康 | 库存周转天数、呆滞库存占比 |
| 风险预案 | 关键物料是否有备选、安全库存策略、地缘/汇率暴露 |

**实算指标**：供应商集中度、准时交货率 OTD、来料合格率、库存周转天数、呆滞率。
**红旗**：① 关键物料独家供应且无备选；② 断供已导致停产/违约。

---

## E8 · 数字化与数据（默认权重 8）

| 评分项 | 观察点 |
|---|---|
| 系统覆盖 | 核心业务是否进系统（ERP/MES/CRM/WMS），还是 Excel 主战 |
| 数据质量 | 账实相符率、数据是否唯一可信源、录入及时性 |
| 自动化 | 重复人工环节占比、RPA/接口集成度 |
| 决策支持 | 是否有经营看板，管理层是否看数据决策 |
| 信息安全 | 权限管理、备份与容灾、等保/数据合规 |

**实算指标**：系统覆盖率、账实相符率、报表出具时效、手工单据占比。
**红旗**：① 财务/库存账实严重不符；② 核心数据无备份或全员共享管理员账号。

---

## E9 · 风险与合规（默认权重 10）

| 评分项 | 观察点 |
|---|---|
| 法律与诉讼 | 未决诉讼、被执行、失信记录、合同履约风险 |
| 资质证照 | 营业执照/生产许可/排污许可/特种设备等是否齐全有效 |
| 知识产权 | 商标专利布局、侵权与被侵权风险 |
| 劳动合规 | 社保公积金、工时加班、劳务派遣比例 |
| 舆情与商誉 | 公开负面、客户公开投诉、监管通报 |
| 内控 | 费用审批、采购招标、关联交易、反舞弊机制 |

**实算指标**：未决诉讼标的额/净资产、证照到期预警数、社保合规率。
**红旗（任一触发即整体降级）**：
① 列入失信被执行人或实控人限高；
② 关键证照缺失/过期仍在生产；
③ 近 1 年重大行政处罚（安监/环保/市监）未整改闭环。

---

## E10 · 客户与服务（默认权重 5）

| 评分项 | 观察点 |
|---|---|
| 满意度 | NPS / CSAT、是否定期测量并驱动改进 |
| 投诉与闭环 | 投诉响应时效、闭环率、重复投诉率 |
| 售后与口碑 | 退换货率、服务成本、复购与转介绍 |
| 客户成功 | 是否主动管理客户价值，还是只做被动报修 |

**实算指标**：NPS、投诉闭环率、一次解决率、退换货率。
**红旗**：① 重大客诉未闭环或被公开曝光；② 批量质量问题召回。

|---|---|---|---|---|---|---|---|---|---|---|
