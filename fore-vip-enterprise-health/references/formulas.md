# 实算指标公式库与行业基准

用途：用户**提供了财报/生产报表**时，用实算结果校准评分卡中靠问卷得出的分数；纯问卷模式下不必调用本文件。

**校准原则**：实算值与问卷分冲突时，**以实算值为准**，并在报告中标注「实算校准」。

---

## 一、财务公式库

| 指标 | 公式 | 健康区间 | 预警 |
|---|---|---|---|
| 毛利率 | (营收 − 营业成本) / 营收 | ≥ 行业中位 | 连续 4 季下滑 |
| 净利率 | 净利润 / 营收 | ≥5%（制造） | <2% 或为负 |
| 现金 runway | 期末现金 / 月均经营性现金流出 | ≥6 个月 | **<3 个月 = 红旗** |
| 经营性现金流净额 | 现金流量表直接取数 | 连续为正 | ≤0 |
| 资产负债率 | 总负债 / 总资产 | 40–60% | **>85% = 红旗** |
| 流动比率 | 流动资产 / 流动负债 | 1.5–2.5 | <1 |
| 速动比率 | (流动资产 − 存货) / 流动负债 | ≥1 | <0.5 |
| 应收账款周转天数 DSO | 应收账款余额 / 营收 × 天数 | ≤ 账期 +15 天 | > 账期 ×2 |
| 存货周转天数 | 平均存货 / 营业成本 × 天数 | 制造 30–90 天 | >120 天 |
| 应付账款周转天数 DPO | 应付账款 / 营业成本 × 天数 | 接近 DSO 更优 | 显著短于 DSO（被压款） |
| 现金转换周期 CCC | DSO + 存货天数 − DPO | 越短越好，理想 <60 天 | >120 天 |
| 利息保障倍数 | EBIT / 利息费用 | ≥3 | <1.5 |
| ROIC | NOPAT / 投入资本 | > WACC | < WACC |
| 固定成本占比 | 固定成本 / 总成本 | 越低越抗周期 | >60% 且订单波动大 |
| 研发费用率 | 研发费用 / 营收 | 制造 ≥3%，科技 ≥10% | <1% 且靠低价竞争 |

> **两套账识别辅助**：毛利率显著低于同行 + 大额其他应收款 + 长期零申报 + 个人卡收付款，需追问并标注风险，不要自行下结论。

## 二、生产/工厂公式库

| 指标 | 公式 | 世界级/优秀 | 一般水平 | 预警 |
|---|---|---|---|---|
| OEE | 时间稼动率 × 性能稼动率 × 良品率 | ≥85% | 60–70% | <50% |
| 时间稼动率 | (负荷时间 − 停机时间) / 负荷时间 | ≥90% | 75–85% | <65% |
| 性能稼动率 | 理论节拍 × 产量 / 实际运转时间 | ≥95% | 80–90% | <70% |
| 产能利用率 | 实际产出 / 设计产能（月） | 80–90% | 60–75% | <50% 或 >100%(超载) |
| 计划达成率 | 实际合格入库 / 计划入库 | ≥98% | 90–95% | <85% |
| 产线平衡率 | 各工位工时和 / (瓶颈工时 × 工位数) | ≥90% | 70–85% | <60% |
| FPY 一次合格率 | 一次通过数 / 投入数（不含返工） | ≥98% | 90–95% | <85% |
| 报废率 | 报废数 / 投入数 | ≤0.5% | 1–3% | >5% |
| Cpk 过程能力 | min[(USL−μ)/3σ, (μ−LSL)/3σ] | ≥1.67 | 1.33–1.67 | <1.0 |
| 客诉 PPM | 不良数 / 交付数 × 10⁶ | ≤100 | 500–2000 | >5000 |
| COPQ 质量成本 | (内部失败 + 外部失败 + 鉴定 + 预防) / 销售额 | <2% | 5–15% | >20% |
| MTBF | 总运转时间 / 故障次数 | 越长越好（按设备类定） | — | 呈下降趋势 |
| MTTR | 总维修时间 / 故障次数 | ≤30min | 1–4h | >8h |
| 计划保养达成率 | 实际完成保养 / 计划保养 | ≥98% | 85–95% | <70% |
| 单位产值能耗 | 综合能耗(tce) / 产值 | 逐年下降 | 持平 | 逐年上升 |
| 材料利用率 | 合格品材料净重 / 投入材料重 | ≥95% | 85–93% | <80% |
| OTIF 准交率 | 按时足量交付订单 / 总订单 | ≥95% | 85–93% | <80% |
| 生产周期 Lead Time | 投料 → 出货自然日 | 越短越好 | — | 增值时间占比 <5% |
| 库存周转天数 | 平均库存 / 日均出库 | 制造 30–60 天 | 60–90 天 | >120 天 |
| 呆滞库存占比 | 呆滞金额 / 总库存 | ≤2% | 3–8% | >15% |
| 账实相符率 | 1 − \|账面−实物\| / 账面 | ≥99.5% | 97–99% | <95% |
| 多能工比例 | 掌握≥3 岗位人数 / 直接人员 | ≥50% | 20–40% | <10% |
| 一线月流失率 | 月离职人数 / 月初在职 | ≤3% | 5–8% | >10% |
| TRIR 可记录伤害率 | 可记录伤害数 × 200000 / 总工时 | ≤0.5 | 1–3 | >5（或瞒报） |

## 三、实算值 → 评分锚定

用实算指标反推维度分时，按以下规则锚定（避免不同 Agent 打出不同分）：

| 实算结果相对基准的位置 | 对应分 |
|---|---|
| 达到「世界级/优秀」 | 5 |
| 达到「一般水平」上限 | 4 |
| 处于「一般水平」中位 | 3 |
| 处于「一般水平」下限但未触发预警 | 2 |
| 触发预警区间 | 1 |

**多指标冲突时**：取该维度内**最低**的实算分，但需在报告中说明是「短板锚定」。

---

## 四、数据不足时的处理

- 关键指标缺失 → 该评分项不给分，标注「数据缺失」，并在报告中列入「需补充采集的数据清单」。
- **禁止用行业平均凑数**顶替缺失数据；缺失本身就是风险信号（尤其能耗、质量成本无计量）。
