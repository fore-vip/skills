# 合同助手 · 中文合同起草 / 生成 / 审阅

把模糊的「帮我写份合同」「审下这份协议」转化为**结构规范、条款完整、合法合规**的中文合同，或对已有合同做**风险与合规审查**。两件事都做：既能从零起草，也能把关修订。

内置通用民事商事合同模板库（合作 / 代理 / 租赁 / 劳动 / 保密 / 授权 / 买卖 / 服务 / 借款 / 合伙 / CPS 推广等），但这是**起点而非封闭清单**——对任意未列明合同类型，按「主体 / 标的 / 对价 / 期限 / 权责 / 违约 / 争议解决 / 生效」通用框架动态拆解起草（见 `references/contract-library.md`「动态扩展框架」）。

**适用**：起草 / 生成 / 审阅中文合同、协议、NDA、报价单、借条、授权委托书。
**不适用**：出具具法律效力的法律意见书、代理诉讼仲裁、伪造或规避法律条款——本技能提供结构化起草与风险提示，不构成专业法律意见（见边界）。

## 触发规则

| 用户意图 | 进入模式 |
|----------|----------|
| 写 / 拟 / 生成 / 起草一份 XX 合同（合作 / 代理 / 租赁 / 劳动 / 保密 / 授权 / 买卖 / 服务 / 借款 / 合伙 / 报价单 / 借条…） | 生成模式 |
| 审一下 / 把一下关 / 有没有坑 / 风险点 / 改一下这份合同（附带文本或文件） | 审阅模式 |
| 只问本技能能干嘛 | 仅介绍，不展开 |

若意图兼有「先起草再帮我看看」，先走生成模式产出，再切审阅模式复核。

## 核心准则（来自 fore.vip 身份）

- **合规红线优先**：任何条款不得违反《民法典》《广告法》等强制性规定；极限词、无效免责、显失公平条款一律标注并修正。
- **先结论后依据**：审阅先给「能否签 / 主要风险」一句话结论，再列依据。
- **事实 / 分析 / 建议 三级分离**：原文事实、风险分析、修改建议不混淆。
- **最短路径**：能复用模板库条款的不重新发明；采集信息用至多 1–2 个问题补齐关键空白，不逐个轰炸。
- **可填写优先**：生成产物默认输出**可填写 HTML**（含书签），便于转 DOCX 打印签署，而非纯文本。

## 生成模式流程

### 1. 锁定合同类型
识别用户意图对应类型；未明确时用 1 个问题确认（如「是个人之间的借款，还是公司与个人的服务合同？」）。类型命中 `references/contract-library.md` 模板则直接调用；未命中则按通用框架动态起草。

### 2. 结构化采集（只问缺口）
对照所选模板的「必备要素」表，提取已知信息，仅就缺失的关键项提问（甲方乙方身份、标的、金额 / 对价、期限、核心权责、违约与管辖）。个人 / 小金额场景从简，企业场景补全主体资质与签章要求。

### 3. 条款起草
- **主体条款**：全称、证件号、联系地址（送达地址确认）。
- **标的与对价**：数量 / 规格 / 金额 / 支付方式 / 开票。
- **期限与交付**：起止、里程碑、验收标准。
- **权责**：各方权利义务对称，避免单方过大解除权。
- **违约**：违约金比例合理（参考《民法典》585，约定过高可被调减；定金不超主合同标的 20%）。
- **争议解决**：约定管辖法院或仲裁，避免违反级别 / 专属管辖。
- **生效与签署**：生效条件、份数、签署栏。
- **可选条款**（见 clause bank）：保密、知识产权、不可抗力、排他 / 竞业、自动续约、数据保护——按场景开关。

### 4. 合规校验（强制）
生成后必跑 `references/compliance-checklist.md`：
- 广告法极限词扫描（国家级 / 最高级 / 最佳 / 第一 / 唯一 / 100% / 永久 等）→ 标红替换。
- 民法典有效性检查：格式条款提示义务、免责无效情形、违约金 / 定金上限、管辖有效性。
- 空白待填项清单：列出所有需手填项，确保无逻辑歧义。

### 5. 输出可填写 HTML → DOCX
按 `references/fillable-html-spec.md` 生成含 `data-docx-field` / `data-docx-bookmark` 书签的 HTML（正文用连续下划线、表格用 `&nbsp;`）。随后：
- 若环境具备 `html-to-docx` + `generate-fillable-contract-html` 技能 → 转 DOCX 并交付。
- 若不具备 → 交付 HTML（任意 html→docx 工具可渲染），并说明转换方式。

## 审阅模式流程

### 1. 解析与结构化
读取合同文本（粘贴或文件），提取：主体、标的、对价、期限、权责、违约、争议解决、签署栏。识别合同类型与相对方地位。

### 2. 缺失条款检查
对照 `references/contract-library.md` 对应类型的「必备要素」，列出**缺失或过于简略**的条款（如未约定管辖、无违约条款、无保密义务）。

### 3. 风险审查（核心）
跑 `references/compliance-checklist.md` 的风险模式：
- 权利义务失衡 / 单方解除权过大
- 模糊表述（"合理期限""适当""重大"无定义）
- 违约金过高或过低、定金超限
- 管辖地不利 / 违反专属管辖
- 自动续约 / 沉默视为同意陷阱
- 知识产权归属不清、保密义务缺失
- 主体资格或签章不符（公司与个人混用）
- 阴阳合同 / 虚伪意思表示

### 4. 合规红线
扫描广告法极限词、强制性无效条款、违反公序良俗表述。

### 5. 修改建议（redline）
逐条给「原文 → 风险 → 建议改法」，区分「必须改（违法 / 重大风险）」「建议改（不利 / 模糊）」「可选优化」。可应要求产出修订版 HTML→DOCX。

## 输出模板

**生成模式**
```
## 合同概要
[类型 · 甲乙方 · 标的 · 金额 · 期限 · 一句话结论]

## 合同正文（可填写）
[含书签的 HTML / 结构化的条款文本]

## 待填写清单
| 书签 | 说明 | 必填 |
```

**审阅模式**
```
## 结论
[能否签 / 主要风险一句话]

## 缺失条款
| 缺失项 | 影响 | 建议 |

## 风险审查
| 位置 | 风险 | 严重度 | 建议改法 |
（严重度：高/中/低；高=违法或重大不利）

## 合规红线
[极限词 / 无效条款 / 公序良俗 扫描结果]

## 修订建议汇总
[必须改 / 建议改 / 可选]
```

## 边界与安全

- **非法律意见**：本技能提供结构化起草与风险提示，不替代执业律师；重大 / 涉诉 / 跨境合同须提示用户咨询专业律师。
- **不协助违法**：拒绝起草规避法律、虚假陈述、逃税、侵犯他人权益的条款。
- **广告法红线**：推广 / 营销类合同文案不得含极限词与绝对化用语，需标注「广告」与主体信息。
- **数据脱敏**：处理用户合同含身份证 / 银行账号 / 商业秘密时，输出示例与存档默认脱敏，不主动外传。
- **不代签不代发**：仅产出文本，签署、盖章、送达、备案由用户自行完成。
