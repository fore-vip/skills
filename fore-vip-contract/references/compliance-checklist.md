# 合规与风险审查清单（Compliance & Risk Checklist）

生成模式**强制**跑一遍（第 4 步），审阅模式**核心**跑一遍（第 3–4 步）。本章是「合法合规」与「风险识别」的硬依据。

---

## 一、广告法极限词（禁用 / 慎用）

《广告法》第九条禁止「国家级、最高级、最佳」等用语；以下为常见**红线词**，合同中（尤其推广/营销/招商条款）出现一律标红替换：

**绝对化/极限词（禁用，除非有客观事实且可证）**
- 国家级、最高级、最佳、第一、唯一、首个、首选、顶级、极品、极致、绝无仅有
- 万能、100%、百分百、永久、永不、永远、根治、包治、立竿见影、瞬间、立即见效
- 王牌、领袖品牌、世界领先、全网销量第一、销量冠军、行业第一
- 史无前例、空前绝后、独家（无依据时）、最/极/第一 等最高级比较级暗示

**慎用（需有依据/限定语境）**
- 「领先」「知名」「优质」「专业」需可佐证；招商中使用「 guaranteed 收益」「稳赚」属违规承诺。

**处理**：标红 → 改为客观可验证表述（如「在 XX 类目中位居前列，依据 XX 报告」）或删除。涉及《广告法》的推广文案须标注「广告」及推广主体。

## 二、民法典要点（起草必查）

| 主题 | 要点 | 违规后果 |
|------|------|----------|
| 格式条款提示义务（496） | 提供方须对免责/限责条款**显著提示并说明**，否则对方可主张不成为合同内容 | 条款不生效 |
| 免责条款无效（506） | 造成对方人身损害、因故意或重大过失造成财产损失的免责约定无效 | 条款无效 |
| 违约金过高（585） | 约定违约金过分高于损失（一般以超损失 30% 为参考）当事人可请求法院/仲裁调减 | 可被调减 |
| 定金规则（586/587） | 定金不超主合同标的额 **20%**；给付方违约无权返还，收受方违约双倍返还 | 超额部分不支持 |
| 显失公平（151） | 一方利用对方危困/缺乏判断致权利义务明显失衡，受损害方可撤销 | 可撤销 |
| 管辖约定（34/级别/专属） | 可协议选择与争议有实际联系地点的法院；不得违反级别管辖和专属管辖（如不动产纠纷由不动产所在地） | 约定无效 |
| 阴阳合同 | 以虚假意思表示订立的条款无效；以合法外壳掩盖非法目的的可撤销/无效 | 无效/可撤销 |
| 劳动合同法定责任 | 不得免除用人单位法定责任、排除劳动者权利（如「工伤概不负责」） | 条款无效 |
| 利息保护上限 | 民间借贷利率不得超过合同成立时一年期 LPR 四倍 | 超额不受保护 |

## 三、审阅风险模式（Risk Patterns）

审阅合同文本时，逐条扫描以下模式，命中即记入「风险审查」表：

1. **权利义务失衡**：一方义务明显重于权利，或单方享有任意解除/修改权。
2. **模糊表述无定义**：「合理期限」「适当」「重大」「必要时」等无量化标准，易生争议 → 要求定义或量化。
3. **违约金畸高/畸低**：明显高于损失 30% 或远低于实际损害 → 提示可调减/补足。
4. **定金超 20%**：提示超额部分无效。
5. **管辖地不利**：约定在对方所在地或偏远法院/不利仲裁 → 提示改为中立或己方所在地。
6. **自动续约 / 沉默视为同意**：未书面通知即续约、沉默视为承诺 → 高亮，建议改为「需双方书面确认续约」。
7. **知识产权归属不清**：未约定交付物 IP 归属、背景 IP 混同 → 明确划分。
8. **保密义务缺失/过宽**：应保密未约定，或保密范围无限扩大 → 补保密条款/限定范围。
9. **主体/签章不符**：公司与个人混用、盖章与名称不一致、无授权代表 → 核主体资格。
10. **阴阳合同 / 虚伪意思**：明暗两套价格/条件 → 提示无效风险。
11. **空白待填项过多**：大量未填项可能事后被单方补填不利内容 → 列清单并要求签署前填妥。
12. **责任排除过宽**：「任何情况下不承担责任」「概不退还」等 → 提示可能无效。

## 四、redline 严重度分级

| 严重度 | 定义 | 处理 |
|--------|------|------|
| **高** | 违法（违反强制性规定）、重大不利、条款可能无效/可撤销 | 必须改，否则不建议签署 |
| **中** | 权利义务不利、模糊易争议、管辖/违约不利 | 建议改 |
| **低** | 表述优化、可增强严谨性 | 可选 |

输出「修订建议汇总」时按此三级分组，让用户一眼看清「必须改 / 建议改 / 可选」。
