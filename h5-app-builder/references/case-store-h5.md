## 从这个实例抽象出的通用做法（已固化进本 SKILL）

1. **需求缺失时的处理顺序**：查详情 → 全库检索 → 资产库 → 历史对话 → 仍无则一次性结构化确认，并把结论写成事实源。→ `SKILL.md` P0
2. **形态决策要先判云服务**，纯前端原型的结论要主动告知，不能默默略过。→ P1 / `references/cloud-service.md`
3. **页面与数据分离**：演示数据集中在一处配置，换业务只改配置不改结构。→ `templates/app.spec.json` + `scripts/build_app.py`
4. **合法落位**：站点模板允许「第二个样式块 + 主脚本之前的独立脚本 + 扩展 TAB」，这样能加交互而不破坏一致性检查。→ 独立应用里改为自带骨架，不依赖任何站点模板。
5. **验证要证据化**：真实视口交互断言 + 截图目视，不能只截图。→ `scripts/verify_viewport.mjs`
6. **上线状态如实**：预演 ≠ 发布，对外动作等明确指令。→ P5
