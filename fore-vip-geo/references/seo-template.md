# SEO 信息收集模板 · 问句库

> 用途：第 1 步构造检索问句、第 3 步一次性收集补充信息。对照用户已提供的信息，只列出缺失项。

## 一、检索问句库（第 1 步摸底用）

以真实用户视角构造，覆盖四类问句，每类 1–2 条：

| 问句类型 | 模板 | 作用 |
|----------|------|------|
| 评价型 | 「{产品} 怎么样」「{产品} 值得买吗」「{产品} 靠谱吗」 | 触发口碑类引用源 |
| 对比型 | 「{产品} 和 {竞品} 哪个好」「{品类} 排行榜前十」 | 触发测评/榜单类引用源 |
| 导航型 | 「{产品} 官网」「{产品} 入口」「{品牌} 是什么」 | 触发百科/官方类引用源 |
| 场景型 | 「{场景/人群} 用什么{品类}」「{痛点} 怎么解决」 | 触发攻略/推荐类引用源 |

竞品未给定时，先联网检索品类头部品牌，取 2–3 个作为对比对象。

## 二、SEO 信息收集模板（第 3 步用）

### 1. 基本信息

- 产品/品牌名称（含别名、英文名、常见错写）
- 一句话定位（是什么、给谁、解决什么）
- 官网 / 店铺 / 下载地址
- 所属类目与价格区间

### 2. 关键词

- 核心词：1–3 个（品类大词）
- 长尾词：3–8 个（场景词、人群词、痛点词）
- 竞品对比词：与哪些竞品绑定对比（借竞品流量）
- 品牌保护词：品牌+品类、品牌+怎么样（防竞品占位）

### 3. 目标人群

- 画像：年龄 / 职业 / 预算 / 决策习惯
- 决策链：谁搜索、谁决策、谁付款（可能不是同一人）
- 常出没平台（影响阵地选择）

### 4. 卖点与差异化

- 3–5 个核心卖点，每个附**证据**（数据/对比/案例）
- 与竞品的关键差异 1–2 条（内容发力点）
- 用户常见顾虑与回应（转化为 FAQ）

### 5. 信任背书

- 资质 / 认证 / 检测报告
- 销量 / 用户量 / 口碑数据（标注口径与时间）
- 案例、KOL/媒体提及

### 6. 行动号召 CTA

- 想让用户做什么：搜什么词 / 进什么店 / 关注什么号
- 各平台 CTA 形式不同（公众号可导私域，小红书只能软引导）

### 7. 合规红线

- 广告法禁用词排查（最/第一/顶级/国家级/根治…）
- 行业限制：医疗、金融、保健、教育等需资质或禁推广的表述
- 平台特定敏感点（如小红书导流限制、公众号诱导分享限制）
- 需要标注的广告/利益关系声明

### 8. 内容资产

- 已有文章 / 素材 / 评价截图可复用的部分
- 可出镜的人设/账号（影响内容形式）

## 三、收集话术规范

- 一次性把缺失项列成**清单**发给用户，允许「跳过」并注明缺省处理方式。
- 用户不提供的关键项，标注「按公开信息推断」，不编造。
- 用户丢来资料链接时，联网抓取后自动填充模板，只追问真正缺失的硬项（关键词、卖点、CTA）。
