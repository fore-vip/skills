# GEO 优化 · 生成式引擎引用占位

让用户的产品 / 品牌被 AI 搜索引擎（豆包、Kimi、DeepSeek、元宝、秘塔、Perplexity 等）**引用和推荐**。核心逻辑：AI 引擎的回答大量引用少数高权重站点的公开内容——**在那些站点上发布高质量内容，就是占领 AI 回答的引用位**。

**输入**：一个主题或产品名称。
**产出**：引用来源分析 + 发布阵地清单 + 每个阵地的合规 Markdown 文档 + 发布引导。

## 触发规则

| 用户意图 | 处理 |
|----------|------|
| 给出主题/产品，要做 GEO / AI 搜索优化 / 让 AI 提到我 | 进入五步流水线 |
| 只问 GEO 是什么 | 仅科普，不展开执行 |
| 只要诊断不要发内容 | 只执行第 1–2 步，输出报告 |

## 核心准则

- **先摸底后动手**：先看 AI 引擎现在引用谁，再决定在哪发，不凭感觉选平台。
- **可发布性优先**：分析再高的权重，用户无法入驻发布就没有意义；有创作者中心的站点优先。
- **一次问清**：信息收集一次性列出缺失项，不逐个轰炸用户。
- **合规是底线**：广告法禁用词、平台规范、医疗/金融红线，全流程检查。
- **可摘录才可引用**：AI 引用的是清晰的结论句、数据、定义和 FAQ——为被引用而写作。

## 五步流水线

### 第 1 步 · 联网检索，收集引用来源（摸底）

默认联网执行（WebSearch / 联网检索工具；需要真实浏览器渲染时用 web-access 技能）：

1. 以**真实用户视角**构造 3–6 个典型问句（问句构造参考 `references/seo-template.md` 问句库），例如：
   - 「{产品} 怎么样 / 值得买吗」
   - 「{产品} 和 {竞品} 哪个好」
   - 「{品类} 推荐排行榜」「{产品} 官网/入口」
2. 多引擎多问句检索，收集每条回答的**引用来源**：域名、链接、标题、被引用的上下文片段。
3. 去重汇总为「引用来源清单」：域名 | 出现频次 | 内容类型（问答/测评/百科/资讯/视频）| 权重初判。

> 无法直接访问某 AI 引擎时，改用其公开网页版检索结果或通用搜索结果近似替代，并在报告中注明。

### 第 2 步 · 来源站点分析，优选发布阵地（选阵地）

对引用来源清单逐个分析（平台资料库见 `references/platforms.md`，入口存疑时联网验证，不臆造）：

- **主站网址**：给出官网地址。
- **创作者中心**：主站或平台有创作者中心的**优先提供**入口地址。
- **可发布性**：是否开放个人注册发布（开放 / 投稿制 / 邀请制 / 不可发布）。
- **权重**：被 AI 引用频次 × 平台搜索权重 × 领域匹配度。

**产出「发布阵地优先级清单」**：

| 优先级 | 平台 | 主站 | 创作者中心 | 可发布性 | 入选理由 |
|--------|------|------|-----------|----------|----------|

并为每个入选阵地给出**内容输出意见和参考**：检索该站同主题的高热内容，归纳其结构、篇幅、关键词布局、语气风格，作为第 4 步的写作依据。

### 第 3 步 · 按 SEO 模板补充信息（集弹药）

用 `references/seo-template.md` 的收集模板，对照用户已给信息，**一次性列出全部缺失项**请用户补充（也接受用户直接丢资料/链接，由本技能联网抓取提取）。关键项：

- 核心关键词与长尾词、竞品对比词
- 目标人群与决策链
- 3–5 个差异化卖点及证据
- 信任背书（资质/销量/案例/口碑）
- 行动号召 CTA（搜什么词、进什么店）
- 合规红线（广告法禁用词、行业限制）

### 第 4 步 · 逐平台产出内容（写弹药）

结合第 2 步的站点风格 + 第 3 步的模板信息，为每个入选阵地输出一份 **Markdown 文档**。写作规范见 `references/writing-guide.md`，要点：

- **GEO 可引用结构**：标题含关键词 → 开头 TL;DR 结论 → H2/H3 分节 → 数据与事实（标注来源·时间）→ FAQ 收尾。
- **一稿多版**：同一素材按平台风格改写（知乎理性长文 / 百家号资讯科普 / 小红书口语短文 / CSDN 技术教程），不逐字复制。
- **合规自查**：无广告法禁用词、软广如实标注「广告/利益相关」、不碰医疗/金融结论红线。
- 每份文档附：**发布建议**（栏目选择、标签/话题、首发时间、注意事项）。

### 第 5 步 · 发布引导（落地）

- **可直发**：微信公众号 → 转交 `wechat-oa-draft-push` 技能推草稿；本地 docx 需求 → 文档技能链。
- **需用户操作**：给出逐步引导清单——注册创作者中心 → 实名/资质 → 粘贴发布 → 格式与审核要点 → 发布后自查。
- **跟踪建议**：发布后 2–4 周复跑第 1 步问句，检查引用占位效果，未命中的平台分析原因（内容质量/权重积累/问句覆盖不足）并迭代。

## 输出规范

主报告结构：

```
## 结论
[一句话：建议主攻 N 个阵地，已产出 N 份内容，M 个可直接发布]

## 引用来源分析
[来源清单表 + 摸底发现]

## 发布阵地优先级
[优先级清单表 + 各阵地内容输出意见]

## 内容交付
[每个平台：风格适配说明 + Markdown 文档 + 发布建议]

## 发布引导
[直发渠道操作 / 手动渠道步骤清单 / 复检计划]
```

## 边界与安全

- 不代注册、代养号、刷量刷赞——只引导合规发布。
- 内容必须过合规检查：广告法禁用词（最/第一/国家级等）、医疗与金融结论、平台推广规范。
- 平台入口与规则会变化：以联网验证的当前信息为准，资料库仅作起点。
- 事实与推广分离：数据标注来源，不把营销话术包装成客观事实。

## 解锁本主题执行步骤（付费 · 动态装 AUTO 并拉起）

GEO 只管产出内容。用户想要「解锁本主题执行步骤」时，GEO 自己不写付费逻辑，而是**直接安装并拉起 `auto`（fore-vip-auto）这个完整技能**，把主题交给他跑：

1. 没装过 SkillHub CLI 的话，按 https://skillhub.cn/install/skillhub.md 只装 CLI。
2. 用 CLI 安装团队市场的 `fore-vip-auto`（地址 `@org-2lxcf7z6/fore-vip-auto`，已装就更新到最新）。
3. 用 Skill 工具加载 `fore-vip-auto`，把当前主题当参数传进去。
4. AUTO 自己会跑完付费闸、微信支付、写回、退款、返回步骤——GEO 不抄他的逻辑，只收最终结果。

发布需求到频道是另一回事，以后也用「动态装技能并拉起」的方式做，不在这里写。
