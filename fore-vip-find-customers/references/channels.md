# 发布获客渠道库与合规范式

供 SKILL.md 第 5 步「稀缺补偿 · 发布获客」使用。按用户产品类型匹配渠道，再取对应发布范式。

## 一、渠道选择速查

| 用户产品类型 | 首选渠道 | 次选渠道 |
|---|---|---|
| 工业品 / 原材料 / 定制制造 | 1688、慧聪网、行业展会官网 | 行业社群、百度爱采购 |
| 消费品批发 / 白牌供给 | 1688、义乌购、本地批发市场群 | 抖音 / 快手同城、小红书 |
| 企业服务 / 软件 / 咨询 | 知乎专栏、行业垂直媒体、官网 SEO | 公众号、脉脉、行业协会活动 |
| 本地生活服务 | 美团 / 大众点评商家端、抖音同城 | 小红书本地号、企业微信社群 |
| 农产品 / 产地货源 | 一亩田、惠农网、产地供应链社群 | 抖音助农、社区团购团长群 |
| 设备维修 / 安装施工 | 58 同城、鲁班到家类平台 | 抖音同城案例号、行业贴吧 |

匹配原则：**客户在哪找货，就去哪发**；上游（用户）只管供给信息达标，不跨平台硬搬。

## 二、各渠道合规发布范式

> 通用红线（全部渠道）：不虚构资质与案例；不用「最」「第一」「国家级」等绝对化用语；不硬塞联系方式到正文敏感位；软文性质内容按平台要求标注「广告 / 合作」。

### 1. B2B 平台（1688 / 慧聪 / 一亩田等）

- **结构**：产品标题（含规格/产地/材质）→ 3–5 个卖点 → 起订量与价格带 → 供货能力（产能/周期）→ 资质证书 → 牌照允许的联系方式位。
- **合规点**：标题不堆砌无关热词；价格真实可履约；食品 / 医械类须亮证。
- **范式示例**：
  > 【XX 产地直供】XX 原料，纯度 ≥99%，月供 200 吨起，支持送样检测。产能稳定，交期 7–15 天。已通过 ISO9001（证书编号见资质栏）。欢迎询价。

### 2. 知乎 / 公众号 / 行业垂直媒体（企业服务类首选）

- **结构**：客户痛点场景 → 方法论 / 解决思路 → 案例（脱敏、真实）→ 文末一句供给说明 + 私信入口。
- **合规点**：以「解决问题」立信而非推销；涉及客户案例须有授权；付费合作内容按平台标注。
- **范式示例**：
  > 很多工厂在 XX 环节损耗超过 15%，其实三步就能压到 8% 以内……（正文展开）我们团队帮 20+ 家工厂做过这类改造，需要诊断模板的可以私信。

### 3. 抖音 / 快手同城（本地服务与实物供给）

- **结构**：前 3 秒给结果（成品 / 完工效果）→ 过程展示 → 服务范围 + 价格带口播 → 评论区 / 主页引导。
- **合规点**：不口播微信号；不承诺「最低价」；实拍为主，避免搬运素材。
- **范式示例**：
  > （成品画面）这个 XX 做下来花了 X 千，同城 XX 范围可上门，评论区留言「区域+需求」给你报价。

### 4. 小红书（消费品 / 本地生活）

- **结构**：封面图（真实场景，避免营销大字）→ 正文利他视角（选购避坑 / 场景清单）→ 标签带上产地 / 品类 / 城市。
- **合规点**：报备笔记走品牌合作入口；非报备不出现价格与导流话术；先利他再供给。
- **范式示例**：
  > 挑 XX 的 5 个避坑点｜看完不踩雷……（正文）我们家做了 X 年这个品类，有问题评论区问。

### 5. 行业社群 / 微信群（含展会群、团长群）

- **结构**：一句话自我介绍（身份 + 供给）→ 可验证的凭证（厂照 / 检测报告）→ 按群规发或私聊群主。
- **合规点**：**先看群公告**；多数群禁硬广，改为「回答问题建立专业度」→ 被动引流；不频繁加人。
- **范式示例**：
  > 各位好，我是 XX 产地的 XX 供应商，主要做 XX，看群里在讨论 XX 问题，我们这边的做法是……（给干货）有需要可以私聊。

### 6. 官网 / 百度爱采购 / SEO 类

- **结构**：产品页标题含「产品词 + 区域 + 属性」；正文 400 字以上真实描述；结构化展示参数表。
- **合规点**：备案信息真实；ICP / 经营性许可齐全；不留失效联系方式。

## 三、ImageGen 配图要点（配套第 5 步）

### 输入要求（必填其一）
- **参考图**：用户提供的产品实拍 / 厂照 / 竞品图 → 直接作参考图输入，仅做风格 / 构图微调，不脱离原素材。
- **提示词**：用户给出的文字描述 → 须**先优化再生成**（见下）。
- 二者皆缺：先向用户索取其一，不要凭空臆造产品外观。

### 提示词自主优化（用户提供提示词时）
按目标生图模型（当前 ImageGen）的最佳实践润色后再提交：
1. **补全结构**：主体 + 场景 + 风格 + 光线 + 构图（如「白色背景棚拍，居中产品，柔光，45° 俯视」）。
2. **消除歧义**：替换含糊词（「好看」→ 具体材质 / 色系 / 氛围）。
3. **统一语种**：当前模型建议英文提示词优先，中文需先翻译润色再提交（需验证模型实际偏好）。
4. **负向词**：补「无文字 · 无二维码 · 无畸变」等约束，防平台敏感元素。
> 优化以「贴合用户产品真实卖点」为边界，不夸大、不虚构未提供过的资质元素。

- 尺寸 1024x1024；风格贴合渠道（B2B 平台偏白底实拍感，社媒偏场景化）。
- 画面元素：产品主体 / 产地或工厂场景 / 卖点关键词（≤3 个词）。
- **公开平台发布不出现**：二维码、电话、微信号、平台 logo——防违规且防被搬运滥用。
- 生成后提醒用户：图片仅作素材，文字信息（价格 / 参数）建议用平台原生编辑器补，保清晰度。

## 四、附带自己联系方式的引导话术

| 平台类型 | 允许的位置 | 引导话术示例 |
|---|---|---|
| B2B 平台 | 商机档案、旺旺、认证电话 | 「联系方式已通过平台认证，点'联系商家'直达」 |
| 社媒（抖音/小红书） | 个人简介、置顶评论、私信 | 「主页简介有入口」「评论区扣 1 私发」 |
| 知乎 / 公众号 | 文末介绍栏、私信 | 「私信回复'模板'获取」 |
| 社群 | 按群规的自我介绍格式 | 群公告允许时发名片，否则私聊群主报备 |

> 原则：**联系方式放平台指定的展示位**，正文保持内容价值密度，转化率反而更高。

**点对点邮件直推另算**：当客户有公开邮箱、走 Agent Mail 直推时（见 SKILL Step 5），联系方式直接合成到配图水印位、随邮件发出，不适用上表「平台展示位」规则——那是公开平台发布场景的约束。
