# 学习成长路线（缺口补强）

供 `fore-vip-career-starter` 在「条件未达标」步骤加载。当用户与目标岗位存在硬缺口时，输出「差距清单 → 分阶段路线 → 达标目标」。

## 一、通用路线框架

对每个缺口项，按以下结构给路线：

```
缺口项：[如「缺数据分析实操经验」]
阶段1（0–1 月）：免费资源打基础
  - 资源：freeCodeCamp / 哔哩哔哩 / 官方文档 / 慕课网（免费区）
  - 里程碑：完成 X 入门课，产出 1 个小练习
阶段2（1–3 月）：做可证明的项目
  - 资源：Kaggle 入门赛 / 开源项目 / 课程大作业升级
  - 里程碑：1 个可写进简历的项目（带链接/截图）
阶段3（3–6 月）：对标岗位要求
  - 资源：岗位 JD 反向补技能 / 考 1 张低成本证书（如必要）
  - 里程碑：达到「熟悉」级，可投初级岗
达标后可投：[岗位名 + 平台]
```

**资源优先级**：免费/低成本优先（官方文档、B 站、freeCodeCamp、Coursera 审计模式、Kaggle、GitHub 开源）→ 再考虑付费系统课。

## 二、常见岗位缺口 → 起点动作（示例种子）

| 目标岗位 | 常见缺口 | 起点动作 |
|----------|----------|----------|
| 前端开发 | 框架/项目经验 | 跟做 1 个 React/Vue 项目，部署到 GitHub Pages |
| 数据分析 | SQL/可视化 | 学 SQL + Tableau/BI，做 1 份公开数据集分析报告 |
| 新媒体运营 | 作品/数据感 | 起一个垂类账号，跑通「选题→发布→复盘」闭环 |
| 电商运营 | 平台规则/实战 | 开个人店或代运营练习，记录 GMV/转化数据 |
| UI 设计 | 作品集 | 做 2–3 套完整界面稿，上站酷/Behance |
| 测试工程师 | 用例/工具 | 学 Postman + 自动化入门，写 1 份测试报告 |
| 行政/人事 | 流程熟悉 | 梳理 1 份招聘/入职 SOP，体现组织力 |

> 上表为种子示例，实际路线需结合用户学历/特长/时间生成，并优先引用免费资源。

## 三、诚实边界

- 不承诺「学完必上岸」；只给可验证的里程碑与可达成的下一步。
- 缺口过大（如学历硬性不符）时，明确告知并引导至「其它可行路径」（alt-paths.md）或考证/升本等合规通道。
