# 简历模板与轮询优化指南

供 `fore-vip-career-starter` 在「简历生成」步骤加载。面向低经验 / 应届生，强调**从零起步、逐项填充、轮询优化**。

## 一、简历骨架（标准模块）

```markdown
# 姓名
电话 · 邮箱 · 所在城市 · [可选] 个人主页/作品集链接

## 求职意向
目标岗位 · 期望城市 · 到岗时间

## 教育背景
[学校] · [专业] · [学历] · [起止时间]
- GPA / 排名（若亮眼）
- 核心课程（3–5 门与岗位相关）
- 荣誉（奖学金 / 竞赛等，1–3 条）

## 专业技能
- 按岗位相关性分组（如：编程语言 / 设计工具 / 语言能力）
- 标注熟练度（了解 / 熟悉 / 熟练），不夸大

## 项目经历（含课程/比赛/自学项目）
**[项目名称]** · 角色 · 时间
- 用「动词 + 做了什么 + 怎么做 + 结果」句式
- 尽量量化（数量 / 比例 / 时长 / 规模）

## 实践 / 实习 / 社团
**[组织/公司]** · [角色] · [时间]
- 负责事项与产出，优先量化

## 校园 / 其他经历（可选）
- 志愿、兼职、兴趣特长中能体现软技能的部分

## 自我评价（1–3 行，紧扣岗位）
- 用事实支撑，避免「认真负责、吃苦耐劳」等空话
```

> 低经验者结构顺序：**教育 → 项目/实践 → 技能 → 其他**。把最亮的部分放最前。

## 二、逐项轮询优化要点

每填一项，给 1 条建议。通用原则：

| 模块 | 轮询优化关注点 |
|------|----------------|
| 教育 | 课程只留与岗位相关的；GPA 不亮眼可不写，写排名/荣誉替代 |
| 技能 | 删「了解」级且无证据的项；按岗位重排熟练度 |
| 项目 | 补动词开头 + 量化结果；无结果则写「学到了/实现了 X」 |
| 实践 | 把职责改写成「动作 + 影响」；社团也能体现协作/组织力 |
| 自我评价 | 删空话，改「用 X 证明我能做 Y」 |

### 量化与动词库（给用户的填空素材）
- **动词**：搭建 / 优化 / 设计 / 主导 / 协调 / 分析 / 增长 / 还原 / 输出 / 推动。
- **量化维度**：用户量、转化率、节省时长、覆盖人数、排名百分比、金额、版本/迭代次数。
- **没数据怎么办**：写「从 0 到 1 完成」「覆盖 X 人」「较之前提升」（有依据才写）。

### 低经验特化
- 无实习：用课程大作业、比赛、自学项目、开源贡献填补「项目经历」。
- 无技能证书：写「正在学 / 计划 X 月达成」，并接学习路线（见 learning-roadmaps.md）。
- 转行：用「可迁移能力」桥接（如销售→运营的客户沟通，行政→项目助理的协调）。

## 三、输出格式说明

| 格式 | 生成方式 | 备注 |
|------|----------|------|
| html | 直接产出带内联 CSS 的可预览 HTML | 默认；可打印为 PDF；可上传资料库 |
| doc | 引导「资料库」技能创建在线文档 | 便于二次编辑与分享 |
| pdf | html → 浏览器「打印 → 另存为 PDF」；或资料库/腾讯文档导出 | 投递最稳妥格式 |

**上传与链接**：用户确认内容后，引导用「资料库」技能上传简历成品，生成可分享链接；**只传成品，不传原始个人档案**。
