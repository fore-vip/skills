# 其它可行路径（备选规划）

供 `fore-vip-career-starter` 在「多手准备 / 求职受阻」步骤加载。每条给：**适合谁 + 起点动作 + 风险提示**。

## 一、路径清单

| 路径 | 适合谁 | 起点动作 | 风险提示 |
|------|--------|----------|----------|
| 考研 / 升学 | 专业需更高学历、想换赛道 | 选专业/院校，看往年分数线，定复习计划 | 时间成本高，非「逃避就业」的解法 |
| 考公 / 考编 | 求稳定、适配专业 | 看国考/省考公告，刷行测申论 | 竞争大，需长期备考 |
| 技能培训 + 认证 | 缺口明确、可短期补齐 | 选 1 项硬技能课 + 证书（如数据分析/设计） | 警惕「包就业」机构与培训贷 |
| 学徒 / 实习转正 | 重实操、愿意从底做起 | 找带教岗位/实习，积累背书 | 起薪低，确认是否有转正通道 |
| 自由职业 / 接单 | 有一技之长、自驱力强 | 上猪八戒/Upwork 接小单，攒作品与评价 | 收入不稳定，需自我管理 |
| 公益 / 志愿 | 过渡期、积累经历 | 加公益组织/志愿项目，补实践空白 | 非收入来源，作履历补充 |
| 小成本创业 | 有产品/服务想法 | 先验证需求（朋友圈/社群试水）再投入 | 现金流风险，先副业后全职 |
| 出海 / 远程 | 英文或可学、时差耐受 | 优化英文简历，上 RemoteOK/Upwork | 需自管税务与合同，防诈骗 |
| 技能证书补短板 | 岗位硬性要求证书 | 报官方/正规考点，拿到即投 | 确认证书被目标行业认可 |

## 二、使用方式

- 与「岗位推荐 + 学习路线」并列给用户，作为** Plan B/C**，不打压主路径。
- 每条只给「下一步最小动作」，不展开长篇规划；用户感兴趣再深入。
- 涉及考证/培训时，主动提示防骗（联动「反诈助手」），拒绝任何「先交费/押金」方案。
