# 精度损失 · 预测、复验与补偿

任务设定里最容易被跳过的一步：**在动手前说清楚会丢什么**。这份文档给判定口径、常见矩阵、模板和补偿动作。

## 一、三维损失模型

逐维比对源格式与目标格式的**表达力上限**，不是比对文件能不能打开。

| 维度 | 检查项 |
|---|---|
| 内容 | 正文、公式、脚注、批注、修订、超链接、隐藏文字、 speaker notes、字幕轨、图层 |
| 结构 | 分页与页眉页脚、合并单元格、多工作表、目录层级、母版、时间轴与多轨、动画、透明度 |
| 元数据 | EXIF、色彩配置、作者与创建时间、书签、字体嵌入、文档属性、标签、ICC |

一句话判据：**目标格式无法表达的东西，一定丢；目标格式能表达但工具没映射的，可能丢。** 前者改工具没用，只能换目标格式或做补偿；后者可以换工具、加参数或重建。

## 二、L0–L3 判定

| 级 | 含义 | 处理 |
|---|---|---|
| L0 | 本次复验口径下未发现差异 | 直接转，回执简要带过；不宣称「无损」 |
| L1 | 轻微，可自动补偿（如元数据、编码、命名） | 直接转，回执列出补偿项 |
| L2 | 明显，可部分补偿（如版式、合并单元格） | **转换前**出预测卡并告知注意点 |
| L3 | 不可逆或影响语义（如多表并成单表、公式变文本、修订记录消失） | **须用户明确确认或改选目标格式**；坚持转换时回执标注「已知不可逆损失」 |

判定落在最高那一维：内容丢了就按内容定级，不因结构完好就降级。

## 三、常见格式对损失矩阵

用作起点，**不替代实测**；同类工具版本不同表现会变。

| 源 → 目标 | 典型损失 | 级 | 常见补偿 |
|---|---|---|---|
| `.docx` → `.md` / `.txt` | 分页、页眉页脚、合并单元格、批注修订、嵌入字体、复杂表格 | L2 | 图片外挂、表格另存 CSV、侧车清单 |
| `.docx` → `.pdf` | 可编辑性、部分域与批注；字体替换可能改版式 | L1 | 保留源文件、嵌入字体、复验页数 |
| `.xlsx` → `.csv` | **只保留活动工作表**、公式变值、格式与图表消失、多表丢失 | L3 | 每表一个 CSV，或改 `.xlsx` → `.json` / `.xlsx` |
| `.xlsx` → `.pdf` | 交互性、筛选、公式；打印区域外的列可能被截 | L2 | 设打印区域、分页预览复验 |
| `.pptx` → `.pdf` | 动画、切换、演讲者备注、可编辑性 | L2 | 备注另存文本、复验页数与字体 |
| `.pptx` → `.md` | 版式、图形关系、备注（部分工具不读）、SmartArt | L2–L3 | 逐页导出图片 + 文字稿双轨 |
| `.pdf` → `.docx` / `.md` | 扫描件需 OCR、栏序错乱、表格结构破碎、字体丢失 | L2–L3 | OCR 后人工校栏序、保留原 PDF 双轨 |
| `.pdf` → 图片 | 可选文字、链接、书签、矢量缩放能力 | L2 | 提高 DPI、保留原 PDF |
| `.md` / `.html` → `.pdf` | 样式由外部样式表决定，与源观感无对应关系 | L1–L2 | 指定样式模板、复验分页与代码块 |
| `.html` → `.md` | 脚本、内联样式、复杂表格、iframe | L2 | 表格另存、链接清单 |
| 图片 有损 → 无损（`.jpg` → `.png`） | 无新增损失，但**已丢弃信息不会回来**，体积虚增 | L0–L1 | 说明「换壳不回血」，按用途决定是否值得 |
| `.png` → `.jpg` | 透明度、无损细节、部分元数据 | L2 | 需要透明就改 WebP / PNG |
| 图片 → `.webp`（有损） | 细节、EXIF、色彩配置 | L1–L2 | 调质量参数、元数据回填 |
| 音视频 → 另一编码 | 有损转码的代际损失、多轨与字幕、章节、HDR | L2 | 用流拷贝（不改编码）或保留源文件 |
| 视频 → GIF | 色彩位深、帧率、音轨、体积膨胀 | L3 | 改短片段 / 用 APNG / WebM |
| `.epub` → `.txt` | 链接、图片引用、章节结构（取决于工具参数） | L2 | 显式开启保留链接与图片引用 |
| 多文件 → 单文件 | 文件边界、命名信息、原始顺序 | L2 | 生成清单文件、目录结构映射 |

## 四、精度预测卡模板

```
源 → 目标：<path> → <path>
损失等级：L?（<一句话结论>）
会丢失：<按内容 / 结构 / 元数据分组列>
原因：<目标格式表达力上限 / 工具映射缺口>
可逆性：<可逆 / 部分可逆 / 不可逆，是否保留源文件>
补偿方案：<对应补偿动作，最多三项>
备选目标：<能承载这些信息的其他格式>
确认：<L0/L1 免确认；L2 知晓即可；L3 须明确确认>
```

预测卡在**批量试转样本之前**给出，让用户有机会改目标格式，别等全批转完才说。

## 五、复验清单（按格式族选，逐项实测）

| 族 | 必查 |
|---|---|
| 文档 / 演示 | 可打开、页数、段落数、字数、标题层级、图片数、字体是否替换、页眉页脚 |
| 表格 | 工作表数、行列数、公式是否变值、合并单元格、数字与日期格式、编码 |
| 图片 | 尺寸、模式（是否丢透明度）、色彩配置、EXIF、体积合理性 |
| 音视频 | 时长、分辨率、帧率、编码、音轨与字幕轨数量、可播放 |
| 文本 / 数据 | 编码、BOM、行尾符、记录条数、字段数、特殊字符与换行、首尾完整性 |
| 通用 | 体积不是 0 B、不是占位页、扩展名与真实格式一致、输出路径与 S3 一致 |

计数一律从产物实算，不照抄源文件数字，也不估算。

## 六、补偿方案库

按「先能自动补，再列人工项」的顺序执行，落地后复跑复验。

1. **侧车清单**：同目录 `<stem>.loss.md`，逐条记录丢失项、原始位置、是否可恢复。
2. **双轨输出**：保真版（PDF / 原图 / 源文件副本）+ 可编辑版（DOCX / MD / CSV），各自标注用途，不让用户猜哪个能改。
3. **资源外挂**：图片、媒体、附件单独导出到子目录，正文改相对路径引用；同时给一份资源清单。
4. **元数据回填**：作者、创建时间、EXIF、书签、超链接、语言标记，在目标格式支持的范围内写回。
5. **结构重建**：表格、脚注、目录、多轨时间轴在目标格式里重建等价表达；重建不出来的，说明上限在哪。
6. **改选目标格式**：损失来自目标格式表达力上限时，回 F2 换一个能承载的格式重转（典型：`xlsx → csv` 丢多表，改「每表一个 CSV」或 `xlsx → json`）。

无法自动补偿的项写入「需人工复核清单」，指明文件名、位置、需要人做什么，不用「建议检查」这类空话。

## 七、措辞规范

- 不写「无损」「完美保真」「完全一致」，L0 只表述为「本次复验口径下未发现差异」。
- 不把「已生成」写成「已验证」；未跑的校验项明确标「未校验」。
- 不夸大工具能力；社区工具的表现以本次实测为准。
- 广告法敏感词（最 / 第一 / 保证 / 独家等）不用于描述转换质量。
