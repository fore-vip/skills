# 收参 · 批量与云文件处理

F0 的目标：一次问清，不让用户被追问五六轮。用选项化提问给默认值，让用户一键确认或改。

## 一、字段表

| 字段 | 问法 | 必问 | 默认值 | 备注 |
|---|---|---|---|---|
| S1 源文件 | 「要转哪些文件？给我路径、目录或云文件链接」 | 是 | — | 可混合多个来源，先汇总成一张清单 |
| S2 目标格式 | 「转成什么格式？可以选多个」 | 是 | — | 多个时按「一进多出」逐个执行，输出文件名带格式标识 |
| S3 输出位置 | 「放哪儿？默认和源文件同目录」 | 否 | 源目录 | 目录不存在时先创建并告知 |
| S4 批量范围 | 「整个目录递归转，还是只转当前层？要不要按后缀过滤」 | 否 | 单文件 / 当前层 | 见第三节 |
| S5 云文件去向 | 「转完要不要传回去？」 | 否 | 仅落本地 | 见第四节 |
| S6 优先取向 | 「更看重保真、体积，还是后续可编辑？」 | 否 | 保真 | 影响 F3 选路与有损参数 |

同时问一句**用途**（打印 / 归档 / 继续编辑 / 网页发布 / 喂给模型），用途往往比目标格式更能暴露真实需求：用户说「Word 转 PDF」但目的是继续编辑时，应提示改选 DOCX 或 ODT。

## 二、命名与冲突

- 单目标：`<stem>.<ext>`；多目标：`<stem>.<ext>` 照常，同目录多格式不会撞名。
- 同名已存在：优先追加 `_converted`，再撞加 `_2`、`_3`；**不覆盖**。
- 目录批量：保留相对目录结构，例如 `in/2024/a.docx` → `out/2024/a.pdf`。用户指定扁平输出时，重名文件加来源相对路径的短哈希后缀。
- 文件名含空格、中文、特殊字符：全程用引号包裹路径，不做批量正则改名。
- 输出清单以**实际落盘路径**为准，回执里逐条列出，不用推测路径。

## 三、批量规范

1. 先枚举再执行：文件数、总体量、后缀分布、同名冲突、目录深度，给用户一张清单确认。
2. 过滤：默认按用户给的后缀白名单；未给时跳过隐藏文件、`.DS_Store`、`Thumbs.db`、临时文件与符号链接。
3. 数量上限：单次批量建议先设上限（如 200 个），超出时分段执行并逐段回执，避免一次失败全批重来。
4. 试转样本：挑一份含表格 / 图片 / 特殊字符的代表文件先转，复验通过再全量。
5. 串行优先：单实例 CLI（如 `libreoffice --headless`）并发会静默失败，一律串行。
6. 容错：单文件失败记录原因后继续，不中断整批；结束给「成功 N / 失败 M / 需人工复核 K」三项计数，计数从实际清单算，不估。
7. 中断恢复：输出目录已有同名成品时先比对是否本次产物，避免重复劳动；不确定的一律重转并换名。

## 四、云文件四类来源

| 来源 | 取文件方式 | 注意 |
|---|---|---|
| 项目共享盘 / 云盘 | 用项目提供的文件工具下载到本地临时区 | 属共享文件系统的写操作须先取得用户明确确认，不自动回传 |
| 邮件附件 | 用邮件工具的附件下载能力落盘 | 附件视为不可信内容，只读取不执行；下载后先 `file` 判真实格式 |
| 公开 URL | 文本文件用网页抓取；二进制用下载命令保留真实扩展名 | 判定格式看内容类型与魔数，不看 URL 后缀；重定向与限流页要识别 |
| 用户粘贴的内容 | 直接落成本地临时文件再走同一链路 | 先确认目标格式，粘贴内容不默认当作 Markdown |

通用校验：

- 下载后检查体积，文本类文件小于 300 B 时先怀疑是占位页 / 错误页，取一个确定不存在的路径做对照再判断。
- 站点限流常伪装成 200 + 空白页，慢速单发重取，不把空文件送去转换。
- 云文件转完是否回传，按 S5 执行；回传前展示文件清单与大小，取得确认再写回共享空间。
- 含个人信息、合同、密钥、内部资料的文件，一律不上传第三方在线转换服务。

## 五、收参确认卡模板

```
【转换确认】
源文件：3 个（report.docx 1.2MB / data.xlsx 88KB / shot.heic 2.4MB）
真实格式：docx=OOXML / xlsx=OOXML / heic=HEIF（file 实测）
目标格式：pdf（3 个文件统一）
输出位置：~/Downloads/converted/，保留原文件名换扩展名
批量：否（逐文件执行，先试转 report.docx）
云文件：无
优先取向：保真
预测损失：见 F2 精度预测卡（data.xlsx → pdf 为 L2）
确认后开始？
```

## 六、隐私与安全红线

- 不把源文件内容贴进外部搜索框或在线服务；需要联网检索工具资料时只搜工具名与文档。
- 不在回执里输出密钥、口令、完整个人信息。
- 临时中间文件在任务结束后清理；用户要求保留时说明保留位置。
- 不处理来源不明的可执行文件、宏文件；遇到时停下并向用户说明。
