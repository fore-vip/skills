# act — 活动查询

让 AI 帮助用户发现和查询户外活动。

## 功能

| 工具 | 说明 |
|------|------|
| `search_activities` | 搜索活动：按位置、关键词、类型，带距离排序或热度排序 |
| `get_activity_detail` | 查看活动详情：时间、地址、参与信息 |

## 接入

服务地址：`https://mcp.fore.vip`

工具声明见 `mcp.json`，Agent 读取后自动注册。

## 搜索行为

- **有位置** → 按距离由近到远
- **无位置** → 按热度（浏览数）排序
- **有关键词** → 叠加关键词匹配
- **有类型** → 叠加类型筛选（运动/文化/志愿/其他）

以上可自由组合。
