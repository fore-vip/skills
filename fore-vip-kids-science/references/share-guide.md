# 分享途径（图文页发布 / 沉淀）

排版页（HTML 图文页）生成并展示后，主动询问用户是否分享。默认走 **资料库**，备选 **IMA 知识库** 与 **腾讯文档** 等文档工具。本文件给出路由决策与降级策略，供技能在「步骤 7 分享」时参照。

## 一、路由决策表

| 用户表达 | 目标 | 调用方式 |
|----------|------|----------|
| 「存到资料库 / 放进库 / 分享一下」（未点名外部产品） | WorkBuddy 原生资料库 | `skill: 资料库`，kind=`page` 上传 HTML 图文页 |
| 「存到 IMA / 上传到 ima / 进知识库」 | 腾讯 ima 知识库 | 需 `ima-mcp` 连接器已连接；未连则按 `references/ima-connect-guide.md` 引导接入 |
| 「存腾讯文档 / 发到 docs.qq.com / 微信分享」 | 腾讯文档个人版 | `skill: tencent-docs`，本地 HTML 上云（aipage 打包导入）或建在线文档 |
| 「不用了 / 只要本地文件」 | 不分享 | 保留本地 HTML，给出文件路径即可 |

## 二、默认行为

- 用户未明确指定产品时，**默认且唯一推荐资料库**（原生），不反问存到哪个产品。
- 用至多一次选择询问偏好（资料库 / IMA / 腾讯文档 / 仅本地文件），不强行替用户决定。
- 资料库与腾讯文档均为宿主鉴权：按各自 SKILL.md 走 `ToolSearch` → `DeferExecuteTool` 换票，token 不落盘、不进产物。

## 三、各载体要点

### 资料库（默认）
- 原生内容管理 / 分享协作模块；HTML 图文页按 `kind=page` 上传 / 发布，回执 `/space/d/{id}` 或 `*.workbuddy.link/p/{id}` 分享链接。
- 用户说「存到资料库」而未点名外部产品 → 一律走原生库。
- 路由细节以 `资料库` skill 的 `page/entry.md` 为准。

### IMA 知识库（备选）
- 依赖 `ima-mcp` 连接器（腾讯 ima 知识库，常态可能为 disconnected）。
- 已连接 → 引导把图文页 / Markdown 上传沉淀进 ima 知识库。
- 未连接 → **不替用户连接**（平台规则：连接动作由用户在卡片/连接中心触发）。按 `references/ima-connect-guide.md` 的固化话术引导用户在 WorkBuddy 连接中心接入 `ima-mcp`，连好后再分享；期间不阻断本地交付。

### 腾讯文档（备选）
- `skill: tencent-docs`；本地 HTML 走 `aipage_pack.js` → `import_file.py` → `manage.async_import` 上云，或直接建在线文档（smartcanvas / doc）。
- 适合需要微信 / QQ 转发、多人协作编辑的场景。

## 四、注意事项

- 分享只搬运「排版后的图文页成品」：不把生图 token、本地绝对路径、思考过程写入产物。
- 任一远端分享失败 → 回退到「仅本地文件」，给出 HTML 路径，并说明失败原因，不阻塞主交付。
- 安全边界同主技能：不分享任何不适龄 / 恐怖画面或敏感信息。
