# 热点雷达 · 近三天热点聚合与行动建议

把「最近有什么热点」变成**一份能读完、能信、还能动手的简报**。

三个硬约束贯穿全程：**只取近三天**、**每条可溯源**、**必须给出可执行的下一步**。
内容边界：社会民生、科技数码、商业财经、文娱体育、消费生活、行业趋势。
**不做**：涉政、军事、民族宗教、领土主权类话题（见「边界与安全」）。

## 触发规则

| 用户意图 | 处理 |
|----------|------|
| 「最近有什么热点 / 今天有什么新鲜事 / 追个热点」 | 走完整流程：快扫候选 → 弹窗选主题 → 深挖出简报 |
| 直接给出主题（「帮我看看 AI 眼镜最近怎么样」） | 跳过弹窗，直接用该主题进入 Step 3 深挖 |
| 追问某个已出简报的主题（「再挖深一点」「有更新吗」） | 沿用原主题，只补近三天新增信息，不重复已有内容 |
| 只问本技能能干嘛 | 简要介绍，不启动检索 |

## 核心准则

- **时效闸门优先于信息量**：宁可只写 3 条确凿的近三天进展，也不凑 10 条过期信息。搜不到近期内容就直说「近三天暂无新进展」。
- **弹窗是必经环节**（用户未指定主题时）：不允许自己挑一个主题就开写。
- **事实与舆论分离**：官方/权威媒体说的 → 事实；网友说的 → 必须写成「网友普遍认为」「讨论集中在」。
- **可溯源**：正文用 `[n]` 编号引用，末尾「信源清单」给出平台、标题、日期、链接。查不到出处的，明说查无出处。
- **可读性 > 覆盖面**：写完逐条对照 `references/sources.md` 第四节的去 AI 味规则自检，不合格就重写。
- **必须有行动建议**：没有「可以做什么」的简报 = 未完成。
- **最短路径**：结论先行，不描述检索过程。

## 工作流程

### Step 0 · 确定时效基准

先用 Bash 执行 `date +%Y-%m-%d` 取得**当天真实日期**，记为 `TODAY`；采集窗口 = `TODAY-2` ~ `TODAY`（含当天共 3 天）。

> 禁止凭记忆或推算当前日期——日期错了，整个时效闸门就失效。
> 简报顶部必须写明「采集窗口：YYYY-MM-DD ~ YYYY-MM-DD」。

### Step 1 · 快扫候选主题（3–5 次检索）

用 `WebSearch` 且**必须带 `freshness: "d3"`**。

**首选做法**：先检索「今日热榜聚合站」（`今日热榜 全网实时热点聚合`、`微博抖音B站虎扑知乎 热榜源`），这类页面一份就同时给出微博/知乎/抖音/头条/B站/虎扑 6 个平台的 Top10，性价比远高于逐平台检索（详见 `references/sources.md` 第 2 节）。

再用**定向检索**补齐领域覆盖（3–5 次总量）：

- `微博热搜 今日` / `百度热搜 今日` —— 大众热度面
- `知乎热榜 今日` —— 科技商业与公共议题
- `今日头条 热榜` / `抖音 热榜 今日` —— 民生与消费向
- 用户若有领域倾向（如「科技热点」），把其中 2 次换成该领域的定向检索

**产出 6–10 个候选主题**，规则：
- 跨平台重复出现的排前面（重复 = 热度信号）；
- 主题名写成**发生了什么**的具体短语，不写「XX 领域动态」这种空壳；
- 合并表述不同但同一事件的条目；
- **剔除涉政/军事/敏感项**（见「边界与安全」）。

> ⚠️ 实战提醒：热榜聚合页天然混入大量时政条目（人事任免、国防部表态、领导人行程等），**过滤后候选常常不足 6 个**。此时应追加定向检索补量（换领域词、换平台词），**绝不能把已剔除的涉政项捞回来凑数**。

### Step 2 · 弹窗让用户选（必经）

取热度前 4 个候选，调用 `AskUserQuestion`：

```json
{
  "questions": [{
    "question": "刚扫完近三天的热点，想先看哪个？（也可以直接在下方输入别的主题）",
    "header": "热点主题",
    "multiSelect": false,
    "options": [
      { "label": "<主题1，≤12字>", "description": "<一句话：发生了什么 + 为什么值得看>" },
      { "label": "<主题2>", "description": "……" },
      { "label": "<主题3>", "description": "……" },
      { "label": "<主题4>", "description": "……" }
    ]
  }]
}
```

规范要点：
- **不要自己加「其他」选项**——该工具会自动提供自由输入框，用户可在其中输入任意主题。
- `description` 必须给出「发生了什么」的实质信息，不写「点击查看」这类空话。
- 若当前环境**没有 `AskUserQuestion` 工具**，降级为纯文本列出：`1. 主题一 —— 一句话说明` … `4. 主题四`，末尾加「回复数字，或直接输入你想看的主题」，然后**等待用户回复**再继续。
- 用户直接输入主题时，原样采用；若主题过于宽泛（如「经济」），用至多 1 个问题收敛到具体事件，或按热度选一个最具体的切入点并声明假设。

### Step 3 · 多平台深挖（8–15 次检索）

围绕选定主题，按 `references/sources.md` 的矩阵采集，要求：

- **覆盖 ≥4 个平台、≥3 类信源**（热榜层 / 社交层 / 深度层 / 权威核验层）；
- 分层检索式：`主题词 官方 通报`、`主题词 最新进展`、`主题词 知乎 怎么评价`、`主题词 36氪 解读`、`主题词 小红书`、`主题词 数据 同比`；
- 对最关键的 3–8 条用 `WebFetch` 打开原文，拿到准确表述、发布时间与关键数据；
- **边采边打标**：每条素材立刻记下 `平台 · 日期 · 信源等级(S/A/B/C/D) · 原始表述`，不要等到写作阶段再回溯；
- 检索配额用满即停，不追加；未覆盖的平台在末尾如实说明。

检索失败时：换检索式重试 1 次 → 仍失败就跳过该信源，不卡流程。

### Step 4 · 过时效闸门与交叉验证

**时效过滤**：
- 发布日期 > 3 天 → 移出主线，只有确属必要背景的才放「背景补充」并**显式标注日期**；
- 无日期且 `WebFetch` 也确认不了 → 不进主线，只在末尾「待确认」标「时间未标注」；
- **`freshness: "d3"` 只是粗筛，不是保证**。实测会混入几周前的旧文与 AI 生成的软文（典型特征：通篇「深度解析/正向价值/赋能」、正文中出现明显早于本月的月份）。逐条确认发布日期这一步**不可省略**。

**真实性判定**（依据信源等级）：

| 情形 | 标注 |
|------|------|
| 有 S 级（官方/一手）或 A 级（权威媒体实名） | ✅ 已确认 |
| 两个及以上独立 A/B 级来源一致，无 S 级 | ⚠️ 多方报道，暂无官方确认 |
| 仅 C 级（社交讨论） | 💬 舆论，非事实 |
| 仅 D 级（匿名/营销号） | ❓ 未证实传闻 |

完全检索不到 → 明确回复「近三天暂未检索到可靠信息」，**不硬编、不脑补**。

### Step 5 · 可读性改写

按 `references/sources.md` 第四节的 8 条去 AI 味规则逐条自检后成文。核心是：**像人写给朋友看的简报，不像模型生成的内容总结。**

- 段落 2–5 句，长短交错；
- 关键数字给对比锚点；
- emoji 全文 ≤5 个，只出现在区块标题；
- 观点一律署名到具体机构或人。

### Step 6 · 生成行动建议

从简报内容出发，挑**与主题性质匹配的 2–3 个角色视角**给建议（不要五个全列）：

| 角色视角 | 适用主题 |
|----------|----------|
| 普通读者 | 所有主题 |
| 内容创作者 | 有传播度、有话题争议的热点 |
| 商家 / 从业者 | 消费、平台规则、行业政策类 |
| 求职者 | 行业变动、企业动向类 |
| 投资者 | 公司/行业/宏观事件（**必须附免责声明**） |

每条建议四要素齐全：

```
**<动作标题>**
- 为什么是现在：<与近三天进展挂钩的理由，说明窗口期>
- 怎么做：<具体到能立刻上手的一步，含工具/渠道/话术要点>
- 注意：<风险或常见坑>
```

要求：3–5 条，每条都能在半小时内启动；不写「持续关注」「加强学习」这类无效建议。
涉及投资、医疗、法律：只做信息整理与风险提示，**不给具体操作指令**（不荐股、不诊断、不下法律结论），并附免责声明。

### Step 7 · 输出简报

按下方模板组织，一次输出完整简报，不分段索要确认。

## 边界与安全

- **涉政、军事、民族宗教、领土主权类话题一律不做**：Step 1 生成候选时即过滤；用户主动输入时，说明「这类话题超出本技能范围」并请换一个主题，不做变相输出。
- **不造谣不传谣**：所有未确认内容必须带 ⚠️/💬/❓ 标记；检索不到就直说，不用推测填补空白。
- **违法犯罪 / 未成年人相关**：只引用官方通报原文，不猜测细节、不描述手法。
- **不挖隐私**：不检索当事人住址、家属、行踪、私人联系方式等非公开信息；素人相关话题不展开。
- **不带节奏**：不引导网暴、不站队煽动对立；「舆论」区块只呈现已有讨论，不新增攻击性评价。
- **不确定就标注**：日期、数据、因果链任何一环拿不准，就在「待确认」列出，不装作确定。
- **时效声明**：热点变化极快，末尾注明采集窗口，提示后续可能有新进展。
