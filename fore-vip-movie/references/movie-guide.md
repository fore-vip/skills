# 观影指南 · 参考库

本文件供 `fore-vip-movie` 在推荐时按需载入，包含：评估维度评分标尺、权威评分源说明、场景预设库、分级与未成年人保护参考。保持 SKILL.md 精简，详细内容集中于此。

---

## 一、评估维度评分标尺（1–10）

| 维度 | 9–10 | 6–8 | 3–5 | 1–2 |
|------|------|-----|-----|-----|
| 情绪契合度 | 精准命中当下心情/场景 | 基本契合，略有偏差 | 部分契合，需妥协 | 明显违背诉求（想治愈却致郁） |
| 口碑评分 | 豆瓣 8.5+/烂番茄 90%+ 或获奖 | 豆瓣 7.5–8.4 / 烂番茄 75–89% | 口碑分化 6.5–7.4 | 争议大 / 低分 |
| 类型匹配 | 完全符合点名类型 | 主类型符合，含混搭 | 仅边缘相关 | 类型错配 |
| 观看门槛 | 时长友好、全年龄、平台可得 | 小门槛（略长/需会员） | 明显门槛（3h+/限平台） | 分级不适 / 不可得 |
| 新鲜度 | 完美匹配「新片」或「经典」偏好 | 基本匹配 | 中性 | 与偏好相悖 |

> 默认五维均权（各 20%）。用户有明确优先级时按序加权，并请其确认；权重合计 100%。

## 二、权威评分源（标注格式：`来源·分值·时间/适用范围`）

| 源 | 适用 | 说明 |
|----|------|------|
| 豆瓣 | 国内主流观众 | 评分 + 短评 + 年度榜；注意「开分虚高/防剧透」 |
| IMDb | 全球 | 加权用户分，参考 Top 250 |
| 烂番茄 | 海外 | Tomatometer（影评人）+ Audience（观众）双分 |
| Metacritic | 海外 | 媒体均分（百分制），偏专业 |
| 票房 / 奖项 | 热度与品质信号 | 奥斯卡 / 金棕榈 / 豆瓣年度 / 国内票房榜 |
| 社区 | 体感口碑 | Letterboxd、小红书、微博话题的避雷与种草 |

**采集原则**：优先标注可验证的来源与年份；新片以「点映/首周」口径标注时间；不把社媒情绪当事实分。

## 三、场景预设库

每个场景给出「基调 + 选片逻辑 + 典型类型 + 避雷」，推荐时直接套用并代入具体片目。

### 1. 周末宅家补番 / 刷经典
- 基调：轻松、可控、可随时暂停
- 逻辑：优先口碑长青、节奏不紧绷；经典重温走「导演系/类型标杆」
- 避雷：3h+ 严肃片、需要专注烧脑的

### 2. 情侣约会
- 基调：浪漫 / 轻松 / 有共鸣，不沉闷不致郁
- 逻辑：爱情 / 轻喜剧 / 合家欢动画；避免大尺度与沉重议题
- 避雷：致郁、血腥、纯悬疑无情感线

### 3. 亲子合家欢
- 基调：全年龄友好、有笑有暖
- 逻辑：合家欢动画 / 奇幻冒险；确认全年龄分级
- 避雷：恐怖、暴力、复杂成人梗；须标注「家长陪同」项

### 4. 朋友聚会
- 基调：热闹、可讨论、低专注门槛
- 逻辑：喜剧 / 悬疑推理（可一起猜凶手）/ 动作爽片
- 避雷：文艺慢片、需要静心细品的非爽片

### 5. 一个人治愈
- 基调：温暖、轻盈、情绪安全
- 逻辑：治愈系 / 温情 / 自然纪录片；不推向孤独致郁
- 避雷：致郁、高能反转、重口味

### 6. 想哭一场（情绪释放）
- 基调：催泪、共情、允许宣泄
- 逻辑：家庭 / 成长 / 真实事件改编；提示备纸巾
- 避雷：黑化结局、纯搞笑

### 7. 纯解压喜剧
- 基调：爆笑、无脑快乐
- 逻辑：喜剧 / 闹剧 / 脱口秀式；短平快更佳
- 避雷：黑色幽默过重、讽刺门槛高

### 8. 悬疑烧脑
- 基调：反转、推理、沉浸
- 逻辑：悬疑 / 犯罪 / 心理；提示「别快进、防剧透」
- 避雷：逻辑硬伤、为反转而反转

### 9. 档期新片
- 基调：追热点、社交货币
- 逻辑：近期上映 / 话题度高的新片；标注院线与排片提示
- 避雷：把未映预期当事实；提醒以实际排片为准

### 10. 经典重温
- 基调：影史必看、品味沉淀
- 逻辑：Top 250 / 获奖经典 / 导演代表作；给「为何经典」一句话
- 避雷：过度剧透、强行拔高

### 11. 硬核科幻 / 视效大片
- 基调：视听震撼、想象延展
- 逻辑：科幻 / 视效 / IMAX 友好；提示「适合大屏」
- 避雷：剧情薄弱却号称神作（如实标注）

### 12. 通勤碎片
- 基调：短、轻、可中断
- 逻辑：短剧集 / 短片 / 纪录片单集；不推长电影
- 避雷：需要连续沉浸的剧情长片

## 四、分级与未成年人保护参考

- **国内现状**：中国大陆无正式电影分级制度，以广电总局审查 + 平台「青少年模式 / 适龄提示」为准。推荐时采用「建议 X 岁+」的软性提示。
- **国际参考（MPAA）**：G（全年龄）/ PG（建议陪同）/ PG-13（13+）/ R（17+ 或陪同）/ NC-17（17+）。
- **硬性要求**：
  - 限制级（R / NC-17 / 致郁重口）须标注「建议 X 岁+ / 家长陪同」。
  - 不主动向未成年人推荐限制级内容。
  - 亲子场景默认全年龄友好，逐片确认分级提示。
