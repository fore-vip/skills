# 合规与文案红线

> 来源：`_common/references/compliance.md @ 1.0.0`
> 用于出稿后自查，不构成法律意见；平台规则以最新官方口径为准。

## 一、事实、分析、建议必须分开

| 层 | 写法 | 反例 |
|---|---|---|
| 事实 | 带来源、时间、适用范围 | 把检索摘要写成结论 |
| 分析 | 标明推导链条与假设 | 用「显然」「必然」跳过推理 |
| 建议 | 写清触发条件与代价 | 用「应该」包装成定论 |

关键数据标来源与时间；信息不足写「未补充验证」，并给出补验方式。推测不写成事实。

## 二、禁用词与处理

| 类别 | 典型词 | 处理 |
|---|---|---|
| 绝对化 | 最、第一、唯一、首个、顶级、极致、百分百、史上 | 改成可核对的具体事实（「便宜」→「比上一代低 40 元」） |
| 承诺效果 | 保证、包过、稳赚、躺赚、零风险、立竿见影、永不 | 删承诺，改条件式表述 |
| 无据权威 | 专家推荐、官方认证、国家专利、权威机构认定 | 补来源与编号，无据就删 |
| 医疗断言 | 治疗、治愈、根治、疗效、抗炎、提高免疫力 | 删除，改生活体验表述 |
| 金融断言 | 荐股、内幕、保本、收益率承诺 | 删除，不写此类选题 |
| 迷信与低俗 | 转运、改命、风水布局、性暗示、地域黑称 | 删除 |
| 未成年人 | 姓名、学校、照片、住址、可识别身份 | 一律脱敏 |
| 涉政涉灾 | 政治评价、历史争议、遇难人数渲染、事故细节消费 | 整段重写选题 |

处理顺序：**先过禁用词，再去 AI 味**。改词会动字数，顺序反了要重算两遍。

## 三、运营与平台口径

- 微信生态遵守运营规范；口播与图文不做站外引流动作（加微信、私信、评论区扣 1、主页领取、点击购买等）。
- 商业关系必须标注（含商业推广），不隐藏。
- 平台资质类内容（金融、医疗）先确认资质再出稿。
- 高频限流词按投放平台自查，平台口径不一致时按较严的一版执行。

## 四、去 AI 味词表

| 类型 | 词 |
|---|---|
| 互联网黑话 | 赋能、闭环、抓手、颗粒度、对齐、心智、组合拳、面向未来 |
| 标题党 | 震惊、不看后悔、必看、封神、破防 |
| 直播腔 | 家人们、宝子们、老铁们 |
| 空转承接 | 那么问题来了、接下来让我们、值得注意的是、由此可见 |

黑话直接删，标题党换具体信息，直播腔按平台调性删或降频。文案贴合目标场景，不堆形容词。

## 五、固定四步

1. **扫**：通读全文，按上面各表标出全部命中项。
2. **分类**：判定「必须删」还是「可以换」。
3. **三选一**：删（不影响语义时首选）／换（同义自然表达）／改（整句重组为有条件陈述）。
4. **复核**：确认事实、数字、专有名词未被改动；确认没有一句话能被理解为「保证结果」。

输出格式固定三列：**原词 → 替换 → 位置**。

## 六、隐私与凭证

- 凭证只在命令行传入，不写进任何仓库文件；日志与交付说明做脱敏。
- 公开文件不写内部路径、部署配置、内部端点与计费实现。
- 用户项目信息保密；示例数据写「示例数据」，未上线写「未上线」，未验证写「未验证」。

## 七、红线

- 不为过检改事实。改的是表达，不是内容。
- 不承诺「绝对安全」；本表是常见项集合，不等于平台审核清单。
- 灾难伤亡、未成年人、医疗、荐股类选题不找擦边写法，直接不做。
