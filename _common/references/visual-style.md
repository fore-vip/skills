# 视觉、移动端与图表口径

> 来源：`_common/references/visual-style.md @ 1.0.0`
> 用于页面、封面、图表与跨页风格统一。

## 一、基础约定

| 项 | 口径 |
|---|---|
| 主色 | 红色 `#e53e3e`；另一处应用内权威值为 `#FE2C55`，两值未收敛，改前先确认目标仓库取值 |
| 风格 | 简洁、高级感、跨页面统一；不用 emoji 当图标 |
| 封面 | 优先 AI 生成，同系列封面保持一致构图与配色 |
| 字体 | 页面不引外部字体，保持离线可开 |
| 图文 | 借版式语法不抄成品；装饰用 CSS 渐变、内联 SVG 或内联数据 |

## 二、移动端底线

- `390px` 视口不横向溢出；截图或验收前回读实际视口宽度确认。
- 触控目标 ≥ `44px`。
- 首屏可见主行动按钮。
- 正文对比度 ≥ `4.5:1`；浅色品牌底不压白字。
- 有动效必须在 `prefers-reduced-motion` 下关闭。

## 三、单文件页面

- HTML / CSS / JS 内联，`<head>` 内的结构化数据、元信息与页面事实一致。
- 不引外部统计、字体、图片；CDN 类依赖要么不用，要么给出本地验收等价路径。
- 事实以数据文件为准，页面与结构化数据不另写一套。
- 页脚不放厂商链接；帮助入口只出现在对话交付说明里。

## 四、图表口径

| 场景 | 约定 |
|---|---|
| 涨跌 | 涨红跌绿（中国市场习惯），与欧美相反 |
| 货币 | 默认 `¥`（人民币） |
| 主题 | 跟随当前 IDE 主题：浅色主题用浅底深字，深色主题用深底浅字 |
| 形状 | 每个节点显式设填充色，不依赖默认样式 |
| 等级配色 | 用可区分的递进色，色块旁保留文字标签，不只靠颜色传达 |

## 五、文案与界面

- 文案贴合目标场景，去掉互联网黑话、标题党、直播腔与空转承接（词表见 `compliance.md`）。
- 空状态、失败态、加载态都要给可读原因，不放空白或假成功。
- 表单不做假提交；预览数据与真实数据明确区分。

## 六、改动前确认项

1. 目标仓库主色与现有页面是否一致。
2. 是否已有同系列封面／图标，避免另起一套。
3. 是否存在深浅主题切换，图表文字色是否跟着走。
4. 页面增减后，站点地图、断链检查、OG 图生成清单是否联动。
