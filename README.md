# 火力打卡 · Skills

让 AI 帮你发现和参与户外活动。

## 技能列表

### act — 活动查询技能

搜索活动、查看详情，支持地理位置与关键词匹配。适合接入支持 MCP 的 AI 助手。

```bash
npx skills add fore-vip/act
```

安装后，对 AI 说「附近的爬山活动」「这个活动详情是什么」，即可自动查询。

### fore-ex — 活动发现浏览器插件

给运营、达人、团队成员用的 Chrome 插件：在浏览器里浏览平台活动、查看详情、获取发布密钥。

详见 [fore-ex/README.md](fore-ex/README.md)。
