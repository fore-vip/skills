# 评分卡细则 · 三维度 8 子项

打分前必读。每个子项都是 **0–5 分整数**，权重固定，总分百分制。

**总分公式**：

```
总分 = Σ(子项得分 ÷ 5 × 子项权重)
     = P1小计 + P2小计 + P3小计        （满分 100）
```

**打分三条纪律**：

1. **一证据一分**。写下分数时必须附来源与日期，写不出证据的分不算数。
2. **查不到就 null**，按中位 3 分代入并标注「信息不足·按中位代入」，不许用印象补分。
3. **区分「已证实」与「单方主张」**。已生效法律文书、监管处罚、企业公开承认 → 可重扣分；
   匿名爆料、单方投诉、传闻 → 只能轻扣分并标「未证实」。

## P1 用工友好与工时（45 分）

### P1.1 双休制落实（18 分）

看这家企业**是否真的每周休两天**，而不是名义双休、实际到岗。

| 分 | 判定 |
|----|------|
| 5 | 官网招聘页/员工手册明确写明「双休 + 法定节假日 + 不调休」，且社区口碑一致印证无大小周 |
| 4 | 明确双休，偶有周末值班但可调休，社区无系统性抱怨 |
| 3 | 名义双休，但存在「业务需要时周末到岗」的模糊表述；或证据不足 |
| 2 | 大小周（隔周休两天）被公开承认或多人印证；或名义双休实际长期单休 |
| 1 | 单休 / 月休四天 / 排班制且无固定休息日，有明确证据 |
| 0 | 公开宣称 996、狼性、无休；或休息日安排明显违法且被监管点名 |

**证据类型**：招聘 JD 原文、员工手册、官方公众号/招聘号表述、脉脉与知乎的多源一致描述、劳动监察处罚决定书。

**常见误判**：
- 招聘页写「双休」不等于真双休，要交叉印证。**只凭一条 JD 最多给 4 分，给 5 分必须有社区印证。**
- 门店类、制造类、零售类岗位常为排班制，「双休」不适用——此时改看**每周实际休息日数**与**排班是否提前公示**，不要直接判低分。

### P1.2 实际加班强度（15 分）

| 分 | 判定 |
|----|------|
| 5 | 社区普遍反馈「基本不加班 / 到点走」；加班视为异常事件 |
| 4 | 偶有项目期加班，日常准时下班；无强制加班记录 |
| 3 | 普遍存在阶段性加班，但无强制；或证据不足 |
| 2 | 常态性加班（日均多 1–2 小时），有「加班是默认」的社区共识 |
| 1 | 强制加班、加班时长明显超标，有多方印证 |
| 0 | 公开的 996/007 工作制、工时严重违法且有监管或司法认定 |

**证据类型**：员工社区工时描述（多人多源）、加班费/考勤相关争议记录、媒体报道、社交平台的打卡吐槽。

**常见误判**：
- 「加班多」分行业。广告、咨询、互联网、餐饮、医护的高强度是行业性的——
  评的是「相对于同行业是否更差」，不是拿所有行业同一把尺子。**务必在报告里写清比较基准。**
- 单人吐槽不给低分。**至少两条独立信源**才认定为「常态性」。

### P1.3 加班补偿落实（12 分）

| 分 | 判定 |
|----|------|
| 5 | 明确按法定 1.5/2/3 倍支付加班费，或足额调休由员工自选，社区无异议 |
| 4 | 有加班费或调休，执行基本到位，个别岗位有争议 |
| 3 | 有制度但执行不稳定；或证据不足 |
| 2 | 以「绩效/年终奖」含糊替代加班费，员工反馈拿不到法定标准 |
| 1 | 明确无加班费且无调休；有员工投诉或仲裁记录印证 |
| 0 | 因拖欠加班费被裁判文书/劳动监察认定，或有集体讨薪事件 |

**证据类型**：招聘页薪酬福利栏目、员工反馈、裁判文书网「追索劳动报酬」案由、12333/12345 投诉公示。

## P2 劳动合规与雇主口碑（30 分）

### P2.1 劳动纠纷与仲裁记录（12 分）

**这是最容易踩名誉侵权红线的子项，严格按证据等级判定。**

| 分 | 判定 |
|----|------|
| 5 | 检索范围内无劳动争议案件；或仅有零星个案且已了结、非企业过错 |
| 4 | 有少量劳动争议诉讼，多为个人员工纠纷，无系统性特征 |
| 3 | 存在一定数量劳动争议案件；或证据不足 |
| 2 | 多起劳动争议，涉及欠薪/违法解除等事项，含裁判文书可查的败诉记录 |
| 1 | 大量劳动争议、有群体性仲裁或集体欠薪报道 |
| 0 | 被列入失信名单、被认定恶意欠薪、或有重大群体性劳动事件 |

**证据等级（决定扣分力度）**：

| 等级 | 来源 | 处理 |
|------|------|------|
| **A 已证实** | 生效裁判文书、劳动监察处罚、企业公开承认、政府部门通报 | 可按上表正常扣分 |
| **B 可核验** | 权威媒体的调查报道、上市公司公告披露 | 扣分但降一档，标注媒体与日期 |
| **C 未证实** | 员工单方爆料、匿名帖、社交平台抱怨 | 最多扣至 3 分，必须标「未证实（单方主张）」 |

**取证渠道**：中国裁判文书网、信用中国、国家企业信用信息公示系统、各地人社局「重大劳动保障违法行为」公示、黑猫投诉企业页。

**硬约束**：
- 只说「**公开信息显示存在争议**」，不说「该企业违法」。
- 立案不等于败诉，被告不等于过错方，**要看清裁判结果的输赢和理由**，不能只凭「有案件」扣分。
- 结案多年的历史案件权重递减，优先看近 3 年。

### P2.2 社保与用工合规（8 分）

| 分 | 判定 |
|----|------|
| 5 | 公开渠道无社保公积金未缴/少缴投诉，招聘明确「五险一金按实际工资缴纳」 |
| 4 | 五险一金齐全，基数可能存在普遍性打折（员工反馈但无投诉） |
| 3 | 仅缴五险无公积金，或基数按最低标准；或证据不足 |
| 2 | 有社保欠缴、劳务派遣比例畸高、大量非全日制规避用工的公开反馈 |
| 1 | 有社保相关行政处罚或批量员工投诉 |
| 0 | 因社保问题被列入严重失信名单或有监管重罚 |

**证据类型**：招聘 JD 福利栏、员工反馈、人社局公示、公积金管理中心催缴/处罚公告。

### P2.3 员工社区口碑（10 分）

看员工**主动评价**时的整体情绪，这是「双休」最真实的镜像。

| 分 | 判定 |
|----|------|
| 5 | 社区评价以「人性化、尊重、到点下班」为主，负向评价极少且被有效回应 |
| 4 | 好评为主，负向集中在个别岗位/前员工，无系统性指控 |
| 3 | 好评差评参半；或样本太少不足以判断 |
| 2 | 负向为主，集中在加班、PUA、画饼、裁员方式 |
| 1 | 高度一致的负面评价，且包含侮辱性管理、变相逼退等具体描述 |
| 0 | 出现「讨薪群」「集体维权」「跑路」等标志性组织化负面信号 |

**证据类型**：脉脉、知乎、小红书、豆瓣小组、贴吧、Boss直聘评价区。

**判读规则**（详见 `references/flags.md`）：
- 单条差评不给低分，看**是否形成模式**（同类指控 ≥3 条独立来源）。
- **剔除离职前后情绪帖**：刚离职/被裁员工的极端评价要打折看。
- 注意「水军」特征：短时间内大量雷同好评、无具体细节，识别后不作加分依据。

## P3 产品质量与供应链（25 分）

### P3.1 产品质量风评（15 分）

用工友好的企业若产品不行，推荐仍是失败的——这一项保证结论**不至于叫好不叫座**。

| 分 | 判定 |
|----|------|
| 5 | 口碑优良，专业评测与用户反馈一致认可，无重大质量事故 |
| 4 | 整体良好，存在个别小毛病但售后响应到位 |
| 3 | 口碑中性；或证据不足 |
| 2 | 质量投诉较多，负面集中在核心功能；或售后推诿 |
| 1 | 有产品召回、质量抽检不合格、重大质量事故报道 |
| 0 | 有重大安全事故或系统性造假（虚假宣传被处罚） |

**证据类型**：专业媒体评测、电商评价（注意剔水分）、市场监管局抽检公告、黑猫投诉、产品召回公告。

### P3.2 供应链用工与稳定性（10 分）

**这是本技能区别于普通产品推荐的独有维度**——把企业的用工责任延伸到它的代工厂。

| 分 | 判定 |
|----|------|
| 5 | 公开披露供应商行为准则/ESG 用工审核，或有第三方供应链审计报告 |
| 4 | 自建产能为主，供应链可控，无供应链用工负面 |
| 3 | 以代工为主但无公开负面；或证据不足 |
| 2 | 代工厂出现被曝光的用工问题，或供应链有欠款/压款争议 |
| 1 | 供应链用工问题被媒体调查报道且企业未有效回应 |
| 0 | 供应链存在明确的强迫劳动、童工等严重问题被查处 |

**证据类型**：企业 ESG/社会责任报告、供应商行为准则公开文件、媒体供应链调查报道、代工厂所在地的监管公示。

> 若企业为轻资产 DTC 品牌、全部依赖代工且无任何披露 → 此项按 3 分（信息不足）处理，
> 但在报告中必须写明「供应链用工不透明，无法验证」，这是重要风险提示而非中性结论。

## 等级映射与结论口径

| 等级 | 分数 | 结论口径（措辞模板） |
|------|------|---------------------|
| S | ≥ 85 | 「本次候选中用工记录最扎实的一家，可放心支持。」 |
| A | 70–85 | 「用工记录良好，值得优先考虑。」 |
| B | 55–70 | 「整体可接受，但在 XX 方面存在明确短板，介意的话建议对比后再定。」 |
| C | 40–55 | 「用工方面存在较多争议点，是否支持取决于你是否在意这些维度。」 |
| D | < 40 | 「公开信息显示用工问题较突出，建议优先考虑其他候选。」 |

**数据完整度**：

```
数据完整度 = 有实证依据的子项数 ÷ 8
```

| 完整度 | 报告要求 |
|--------|----------|
| ≥ 75% | 可正常给出排名与结论 |
| 50–75% | 排名可给，但结论必须附「部分维度证据不足」提示 |
| < 50% | **不给确定排名**，改为「信息不足，无法可靠比较」，并说明缺什么、去哪补 |

**免责声明模板**（每份报告结尾必须带，措辞不要弱化）：

> 本报告的评分仅基于公开可检索信息在本次 5 家候选范围内的横向比较，
> 不构成对企业用工合法性的认定，也不代表任何官方评级。
> 标注「未证实」的内容为企业外部人员单方主张，未经司法或行政确认。
> 企业经营状况与用工政策会随时间变化，请以企业最新公开信息为准。
