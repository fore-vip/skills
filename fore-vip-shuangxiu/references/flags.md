# 信号词库与判读规则

判读社区口碑时读。**词表只提供线索，不构成结论**——命中一个词不代表判定成立，
必须结合信源数量、具体细节与可信度分级（见 `sources.md`）综合判断。

---

## 一、用工与工时信号

### 强正向（可支撑 4–5 分）

| 信号词 / 表述 | 含义 |
|---|---|
| 「真双休」「不调休」「法定节假日正常放」 | 休息制度扎实 |
| 「到点走」「准点下班」「不打卡」 | 无强制加班文化 |
| 「不用带电脑回家」「下班不看工作群」 | 边界清晰，属于高阶信号 |
| 「加班要审批」「加班需申请」 | 加班是例外而非常态 |
| 「年假能休完」「年假不限制」 | 福利落实到位 |
| 「团建自愿」「周末不团建」 | 尊重个人时间 |

### 强负向（可支撑 0–2 分）

| 信号词 / 表述 | 含义 |
|---|---|
| 「996」「007」「大小周」「单休」「月休四天」 | 工时制度性问题 |
| 「默认加班」「不加班就是不努力」 | 加班已内化为文化 |
| 「加班不给钱」「白干」「义务加班」 | 补偿缺失 |
| 「周末团建」「休息日开会」「周报周日晚上交」 | 侵占休息日 |
| 「下班后要秒回」「24 小时待命」 | 边界被打破 |
| 「请假看脸色」「年假批不下来」 | 休假权受限 |
| 「打卡不自由」「补卡要罚款」 | 考勤刚性，常见于高压环境 |

### 劳动合规信号

| 信号词 | 指向 |
|---|---|
| 「五险一金按最低基数缴」「社保断缴」 | 社保合规瑕疵 |
| 「只交五险没公积金」 | 福利不完整 |
| 「劳务派遣」「外包」「非全日制」比例高 | 用工规避倾向 |
| 「试用期不缴社保」 | 明确违规 |
| 「拖欠工资」「发薪日一拖再拖」 | 资金或合规风险 |
| 「赔偿不给足」「N 都拿不到」「逼你主动离职」 | 离职合规风险 |
| 「仲裁」「劳动监察」「讨薪」 | 已进入争议阶段 |
| 「绩效强制分布」「末位淘汰」 | 管理手段激进 |
| 「35 岁」「优化」「毕业」 | 年龄歧视与裁员话术 |

### 组织风气信号

| 信号词 | 指向 |
|---|---|
| 「PUA」「人身攻击」「当众羞辱」 | 管理失当 |
| 「画饼」「承诺不兑现」「口头 offer 反悔」 | 诚信问题 |
| 「拉帮结派」「站队」「办公室政治严重」 | 内耗文化 |

| 「离职率高」「半年换一批人」 | 留不住人 |

## 二、产品质量信号

| 正向 | 负向 |
|---|---|
| 「用三年没坏」「品控稳定」 | 「三个月就坏」「开箱即故障」 |
| 「售后直接换新」「不啰嗦」 | 「售后推诿」「踢皮球」 |
| 「工艺扎实」「用料实在」 | 「偷工减料」「减配」 |
| 「老品牌」「口碑积累」 | 「贴牌」「代工不透明」 |
| 「评测数据好」 | 「抽检不合格」「召回」 |

**判读提示**：产品质量类信号要区分**个体瑕疵**与**系统性缺陷**。
同一型号多人反映同一故障 = 系统性；零散不同问题 = 个体差异，不该重扣。

## 三、供应链信号

| 信号 | 指向 |
|---|---|
| 公开披露《供应商行为准则》《责任采购政策》 | 正向，可支撑 5 分 |
| 发布 ESG / 社会责任报告且含用工章节 | 正向 |
| 第三方供应链审计（如 BSCI、SA8000） | 正向，强证据 |
| 「全部代工」「无自有产能」且无任何披露 | 中性偏风险，按信息不足处理 |
| 「代工厂被曝血汗工厂」 | 负向，需看企业是否回应整改 |
| 「压供应商货款」「账期拖到 180 天」 | 负向，反映生态强势与传导风险 |

## 四、信噪比判读规则

### 认定「形成模式」的门槛

| 子项 | 最低证据量 | 处理 |
|------|-----------|------|
| 加班是常态 | ≥3 条独立来源，覆盖 ≥2 个平台 | 可判 2 分及以下 |
| 社保不合规 | ≥2 条具体描述 + 能说明岗位或地区 | 可判 2 分 |
| 拖欠工资 | 1 条 A 级证据，或 ≥3 条 C 级独立描述 | 可判 1 分 |
| 双休落实 | ≥2 条正向印证（含 JD 原文） | 才可给 5 分 |
| 产品质量系统缺陷 | 同一问题 ≥5 条独立反馈 | 可判 2 分 |

**未达门槛的**：记录在「线索」栏供参考，不进评分。

### 必须打折看的内容

| 类型 | 打折原因 | 处理 |
|------|----------|------|
| 刚离职/被裁员工的评价 | 情绪未冷却，倾向极端 | 权重打 5 折，只作参考 |
| 离职前最后一个月发的吐槽 | 常伴随冲突事件 | 与其他证据交叉后才用 |
| 匿名无细节爆料 | 无法核实 | 只记「线索」，不评分 |
| 面试未通过者的评价 | 立场偏差 | 一般不采用 |
| 竞品对比帖 | 可能有商业动机 | 需独立印证 |
| 三年前的帖子 | 政策可能已变 | 只作背景 |

### 水军与黑公关识别

**疑似刷好评**：短时间集中出现、句式高度雷同、只给结论不给经历、账号历史单一、发布时间规律。
→ 识别后**不作为正向加分依据**，并在报告中提示「存在疑似营销内容」。

**疑似黑帖**：多平台同步同文案、指控笼统无细节、无任何当事人信息、集中指向同一竞品。
→ 归入 D 级不可用信源，**不采用**。

## 五、一条底线

词表是给**判读提速**用的，不是给**结论凑数**用的。

命中负向词 ≠ 企业有问题；命中正向词 ≠ 企业真好。
在没有具体、可核实的证据前，任何一条负面描述都只能写成
「有员工反映（未证实）」，而不能写成「该企业存在 XX 问题」。
