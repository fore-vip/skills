# 信源清单与检索式模板

第 3 步取证时读。目标：**对 5 家企业，各维度都能拿到带日期、可点开的证据**。

---

## 一、四路信源定位

| 信源 | 作用 | 可信度 | 使用纪律 |
|------|------|--------|----------|
| **模型基础档案** | 企业规模、性质、成立时间、主营、上市状态、供应链模式 | 参考级 | **必须标注「模型侧信息，未外部核实」**，不能作为评分证据 |
| **社区** | 员工真实口碑：工时、加班、双休、社保、裁员 | 中（需交叉印证） | 单条不算数，同类指控 ≥3 条独立来源才认定为模式 |
| **搜索引擎** | 补充与兜底，覆盖社区未提的侧面 | 中 | 用作发现线索，结论要回到原始来源核实 |
| **资讯站** | 劳动纠纷、裁判文书、行政处罚、行业调查 | 高（原始文书最高） | 优先采信，注意看裁判结果的输赢与理由 |

**取证顺序建议**：先模型档案定 5 家名单 → 再资讯站查硬性合规（可能直接判 D）→ 再社区查工时与口碑 → 最后搜索引擎补齐缺口。
先查硬信息可以避免在明显有问题的企业上浪费检索预算。

## 二、渠道清单

### 劳动合规类（最高优先级）

| 渠道 | 查什么 | 备注 |
|------|--------|------|
| 中国裁判文书网 | 劳动争议、追索劳动报酬、违法解除案由 | 最硬的证据，注意看判决结果 |
| 信用中国 | 失信记录、行政处罚 | 官网可查企业信用报告 |
| 国家企业信用信息公示系统 | 基础工商信息、行政处罚、经营异常 | 核实主体是否与品牌对应 |
| 各地人社局官网 | 「重大劳动保障违法行为」公示、欠薪黑名单 | 分地区，需按注册地检索 |
| 全国法院被执行人信息查询 | 被执行、失信被执行人 | 反映资金链与履约状况 |
| 公积金管理中心 | 催缴、处罚公告 | 社保公积金合规性 |
| 12333 / 12345 投诉公示 | 批量投诉线索 | 部分城市有公开数据 |

### 员工口碑类

| 渠道 | 查什么 | 备注 |
|------|--------|------|
| 脉脉 | 员工实名/匿名评价、加班吐槽 | 中文职场口碑信息密度最高 |
| 知乎 | 「在 XX 工作是什么体验」类问题 | 长文细节多，但个体偏差大 |
| 小红书 | 打工日常、避雷帖 | 年轻员工聚集，节奏类抱怨多 |
| 豆瓣小组 | 「上班这件事」等小组讨论 | 情绪浓，需过滤 |
| 贴吧 | 老牌企业、制造业、地方企业口碑 | 制造业/地方企业覆盖好 |
| Boss 直聘 / 猎聘 | 招聘 JD 的工作时间表述、评价区 | **JD 原文是判断双休的一手材料** |

### 产品质量类

| 渠道 | 查什么 | 备注 |
|------|--------|------|
| 黑猫投诉 | 投诉量与处理率、典型问题 | 看「已回复/已完成」比例 |
| 国家市场监管总局 | 抽检公告、缺陷产品召回 | 权威 |
| 专业评测媒体 | 拆解、横评、实验室数据 | 比电商评价可信 |
| 电商评价区 | 用户反馈 | **必须剔水分**：看中差评、看追评、看去重后的细节描述 |
| 消协 / 12315 | 投诉统计与调解案例 | 行业性投诉提示 |

### 供应链与社会责任类

| 渠道 | 查什么 | 备注 |
|------|--------|------|
| 企业 ESG / 社会责任报告 | 供应商行为准则、用工审核披露 | 上市公司与大型企业才有 |
| 上市公司年报 / 招股书 | 用工规模、劳务外包比例、供应商集中度 | 数据可比性强 |
| 媒体供应链调查 | 代工厂用工调查报道 | 权威媒体的调查报道可信度高 |

## 四、信源可信度分级

打分时按此等级调整扣分力度（呼应 `dimensions.md` 的证据等级表）：

| 等级 | 来源 | 用法 |
|------|------|------|
| **A 已证实** | 生效裁判文书、政府处罚决定、官方公示、企业公告 | 可直接作为扣分依据 |
| **B 可核验** | 权威媒体调查报道、上市公司披露、第三方审计报告 | 可扣分但降一档，注明媒体名与日期 |
| **C 待核实** | 员工单方爆料、匿名帖、社交平台抱怨、投诉平台个案 | 最多扣至 3 分，必须标「未证实」 |
| **D 不可用** | 无信源的传闻、AI 生成内容、营销号拼凑、竞品抹黑 | **不采用**，不作为任何评分依据 |

**辨认 D 级内容的特征**：无具体时间地点、无当事人身份、多平台同文案复制、通篇情绪无细节、明显由竞品或黑公关推动。

**辨认水军好评的特征**：短时间内集中出现、句式雷同、无具体经历细节、只夸「公司好」不说好在哪。

## 五、取证纪律（每次必守）

1. **记三样**：来源名称 + 具体链接或可检索路径 + 时间（发布日或事件日）。缺一样就不算证据。
2. **看清主体**：品牌名 ≠ 工商主体名。连锁品牌要区分加盟店与总部；集团要区分母公司与子公司。
   **劳动纠纷常发生在具体用工主体上**，别把子公司的案子算到母公司头上，反之亦然。
3. **区分主张与结论**：立案通知书 ≠ 判决；原告起诉 ≠ 被告过错。必须看到裁判结果的输赢与理由。
4. **看时间衰减**：优先近 3 年。5 年前的问题若已整改，只作背景提及，不重扣当次评分。
5. **诚实留白**：查不到就写「未检索到公开信息」，这是有效结论。
   **绝不能因为查不到就默认为「没问题」**——查不到是「未知」，不是「清白」，报告里要区分这两种表述。
6. **不做人情分**：热爱的品牌、自己用的产品、用户已经买了的，都不加分。立场中立是这份报告的唯一价值。
