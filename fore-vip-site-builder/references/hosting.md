## 1. 三方案对照与选择

| 维度 | A. 阿里云 OSS · 中国内地 | B. 阿里云 OSS · 中国香港 | C. Vercel |
|------|--------------------------|--------------------------|-----------|
| ICP 备案 | **必需** | 不需要 | 不需要 |
| 大陆访问速度 | 快 | 中等 | 不稳定 |
| 首次上线周期 | 备案 1–20 个工作日（+ 前期准备） | 当天 | 当天 |
| 主要成本 | 域名 + OSS 流量 + **备案载体服务器** | 域名 + OSS 流量 | 免费额度通常够用 |
| 自定义域名 | 必须（默认域名会被强制下载） | 必须（同左） | 支持，自动签证书 |
| 大陆合规支持 | 有 | 有 | **无** |
| 适用 | 面向大陆的主力官网 | 想立刻上线、能接受稍慢 | 海外为主 / 内部演示 / 文档站 |

**选择规则**

- 访客主要在中国大陆且能等 2–3 周 → **A**。
- 访客主要在中国大陆但要求当天上线 → **B** 先上线，后续需要再迁 A（备案完成后换解析）。
- 访客在海外、或只是内部演示 / 文档站 → **C**。

> Vercel 官方说明（见第 4 节）：其在大陆无服务器与 CDN 节点，境外域名可能被阻断或限速，**不保证大陆可用性与性能**，且不提供境内托管与合规支持。这是选择 C 时必须向用户明确的风险，不能含糊带过。

## 2. ICP 备案（走中国内地节点必读）

### 2.1 什么时候必须备案

- 网站域名**解析到中国内地服务器** → 必须完成 ICP 备案。
- 域名解析到**中国香港或海外节点** → 无需 ICP 备案。
- 未备案却把域名解析到阿里云中国内地节点 → 会被阿里云监测系统识别并**阻断该域名访问**。
- **首次备案期间不能做解析**（备案成功后才可开启访问）。
- 备案成功后 **30 日内**还需完成**公安联网备案**。

### 2.2 备案载体（最容易踩空的一步）

**OSS 本身不在可备案服务器列表中。** 阿里云备案必须关联或购买中国内地节点的合格云产品，由其生成**备案服务码**：

| 可备案产品 | 要求 | 免费服务码数量 |
|------------|------|----------------|
| 云服务器 ECS | 中国内地节点、包年包月、时长 > 3 个月（含续费累计）、需购买公网带宽 | 5 个/实例 |
| 轻量应用服务器 | 中国内地节点、包年包月、时长 > 3 个月 | 5 个/实例 |
| 云虚拟主机 | 中国内地节点、包年包月、时长 > 3 个月 | 5 个 |
| 智能建站 / 多端低代码（魔笔） | 见官方列表 | 1 个 / 按规格 |

注意：
- **免费试用 ECS 不满足备案要求**；按量付费需先转包年包月。
- 单台实例最多申请 5 个服务码，续费不增加配额。
- 服务码归属账号与备案账号不一致时可授权，但**自 2024-02-01 起仅企业认证账号可申请新服务码并授权**，个人认证账号无法授权。
- 一个阿里云账号只能备案一个主体（个人或企业）。

```bash
# 登录阿里云备案控制台检查账号下是否有合格服务器
open https://beian.aliyun.com/          # 备案主入口
open https://help.aliyun.com/zh/icp-filing/user-guide/host-instances-and-service-providers/
```

### 2.3 域名前置条件

- 域名后缀（顶级域名）**已获工信部批复**，且注册服务商已获工信部批复。
- 域名**已实名认证**，且持有者信息与备案主体**完全一致**（不一致先过户，过户后需等公示期）。
- 域名在有效期内，**距到期日 ≥ 45 天**（部分省份要求更长）。

### 2.4 流程与时长

| 阶段 | 责任方 | 预计耗时 | 关键动作 |
|------|--------|----------|----------|
| 阿里云初审 | 阿里云 | 1–2 个工作日 | 电话核验、材料完整性 |
| 工信部短信核验 | 用户 | **24 小时内**必须完成 | 手机短信验证码（超时作废重来） |
| 管局审核 | 各省通信管理局 | ≤ 20 个工作日 | 真实性核验、人脸识别 |
| 备案成功 | 管局 | 下发备案号 | **30 日内**完成公安联网备案 |

- 各省管局审核时长差异大（快的 5–7 个工作日，慢的 20 个工作日）。
- 备案通过后须在**网站页脚**展示 ICP 备案号并链接工信部，以及公安备案号。

### 2.5 常见驳回原因

1. 域名持有者与备案主体信息不一致（最高频）。
2. 证件照片模糊、翻拍屏幕、缺公章。
3. 手机号已被其它主体用于备案。
4. 网站用途描述过于笼统（如「商业用途」）—— 需写明主营业务。
5. 涉及前置审批行业（新闻、出版、教育、医疗、药品、文化等）未提交审批文件。
6. **备案期内修改了网站标题 / 关闭了网站**，触发复核。

> 官方文档：<https://help.aliyun.com/zh/icp-filing>（网站备案总览）· <https://beian.aliyun.com/>（备案控制台）

## 3. 阿里云 OSS 静态网站托管

### 3.1 为什么必须绑自定义域名

> **官方说明**：中国大陆、中国香港地区的 OSS，直接使用 OSS 默认域名从互联网访问网页类型文件（`text/html`，后缀 htm/html/jsp/plg/htx/stm）时，响应头会自动加上 `Content-Disposition: 'attachment=filename;'`，浏览器**以附件形式下载**而非在线预览；使用绑定的自定义域名访问则不会附加该头。

结论：**不绑域名 = 网站打不开（只能下载）**。中国大陆 region 的桶，绑定的域名还需完成 ICP 备案。

### 3.2 控制台配置步骤

1. OSS 控制台 → 目标 Bucket → **数据管理 > 静态页面 > 设置**
   - 默认首页：`index.html`
   - 默认 404 页：`404.html`（仅支持根目录下 html/jpg/png/bmp/webp）
   - 子目录首页：单页站保持「不开通」；多级内容站（`/blog/`、`/docs/`）才开通，开通后需设置文件 404 规则（`Redirect` / `Index` / `NoSuchKey`）
2. **Bucket 配置 > 域名管理 > 绑定域名** → 填域名 → 按提示做 DNS 校验
3. **数据管理 > 传输管理 / 权限**：确认 Bucket 为**公共读**（静态站需公开访问），或使用 CDN + 私有回源
4. 绑域名后开启 HTTPS（见第 6 节）

### 3.3 CLI 发布（增量）

`ossutil` 的 1.x / 2.x 命令与配置语义不同，**先判版本**：

```bash
ossutil version     # 输出 v1.x.x → 1.x；输出 2.x.x → 2.x
```

- 2.x：配置使用 `region`（非 endpoint），帮助用 `ossutil --help`
- 1.x：配置使用 `endpoint`（**必须地域级**，如 `oss-cn-hongkong.aliyuncs.com`；写成 bucket 级会 `no such host`），帮助用 `ossutil help`

增量发布（只上传新增/变动，不删除线上对象）：

```bash
ossutil cp -r -u ./site/ oss://<bucket>/ --force \
  --exclude ".DS_Store" --exclude "**/.DS_Store"
```

**红线**：
- **不要无保护地跑 `sync --delete`**。实测 ossutil 2.4.0 中 `sync --delete` 与 `--exclude` 组合会让删除集计算失真（本该删除的对象不会被删），既不可靠又危险。
- 删除一律**显式指定对象**：`ossutil rm oss://<bucket>/<path> --force`。
- 发布前跑 sitemap 同步闸门与断链检查（见 `init_site.py` 生成的 `deploy.sh`）。

> 官方文档：<https://help.aliyun.com/zh/oss/user-guide/hosting-static-websites>（静态网站托管）· <https://help.aliyun.com/zh/oss/user-guide/map-custom-domain-names>（绑定自定义域名）

## 4. Vercel 部署

### 4.1 官方对大陆访问的说明（照抄结论，不加戏）

Vercel 官方 Knowledge Base 明确指出：

1. **无大陆基础设施** —— Vercel 在中国大陆没有服务器或 CDN 节点，请求由邻近区域承载，延迟升高。
2. **防火墙因素** —— 网络管控可能阻断或限速境外域名，**包括 `.vercel.app` 子域**；即使未被阻断，流量也需经国际出口，速度下降。
3. **合规约束** —— 在中国境内托管需要 ICP 许可并遵守当地要求，Vercel **不提供境内托管与合规支持**。
4. **阻断按域名施加**，可能随时间变化、因 ISP 而异 —— **今天能开的域名明天可能被限速或阻断，且无通知**。

官方建议（按顺序）：改用**自定义域名**（比默认域更不易被标记）→ **自托管关键资源**（不要引 Google Fonts、境外分析脚本）→ 部署**静态镜像**或**境内双部署**（后者需 ICP 备案）。并明确：即使做了这些优化，**Vercel 无法保证大陆的可用性与性能**。

> 官方文档：<https://vercel.com/kb/guide/accessing-vercel-hosted-sites-from-mainland-china>

### 4.2 部署方式

**方式一 · Git 集成（推荐）**

1. 代码推到 GitHub / GitLab 仓库
2. Vercel 控制台 → Add New → Project → 导入仓库
3. Framework Preset 选 `Other`，Output Directory 填静态产物目录（如 `dist`、`public`、`site`）
4. 之后每次 push 自动构建发布

**方式二 · CLI**

```bash
npm i -g vercel
vercel login              # 浏览器授权，Token 由 CLI 自行落盘
vercel --prod             # 生产发布
```

- 凭证：Token 只经 CLI 授权流程写入本机配置，**不要粘贴到对话或提交进仓库**。
- **不要裸用 `VERCEL_URL`**：构建脚本里须判断 `VERCEL_ENV == "preview"` 再取，否则预览域会被写进正式产物。

### 4.3 域名与证书

Domains 面板添加**裸域与 `www` 两条**（Vercel 会自动做重定向，避免用户记错地址打不开）。校验通过后 Vercel **自动签发并自动续期**证书，通常十几分钟完成。

提示：先保留 `*.vercel.app` 默认域做排查入口 —— 访问异常时先看默认域是否正常，正常则问题在 DNS / 网络链路，不正常则回查构建。

## 5. 域名注册与解析

### 5.1 注册

- 主流后缀首年/续费参考（2026 年阿里云口径）：`.com` ¥78 / ¥85，`.cn` ¥35 / ¥39，`.net` ¥93 / ¥99，`.top` ¥12 / ¥35。**以注册页实时价为准。**
- 要备案的话，先确认后缀在**工信部批复名单**内，且注册商具备资质。
- 注册人信息直接决定能不能备案，**注册时就填对**，别等备案时才发现要过户（过户 + 公示要额外等 3–7 天）。

### 5.2 解析记录写法

| 目标 | 主机记录 | 类型 | 记录值 |
|------|----------|------|--------|
| OSS 桶（内地/香港） | `@` 与 `www` | CNAME | `<bucket>.<region>.aliyuncs.com`（以控制台显示的「外网访问域名」为准） |
| Vercel | `@` | A | `76.76.21.21`（以 Vercel Domains 面板实时提示为准） |
| Vercel | `www` | CNAME | `cname.vercel-dns.com`（同上，以面板为准） |
| 站点归属验证（Google / 必应 / 百度 DNS 方式） | `@` 或指定前缀 | TXT | 平台给出的验证串 |

- 记录值**以控制台/面板实时显示为准**，本表只用于说明形态，不照抄。
- 解析生效受 TTL 影响，几分钟到几小时不等；**未生效时不要反复删了重加**。
- 验证：`dig +short <域名> CNAME` / `dig +short <域名> A`

## 6. HTTPS 证书

### 6.1 阿里云数字证书管理服务（OSS 路线常用）

- **个人测试证书（原免费证书）**：DV 单域名，**有效期 3 个月**，每个实名主体**每自然年 20 张**，由 DigiCert 等签发。
  - 不支持：通配符、公网 IP、特殊后缀（`.edu` / `.gov` / `.org` / `.jp` / `.pay` / `.bank` / `.live` / `.nuclear` / `.ru` 等）、中文域名（vTrus 品牌）。
  - **无 SLA 保障、无 CA 安全赔付**；生产环境按需评估付费证书。
- **付费参考价（2026）**：DV 通配符约 ¥1,438.50/年起；OV 单域名约 ¥238.50/年起；OV 通配符约 ¥1,063.50/年起。以官网实时价为准。
- 申请路径：数字证书管理服务控制台 → 证书管理 → 个人测试证书（原免费证书）→ 创建证书 → 填域名 → 勾选快捷签发 → 域名所有权验证 → 下载证书。
- **到期处理**：3 个月一换，**必须建提醒**（日历或自动化），否则网站会掉 HTTPS。

> 官方文档：<https://help.aliyun.com/zh/ssl-certificate/create-a-certificate> · <https://helpcdn.aliyun.com/document_detail/28543.htm>

### 6.2 Let's Encrypt / acme.sh（替代路线）

```bash
# 安装 acme.sh
curl https://get.acme.sh | sh -s email=<你的邮箱>

# DNS-01 方式签发（适合无法做 HTTP 校验的静态托管）
export Ali_Key="<AK>" Ali_Secret="<SK>"
~/.acme.sh/acme.sh --issue --dns dns_ali -d example.com -d www.example.com
```

- 证书 90 天有效，acme.sh 装好后会**自动续期**。
- **难点在部署**：OSS 不会自动读取本地证书文件，续期后需重新上传到 OSS 的自定义域名证书配置 —— 需自建续期后自动上传的脚本，否则续期等于没做。
- AK/SK 供 DNS 校验使用，**不要写进仓库文件**，用环境变量或本机配置。

### 6.3 Vercel 路线

绑定域名后**全自动**签发与续期，无需任何操作，也无需提供私钥或 CSR。

## 7. 上线后验证清单

按顺序执行，全部通过才算发布成功：

```bash
D=<你的域名>

# 1. 解析是否生效
dig +short $D CNAME; dig +short $D A

# 2. HTTPS 与状态码（-I 只看头，避免拉全量）
curl -sI https://$D | head -1
curl -s -o /dev/null -w '%{http_code}\n' -L --max-time 15 https://$D

# 3. 关键辅料可公开访问
for p in robots.txt sitemap.xml favicon.ico; do
  printf '%-14s %s\n' "$p" "$(curl -s -o /dev/null -w '%{http_code}' -L https://$D/$p)"
done

# 4. 首页 head 关键标签
curl -s https://$D | grep -oE '<title>[^<]*</title>|rel="canonical"|og:image' | head

# 5. www 与裸域是否都能到
curl -s -o /dev/null -w 'www: %{http_code}\n' -L https://www.$D
```

| 检查项 | 通过标准 |
|--------|----------|
| 解析 | 返回预期记录值，非空 |
| 状态码 | `200`（301 跳转到规范域也可接受） |
| HTTPS | 无证书告警；`curl` 不报 SSL 错误 |
| robots / sitemap / favicon | 三个都是 `200`，不是 `403`（对象权限）/ `404` |
| 页面预览 | 浏览器**在线显示**而非弹出下载（若弹出下载 → 未绑自定义域名） |
| 移动端 | 真机或 DevTools 移动视图无横向滚动、字号可读 |
| 控制台 | 无 404 资源、无 JS 报错 |
| 备案 | 内地节点：页脚已挂 ICP 备案号 + 公安备案号并可点击 |
