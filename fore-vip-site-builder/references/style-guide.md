# 官网风格规范（三档高档模板）

> 目标：**看起来贵，且不靠装饰**。「高档」来自克制的排版、稳定的间距节奏、单一强调色与恰当留白，而不是渐变堆砌、阴影套阴影、满屏动效。

## 1. 高级感从哪来

| 来源 | 具体做法 |
|------|----------|
| **留白** | 大区块上下留白 ≥ 96px（移动端 ≥ 64px）；宁可少放内容，不挤 |
| **字号反差** | 头屏标题与正文拉开 2.5–4 倍差距，中间不设「差不多大」的层级 |
| **单一强调色** | 全站只用一个强调色，且只用在 CTA、关键数字、链接上；别给每个模块不同颜色 |
| **对齐** | 所有元素对齐到一套栅格；宁可少一个元素，不错半个像素 |
| **克制的圆角** | 全站统一一套圆角（如 0 / 8 / 16），不混用 |
| **边界清晰** | 用 1px 细线或色块区分区域，而不是靠重阴影 |
| **一致的图标** | 用一套图标（线性 or 填充，不混），尺寸统一 |
| **真内容** | 不写「Lorem ipsum」，不写「行业领先的解决方案提供商」这类空话 |

## 2. 三档风格定义

| 代号 | 名称 | 底色 | 文字 | 强调 | 特征 |
|------|------|------|------|------|------|
| `noir` | 极简科技暗色 | `#0b0d10` | `#e8eaed` | 单色高光（默认 `#e53e3e`） | 大字号、细分割线、无圆角或小圆角、适合 AI/工具/技术产品 |
| `paper` | 商务留白浅色 | `#ffffff` | `#14171a` | 深色为主（默认 `#14171a`） | 衬线标题、细线分区、大留白、适合企业/咨询/法律/财务 |
| `brand` | 品牌活力 | `#ffffff` + 浅色渐变衬底 | `#101418` | 主色渐变 | 圆角卡片、轻动效、适合消费产品/活动/内容站 |

三档**共用同一套组件 CSS**，只换令牌 —— 这是「换风格不改结构」的关键。

选型话术（给用户的弹窗描述）：

- `noir`：深色底、大标题，像专业工具与 AI 产品。
- `paper`：白底细线、留白多，像正经企业的官方站。
- `brand`：明亮、有主色与卡片，友好、面向年轻用户。

## 3. 设计令牌

用 CSS 变量定义，主题文件只覆盖变量，**不改组件规则**。

```css
:root {
  /* 色 */
  --bg: #ffffff;
  --bg-soft: #f6f7f9;        /* 次级区块背景 */
  --fg: #14171a;             /* 主文字 */
  --fg-muted: #5b6472;       /* 次要文字，对比度仍需 ≥ 4.5:1 */
  --line: #e3e6ea;           /* 分割线 */
  --accent: #e53e3e;         /* 强调色，全站唯一 */
  --accent-fg: #ffffff;      /* 强调色上的文字 */

  /* 圆角 */
  --r-sm: 6px;
  --r-md: 12px;
  --r-lg: 20px;

  /* 间距节奏（8pt） */
  --s-1: 4px;  --s-2: 8px;   --s-3: 12px;  --s-4: 16px;
  --s-5: 24px; --s-6: 32px;  --s-7: 48px;  --s-8: 64px;
  --s-9: 96px; --s-10: 128px;

  /* 版心与字体 */
  --wrap: 1120px;
  --font-sans: -apple-system, "PingFang SC", "Hiragino Sans GB",
               "Microsoft YaHei", system-ui, sans-serif;
  --font-serif: Georgia, "Songti SC", "Noto Serif SC", serif;
  --font-mono: ui-monospace, "SF Mono", Menlo, monospace;

  /* 动效 */
  --ease: cubic-bezier(.2, .7, .2, 1);
  --dur: 300ms;
}
```

**自定义主色**：`init_site.py --brand "#1f6feb"` 会只替换 `--accent`，其余不动。
**对比度硬要求**：`--accent` 与 `--accent-fg` 对比度 ≥ 4.5:1；`--fg-muted` 与 `--bg` ≥ 4.5:1。

## 4. 排版尺度

| 层级 | 桌面 | 移动 | 字重 | 行高 | 用途 |
|------|------|------|------|------|------|
| Display | 64px | 36px | 600 | 1.1 | 头屏主标题（每页仅一处） |
| H1 | 44px | 30px | 600 | 1.2 | 页面标题 |
| H2 | 30px | 24px | 600 | 1.3 | 区块标题 |
| H3 | 20px | 18px | 600 | 1.4 | 卡片/条目标题 |
| Body | 17px | 16px | 400 | 1.75 | 正文 |
| Small | 14px | 14px | 400 | 1.6 | 辅助说明 |
| Eyebrow | 13px | 12px | 600 | 1.4 | 区块上方小标签，**加 0.08em 字距 + 大写/全角转换** |

规则：

- **中文行高 ≥ 1.7**（比英文要松）。
- 正文单行字数控制 **28–40 个汉字**（约 `max-width: 34em`）。
- 标题不要用纯 `font-weight: 700` 猛加粗；中文 600 已足够，靠字号与留白拉开层级。
- `font-feature-settings` / 字距微调只在标题上做，正文不做。

## 5. 间距与栅格

- **节奏**：所有间距取自 `--s-*`（8 的倍数），不出现 13px / 27px 这类随手值。
- **版心**：`--wrap: 1120px`，超出居中；内容区左右内边距桌面 32px、移动 20px。
- **区块**：上下 `--s-9`（96px），移动 `--s-8`（64px）。
- **卡片网格**：`grid` + `repeat(auto-fit, minmax(280px, 1fr))`，`gap: var(--s-5)`。
- **分隔**：用 `border-top: 1px solid var(--line)`，不用重阴影。
- **移动端**：单列；禁用横向滚动（`overflow-x: hidden` 只作兜底，根因是元素超宽）。
- **触控目标**：≥ 44×44px。

## 6. 动效

**原则：只做「出现」和「反馈」两种，不做「炫技」。**

```css
/* 进入视口淡入上移 —— 用 IntersectionObserver 加 .is-in，不做滚动监听 */
.reveal { opacity: 0; transform: translateY(16px);
          transition: opacity var(--dur) var(--ease), transform var(--dur) var(--ease); }
.reveal.is-in { opacity: 1; transform: none; }

/* 悬停反馈 */
.btn { transition: transform 160ms var(--ease), box-shadow 160ms var(--ease); }
.btn:hover { transform: translateY(-1px); }

@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
```

- 位移 ≤ 16px，时长 200–400ms，缓动用 `--ease`。
- **必须有 `prefers-reduced-motion` 兜底**。
- **无 JS 也要能看** —— `.reveal` 的初始 `opacity: 0` 要在无 JS 时失效（用 `<noscript>` 兜底样式或默认可见 + JS 再加类）。
- 不做视差、不做自动轮播、不做鼠标跟随。

## 7. 页面结构范式

### 主页（从上到下）

| # | 区块 | 内容要点 |
|---|------|----------|
| 1 | 顶栏 | 品牌名 + 导航（≤ 5 项）+ 主 CTA；移动端收起为菜单 |
| 2 | 头屏 | Eyebrow 标签 → **一句话价值主张**（Displa​y 级）→ 2 行补充 → 主次两个 CTA |
| 3 | 卖点 | 3–4 条，每条：图标 + 小标题 + 一句解释 |
| 4 | 能力 / 场景 | 2–4 张卡片，或图文左右交替排列（≥ 3 屏内容就左右交替，避免单调） |
| 5 | 数据 / 背书 | 2–4 个关键数字（加粗放大），或客户名与证言 |
| 6 | 常见问题 | 3–6 条 `details/summary`，**零 JS** 折叠 |
| 7 | 转化区 | 一个明确动作：留联系方式 / 加微信 / 下载 / 试用 |
| 8 | 页脚 | 三栏（关于 / 导航 / 联系方式）+ 版权 + **ICP 备案号（内地节点必挂）** |

### 业务功能页

- 页内独立 `title` / `description` / `canonical`。
- 结构：功能一句话定义 → 解决什么问题 → 怎么运作（3 步）→ 能力明细 → FAQ → CTA。
- 与主页互链（主页卡片 → 功能页；功能页 → 主页 CTA），保证 3 次点击可达。

## 8. 禁忌清单

| 禁止 | 原因 |
|------|------|
| 每个模块换一种强调色 | 视觉失焦，显得廉价 |
| 满屏渐变 + 多重阴影 + 玻璃拟态叠加 | 三选一即可，叠加即廉价 |
| 正文用纯黑 `#000` 或纯白 `#fff` 大面积 | 刺眼；用 `--fg` / `--bg` 的柔和值 |
| 用 `robots` 或图片承载关键文字 | 搜索引擎抓不到 |
| 首屏放轮播图 | 转化率低、拖慢加载、移动端体验差 |
| 自动播放带声音的视频 | 违反用户预期 |
| 生造图标风格不一 | 一眼看出拼凑 |
| 中文用 `letter-spacing` 大范围拉开 | 中文不是英文，拉字距会碎 |
| 文案出现「最 / 第一 / 唯一 / 保证收益 / 包过 / 国家级」 | 违反广告法，且平台会判低质 |
| 文案出现技术黑话与内部路径 | 面向普通访客的页面应零技术词 |
| 用 `{{占位符}}` 上线 | 发布闸门会拦，且用户看到会判定「没做完」 |
| 空 `alt`、空链接 `href="#"` | 可访问性与 SEO 双失分 |
