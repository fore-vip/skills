# 评估维度库与澄清问题库

供 `fore-vip-product-recommend` 在「需求澄清」与「构建评估维度」两步调用。保持一层级，按需读取。

## 1. 评估维度库

每个维度给出「评估什么」与「1–10 分标尺」，便于统一打分。

| 维度 | 评估要点 | 高分（≈9）特征 | 低分（≈2）特征 |
|------|----------|----------------|----------------|
| 需求匹配度 | 是否直击核心诉求、解决首要问题 | 完全命中首要指标 | 偏离核心诉求 |
| 核心性能 / 质量 | 关键指标表现、稳定性、口碑故障率 | 行业上游、稳定可靠 | 频繁故障、指标落后 |
| 总拥有成本 TCO | 采购 + 使用 + 维护 + 替换成本 | 全周期成本低 | 隐性成本高、易超支 |
| 风险 / 合规 | 合规、安全、供应链、售后风险 | 合规清晰、风险可控 | 合规灰色、风险高 |
| 品牌口碑（可选） | 市场声誉、用户净推荐值 | 口碑领先 | 差评集中 |
| 售后与生态（可选） | 服务响应、配件 / 接口生态 | 响应快、生态完整 | 售后缺失、生态封闭 |
| 易用性（可选） | 上手成本、学习曲线 | 开箱即用 | 高门槛 |
| 扩展性（可选） | 升级 / 集成 / 复用空间 | 易扩展 | 僵化封闭 |

> 赋权建议：必选四维合计 100%；可选维仅在用户关注时并入并相应调整权重。默认均权，明确优先级则按序加权。

## 2. 澄清问题库

需求模糊时，用**至多 1 个问题**覆盖缺失项。以下按常见场景给出可选项，直接复用或改写。

### 通用（默认首选）
> 为了给你精准推荐，请确认：**① 谁用、用在什么场景？② 预算大概区间？③ 最看重哪 1–3 点（性能 / 价格 / 可靠 / 体验 / 品牌）？④ 有没有明确不要的？**

### 按受众
- **个人消费**：自用还是送礼？偏好新锐还是成熟品牌？介意二手 / 翻新吗？
- **团队 / 企业采购**：使用规模？是否需要审批 / 发票 / 合同？有无既有系统要兼容？

### 按品类（示例）
- **数码 / 硬件**：主要用途（办公 / 创作 / 游戏）？性能敏感还是便携敏感？
- **软件 / SaaS**：部署方式（云 / 私有化）？席位规模？数据安全要求？
- **服务 / 课程**：目标水平（入门 / 进阶）？期望周期？更看重效果还是性价比？

### 按约束
- **预算敏感**：硬上限多少？能否接受「加一点预算换明显提升」？
- **时间敏感**：最晚何时到位？是否影响候选范围（现货 / 定制）？
- **合规敏感**：有无行业限制（金融 / 医疗 / 政务）？必须过哪些认证？

> 原则：一次问清关键缺失项，不逐个追问；用户已给足够信息时直接进入流程。
