# 轻娱乐赛道创业落地工具

## 适用角色

| 角色 | 典型场景 |
|---|---|
| VR体验馆投资者 | 看中某商圈，需算投资+回本+选址风险 |
| 微短剧投流投手 | 有剧本/成片，需算投流ROI+预算分配 |
| 综艺二创创作者 | 想做切片二创，需查合规+变现路径 |
| 沉浸式文旅项目方 | 有场地/IP，需设计体验流程+定价 |

## 能力1：VR体验馆选址与投资测算

### 选址评估表

| 维度 | 评分标准 | 权重 |
|---|---|---|
| 人流量 | 工作日日均>2000 / 周末>5000 | 30% |
| 客群匹配 | 18–35岁占比>60% | 20% |
| 租金占比 | 月租/预估月营收 <25% | 25% |
| 竞品密度 | 3km内同类VR馆<3家 | 15% |
| 停车/交通 | 地铁500m内或有停车场 | 10% |

### 投资测算模板

| 项目 | 金额 | 说明 |
|---|---|---|
| 设备采购 | 8–25 万 | 4–8台VR头显（PICO/Meta Quest）+主机+座椅 |
| 装修硬装 | 3–10 万 | 隔音/暗场/安全地垫 |
| 租金押付 | 3–6 万 | 押二付三 |
| 内容授权 | 1–3 万/年 | 按设备数付费 |
| 开业营销 | 1–2 万 | 美团/抖音本地推 |
| **总投资** | **15–45 万** | 视规模而定 |

### 回本测算

| 月营收 | 月成本 | 月净利 | 回本周期 |
|---|---|---|---|
| 3 万（日均1000元） | 1.5 万 | 1.5 万 | 10–30 月 |
| 5 万（日均1700元） | 2 万 | 3 万 | 5–15 月 |
| 8 万（日均2700元） | 2.5 万 | 5.5 万 | 3–8 月 |

### 关键风险
- 设备折旧 2–3 年，技术迭代快（MR设备可能淘汰VR）
- 复购率低（<20%），严重依赖新客获客
- 内容更新成本高，无新内容=无回头客
- 需《娱乐经营许可证》+消防验收

## 能力2：微短剧投流ROI计算

### 投流ROI公式

```
ROI = 充值收入 / 投流成本
盈亏线：ROI ≥ 1.0（充值=投流时保本，因还有制作+分成成本）
健康线：ROI ≥ 1.3
爆款线：ROI ≥ 2.0
```

### 预算分配

| 环节 | 占比 | 说明 |
|---|---|---|
| 投流买量 | 60–80% | 巨量引擎73% / 腾讯广告17% / 快手8% |
| 制作成本 | 10–20% | 拍摄+后期（竖屏短剧 1–5 万/部） |
| 平台分成 | 10–15% | 小程序/APP抽成 |
| 投流测试预算 | 首批 3000–5000 元 | 测素材+测人群包 |

### 投流决策树

```
首批测试 ROI？
├─ <0.5 → 素材/剧本有问题，止损不追投
├─ 0.5–0.8 → 调人群包+换素材，二次测试
├─ 0.8–1.2 → 临界，微调后小额追投
└─ >1.2 → 追投放量，设日预算上限防风险
```

### 合规红线
- 必须备案（广电总局微短剧备案制）
- 禁投未备案剧、违规内容
- 投流素材不得低俗擦边，平台会封号扣量

## 能力3：综艺二创合规自查与变现

### 合规检查清单

| 检查项 | 要求 | 不通过的后果 |
|---|---|---|
| 素材来源 | 使用抖音二创授权计划正版素材 | 侵权赔偿可达千万级 |
| 原创观点占比 | >50% 须有解说/评论/分析 | 纯搬运会被限流/下架 |
| 时长限制 | 单条切片≤5分钟 | 超长可能被判定侵权 |
| 标注来源 | 需注明原节目名/期数 | 平台判定为无源搬运 |
| 内容导向 | 不得断章取义/恶意剪辑 | 被原节目方投诉下架 |

### 变现路径

| 路径 | 门槛 | 收益 |
|---|---|---|
| 创作者激励 | 粉丝>1万，播放量达标 | 千次播放 5–20 元 |
| 星图商单 | 粉丝>10万 | 单条 2000–2 万 |
| 带货挂车 | 粉丝>1000+保证金 | 佣金 10–30% |
| 综艺宣发合作 | MCN对接综艺方 | 按项目计费 |

## 能力4：沉浸式文旅体验设计

### 体验设计模板

| 要素 | 设计要点 | 案例 |
|---|---|---|
| 主题/IP | 本地文化+情绪共鸣 | 宋韵/赛博/国潮 |
| 时长 | 30–90 分钟（>90 分钟疲劳） | 45分钟最优化 |
| 客单价 | 68–168 元（下沉）/ 168–388 元（一二线） | 亲子套票更优 |
| 互动节点 | 每 5–8 分钟一个互动触发点 | 解谜/体感/AR |
| 社交货币 | 必须有 1 个"值得拍照发朋友圈"的节点 | 网红打卡墙 |
| 复购设计 | 多结局/季节限定/角色扮演 | 二刷率提升 15%+ |

### 投资参考

| 规模 | 投资区间 | 回本周期 |
|---|---|---|
| 小型体验展（200㎡内） | 10–30 万 | 6–12 月 |
| 中型沉浸空间（500㎡） | 30–80 万 | 8–18 月 |
| 大型沉浸式项目（1000㎡+） | 100–300 万+ | 12–24 月 |

### 风险提示
- 内容迭代成本高，无更新=无复购
- 选址依赖强，商圈流量决定生死
- 消防/安全/未成年人保护合规需提前办理
