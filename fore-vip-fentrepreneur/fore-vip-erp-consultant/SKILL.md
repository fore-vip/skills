# ERP 选型与实施顾问工具

面向 ERP 选型顾问、实施顾问、渠道代理商的落地执行工具。用一套「客户分诊 → 选型匹配 → 报价测算 → 实施交付 → 合规自检」流程，把一次 ERP 项目从售前到验收跑通。

## 一、适用角色与场景

| 角色 | 典型场景 | 用本 SKILL 做什么 |
|---|---|---|
| 选型顾问 / 代理商 | 中小企业要上 ERP，拿不准用哪家 | 按客户画像快速匹配产品并出报价 |
| 实施顾问 / 项目经理 | 接单后做交付 | 按 SOP 推进蓝图、配置、上线、验收 |
| 跨境 ERP 服务商 | 跨境卖家多系统割裂、要全渠道打通 | 评估集成痛点、匹配跨境 ERP |
| 信创项目投标方 | 央国企/关键行业国产化替代 | 合规自检、配套国产软硬件清单 |

## 二、能力模块

### 模块 1 — 客户分诊与选型匹配器

先收集客户四个字段，再走决策树。

**必问四项输入：**
1. 员工规模（<30 / 30–500 / 500+）
2. 所属行业（制造 / 贸易零售 / 跨境电商 / 服务业 / 央国企）
3. 预算区间（年投入）
4. 核心痛点（财务核算 / 进销存 / 生产排程 / 多系统集成 / 信创合规）

**选型决策树（按规模 + 行业交叉）：**

| 客户画像 | 推荐产品 | 说明 |
|---|---|---|
| <30 人，纯财务/进销存 | 金蝶云星辰、用友畅捷通、管家婆 | 轻量，年费数千–数万 |
| 30–500 人，制造业 | 金蝶云星空、用友 U8C、鼎捷 T100 | 中端主力，生产模块齐 |
| 30–500 人，贸易/服务 | 用友 U8C、金蝶云星空、NetSuite | 中端市场碎片化，议价空间大 |
| 跨境电商卖家 | 领星、马帮、积加、易仓 | 跨境 ERP 2024 年 13.2 亿市场，集成是刚需 |
| 500+ 人 / 集团 | SAP S/4HANA、用友 NC、金蝶苍穹 | 高端格局 SAP 33%、Oracle 20%、用友 14%、金蝶 6% |
| 央国企 / 信创 | 用友、金蝶、浪潮、鼎捷 | 2027 年底前央国企 100% 替代 |

**输出：** 一份「选型建议单」——推荐主产品 + 备选产品 + 匹配理由（引用客户痛点）+ 预估预算档。

### 模块 2 — 报价与实施周期测算器

报价 = License/订阅费 + 实施费 + 年维保费。实施费通常为 license 的 0.8–1.5 倍。

| 客户档位 | 订阅/许可费（参考区间） | 实施费 | 实施周期 |
|---|---|---|---|
| 小微（<30 人） | 0.3–3 万/年 | 0.5–3 万 | 1–2 个月 |
| 中小（30–500 人） | 20–150 万（含实施） | 含于总包 | 3–6 个月 |
| 大型/集团 | 100 万–千万级 | 按人天另计 | 6–18 个月 |
| 跨境 ERP | 数千–数万/年（订阅） | 轻实施 | 2–6 周 |

> 区间为行业常见水平，实际以厂商报价与二开量为准；报价前必须先做需求访谈，避免范围蔓延吞掉利润。

**报价单三要素（缺一不可）：**
1. 模块范围清单（明确含/不含哪些模块）
2. 实施人天上限 + 超出人天单价
3. 验收标准（以 UAT 通过为准）

### 模块 3 — 信创国产化替代合规自检

适用央国企及关键行业项目。逐项打勾：

- [ ] ERP 本体为国产（用友/金蝶/浪潮/鼎捷等）
- [ ] 配套操作系统：统信 UOS / 麒麟
- [ ] 配套数据库：达梦 / 人大金仓 / 高斯
- [ ] 配套中间件：东方通 / 宝兰德
- [ ] 通过信创目录适配认证
- [ ] 项目在 2027 年底前完成（硬约束节点）

**提示：** 国产替代的难点不在软件本身，而在「行业 know-how + 生态整合」；纯靠堆国产软硬件清单无法中标，需在投标书中附同类行业成功案例。

### 模块 4 — 实施交付 SOP 与风险红线

**六阶段 SOP：**

| 阶段 | 周期 | 关键动作 | 交付物 |
|---|---|---|---|
| 售前调研 | 2–4 周 | 需求访谈、现状流程梳理 | 需求清单 |
| 蓝图设计 | 2–6 周 | 业务流程蓝图、模块范围冻结 | 蓝图文档 |
| 配置与二开 | 4–12 周 | 系统配置、必要二次开发 | 配置原型 |
| 测试与培训 | 2–4 周 | UAT、关键用户培训 | 测试报告 |
| 上线切换 | 1–2 周 | 数据迁移、并行/切换 | 上线确认单 |
| 验收与运维 | 持续 | 验收、SLA 运维 | 验收单 |

**风险红线（触发即升级）：**
1. **数据迁移**：历史数据清洗不到位是上线失败头号原因，迁移前必须做数据质量审计。
2. **范围蔓延**：蓝图冻结后任何新增需求走变更单并重估人天，不口头答应。
3. **集成割裂**：95.1% 跨境商家在用 2 个以上系统、仅 20.8% 打通全渠道——集成方案要在蓝图期就定，不放到上线后补。
