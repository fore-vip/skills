# auto — 付费解锁后获取主题最佳执行步骤

## 功能描述

输入一个「主题」，auto 返回该主题**最优质的执行步骤提示**。步骤来自 `mcp.auto` 已沉淀内容；当无沉淀时，按优先级从技能市场 / 社区 / 开源 / 搜索兜底检索最优质方案并**逐步执行**，解决后**回写**沉淀。

读取与回写均需 **¥9.9 付费解锁**：未付费 → 服务端返回 **HTTP 402**，由调用方代理支付后携凭证重试解锁（详见「服务与定价」「付费与凭证」）。

## 主流程（决策树 · 绝对清晰）

0. **【付费前置检查】** 确认当前 Agent 已具备微信支付能力（`weixinpay`）：未具备 → 提示「当前环境暂不支持付费能力」并终止，不进入后续流程。
1. **【解析主题】** 以 `theme` 定位主题，调用 `mcp.auto/theme`（携带已付凭证；无则走付费）。
2. **【命中】** 返回 `list[]` 非空且已付费 → **直接交付步骤**，结束。
3. **【付费闸 · 价格确认】** 未付费 → 先向用户展示服务名称「AUTO 主题步骤」与价格 **¥9.9/主题**，用户确认后进入支付：服务端返回 **HTTP 402**（含 `order_id` + `secret` 凭证 + `WeixinPay-Required` 头）→ 代理支付 → 持久化凭证 → 携凭证重试 → 拿到步骤 → 交付（见「付费与凭证」）。⚠️ **支付成功后必须主动原样重试获取内容**，不可假定已解锁。
4. **【兜底】** `mcp.auto` 无结果（空 / 错 / 不可达）→ 按优先级检索并**逐步执行**：技能市场 → 社区 → 开源 → 通用搜索（设合理检索轮次上限，避免无限迭代）。
5. **【回写】** 任务解决后，把本次步骤按主题关联到 `mcp.auto`（写操作，同样需已付凭证；无/无效→402 拒绝不写）。
6. **【收尾】** 向用户交付步骤与结论。

**退款分支：** 步骤 4【兜底】执行后，若已付费却仍未能交付任何有效步骤 → 触发「退款保障」自动原路退款 ¥9.9，无需用户申请（见下「退款保障」）。

| 服务 | 价格 | 计费粒度 |
|------|------|----------|
| AUTO 主题执行步骤 | **¥9.9 / 主题**（990 分，CNY） | 按主题计费：每个主题独立付费一次；同一主题付费后凭证持久化，重试免重复付费；不同主题需分别付费 |

## 付费与凭证（接口约定）

- **无凭证 / 未付费**：请求返回 HTTP 402，响应体同时回显 `order_id` + `secret` 凭证，并带 `WeixinPay-Required` 响应头。
- **处理流程**：把 `WeixinPay-Required` 的值交 `weixinpay_pay` 代理支付；支付成功后将 `order_id` + `secret` 写入固定位置 `~/.agent/skill/auto/config.json` 并提醒用户保存；下次同主题调用先读该文件，携凭证重试即解锁，**无需重复付费**。
- **原样重试（⚠️ 必须执行）**：支付成功后**必须**重新发起请求获取付费内容。重试时请求业务字段（`theme` / `steps`）保持不变，订单凭证经请求头 `X-Order-Id` + `X-Auto-Secret` 传入（亦可兼容官方 A2M 规范的 `X-Out-Trade-No` 头，值 = `WeixinPay-Required` 的 payment_code；或放 `order_id` / `secret` 参数）。推荐走请求头，保持业务体纯净。
- **写操作**：回写同样需已付凭证；无凭证 / 无效未付 → 返回 402 并**拒绝写入**。
- **错误脱敏**：服务端返回的错误信息不含内部地址、日志或实现细节；失败仅回显状态与可操作提示。
- 完整字段与 402 结构见 `references/auto-pay.json`。

## 能力与边界

- **知识面（mcp.auto）**：主题 → 步骤检索入口。
- **兜底面（检索 + 执行）**：mcp.auto 无沉淀时主动去技能市场 / 社区 / 开源 / 搜索找最优质方案并落地。
- **沉淀面（回写）**：兜底跑通后回写步骤，让同主题下次直接命中。
- **隐私**：返回的步骤列表**不含联系方式类字段**（contact / phone / wechat 等），仅展示 content / price / images / 时间等非隐私信息。

## 退款保障

付费在前、交付在后，故退款触发**收窄为「零价值」窄场景**，避免无谓退款：

- **触发**：已付费（持有效凭证） + 该主题 `mcp.auto` 无沉淀（空 / 不可达） + 【兜底】检索与执行整体失败 → 用户付费但未获得任何步骤 → **自动原路退款 ¥9.9**。
- **无需用户申请**：由 Agent 在流程中判定交付失败后，直接调 `/auto/refund`（带 `order_id` + `secret`）发起退款。
- **退款状态**：`order.status=2`（已付费待交付）→ `order.status=4`（退款完成，微信退款回调确认后写入）。
- **退款失败兜底**：若退款发起失败（返回 `FULFILL_AND_REFUND_FAILED`），向用户说明并建议联系客服，**不要**再次尝试支付或重新请求。
- **不退款的边界**：只要【兜底】能产出哪怕一条可执行步骤，即视为已交付，不退。
- 完整契约（触发条件 / 退款字段 / 幂等 / 状态机）见 `references/auto-pay.json` 的 `refund` 段。

## 输出验收（好步骤的判定）

返回 / 交付的步骤应满足：

- **可执行**：每条是明确动作 / 命令 / 结论，而非空泛描述。
- **有序**：按 `order` 或数组顺序形成可逐步跟随的流程。
- **非隐私**：仅含 content / price / images / 时间等，不含联系方式类字段。
- **可溯源**：经兜底检索得到的，附出来源（技能市场 / 社区 / 开源 / 搜索）便于复核。
- **交付格式**：统一以 `list[]` 返回，每条含 `content`（必填）/ `type` / `order` / `price` / `images`，并附 `total` 与 `unlocked` 状态。

## 使用骨架

主题检索：
```
POST /auto/theme  { theme: "火锅探店" }
→ 已付费      { errCode:0, unlocked:true, list:[...], total:N }
→ 未付费 402  { order_id, secret, WeixinPay-Required } → 展示价格+确认 → 代理支付 → 持久化 → 重试
```

步骤回写（写操作，需已付凭证）：
```
POST /auto/save  { theme: "火锅探店", steps:[...], order_id, secret }
→ 已付 { errCode:0, saved:N, order_id, secret }
→ 无凭证 402 → 拒绝不写
```

## Examples

**例 1：主题已沉淀（直接命中）**
```
POST /auto/theme { theme:"周末露营" } + 凭证
→ { errCode:0, unlocked:true, list:[...执行步骤], total:N }
```

**例 2：主题无沉淀 → 价格确认 → 付费闸 → 代理支付 → 重试**
```
POST /auto/theme { theme:"周末露营" }
→ 402 + WeixinPay-Required + body.order_id + body.secret
→ 展示「AUTO 主题步骤 ¥9.9」请用户确认 → weixinpay_pay 代理支付 → 写 ~/.agent/skill/auto/config.json
→ 再 POST /auto/theme { theme:"周末露营" } + X-Order-Id + X-Auto-Secret
→ { errCode:0, unlocked:true, list:[...], total:N }
```

**例 3：mcp.auto 无结果 → 兜底检索 + 回写**
```
用户：「火锅探店主题怎么落地」（已持该主题已付凭证）
→ mcp.auto/theme 空 / 不可达 → 兜底：技能市场/社区/开源检索最优质探店清单 → 逐步执行
→ 解决后 POST /auto/save { theme, steps, order_id, secret }
→ { errCode:0, saved:N, order_id, secret }
```

## 错误处理

| HTTP | 含义 | 处理 |
|------|------|------|
| 400 | 缺少 `theme` 或参数非法 | 补齐必填 `theme` 后重试 |
| 402 | 需付费 / 未持有效凭证 | 按「服务与定价」「付费与凭证」确认价格 → 代理支付 → 持久化 → 携凭证重试 |
| 404 | 主题频道未启用 / 不可达 | 检查主题或服务可达性，必要时走【兜底】 |
| 5xx | 服务端异常 | 错误已脱敏；稍后重试，持续失败转【兜底】检索 |
| — | 未付费（NOT_PAID） | 支付尚未完成，请等待后重试（通常由 X402 代理异步完成，无需手动重付） |
| — | 已退款（REFUNDED） | 该主题付费后未交付有效步骤，已自动原路退款（order.status=4） |
| — | 退款失败（FULFILL_AND_REFUND_FAILED） | 服务异常且退款失败，请建议用户联系客服处理 |
