# 前凌智选 Chrome 插件（fore-ex）

前凌智选 Chrome 浏览器插件 —— 在浏览器里浏览户外活动、发现优质内容，一键跳转到活动详情页，并直达密钥管理页获取 API 密钥。

## 下载安装

### 国内用户（推荐）

从静态网站下载最新版本：

- 下载链接：https://f.fore.vip/download/fore-ex-v2.0.zip
- 文件大小：约 90KB

若下载链接暂未更新，可直接用「开发者模式」加载源码目录（见下方安装教程）。

### 国际用户

从 GitHub 仓库获取源码：https://github.com/fore-vip/fore-ex

## 安装教程

### 方式一：开发者模式安装（推荐）

1. 下载插件包并解压到任意目录
2. 打开 Chrome 扩展管理页：地址栏访问 `chrome://extensions/`，或菜单 → 更多工具 → 扩展程序
3. 右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选择含 `manifest.json` 的 `fore-ex` 文件夹
5. 验证：插件出现在列表、图标出现在工具栏、状态「已启用」
6. （可选）点击右上角「🧩」→ 找到「前凌智选」→ 点「📌」固定到工具栏

### 方式二：Git 克隆安装（开发者）

```bash
git clone git@github.com:fore-vip/fore-ex.git
cd fore-ex
# 然后按方式一第 2-4 步加载
```

## 功能特性

| 功能 | 说明 |
|------|------|
| 活动搜索 | 按关键词搜索活动 |
| 活动列表 | 展示封面、内容、地址、标签、浏览/参与数 |
| 封面展示 | 卡片顶部显示活动封面（图片加载失败自动隐藏） |
| 点击跳转 | 点击卡片直达活动详情页 |
| 无限加载 | 滚动自动加载更多活动 |
| 发布引导 | 菜单「发布活动」直达密钥管理页，获取 API 密钥 |

## 使用指南

1. 点击浏览器右上角插件图标
2. 在搜索框输入关键词（可选）
3. 浏览自动加载的活动列表
4. 点击卡片跳转活动详情页，可截图、复制链接
5. 向下滚动自动加载更多

### 如何发布活动？

插件本身不直接创建活动。点击菜单「发布活动」→ 打开密钥管理页 → 登录后生成 / 复制 API 密钥，即可在 Web 端或 AI 助手里创建自己的活动。

## 常见问题

### 插件无法加载？

- 已解压 ZIP，不要直接从压缩包加载
- 选择的是包含 `manifest.json` 的文件夹
- 已开启「开发者模式」
- 文件夹路径不含中文或特殊字符

### 活动列表打不开 / 空白？

- 检查网络连接
- 改过源码后需在 `chrome://extensions/` 点刷新重新加载

### 如何更新插件？

下载最新 ZIP 解压覆盖原目录，在 `chrome://extensions/` 点插件卡片上的「刷新」。

### 数据是否安全？

- 仅读取活动列表所需的最少信息
- 所有传输使用 HTTPS 加密
- 不存储用户隐私数据

### 如何卸载？

`chrome://extensions/` → 找到「前凌智选」→ 点「移除」。
