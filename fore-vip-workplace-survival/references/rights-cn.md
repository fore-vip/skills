## 一、入职与劳动合同

| 事项 | 要点 |
|------|------|
| 书面合同 | 用工之日起**一个月内**应订立书面劳动合同；超过一个月不满一年未订立的，劳动者可主张**二倍工资**（各地起算与截止口径不同，需按当地规定核实） |
| 试用期上限 | 合同期 3 个月以上不满 1 年 → 不超过 1 个月；1 年以上不满 3 年 → 不超过 2 个月；3 年以上及无固定期限 → 不超过 6 个月。同一用人单位与同一劳动者**只能约定一次**试用期 |
| 试用期工资 | 不低于**本单位相同岗位最低档工资**或**合同约定工资的 80%**，且不低于当地最低工资标准 |
| 试用期辞退 | 也需**法定理由与证据**（如不符合录用条件），不能随口一句「不合适」。录用条件最好事先书面告知 |

**动作**：入职当天拿到合同原件或清晰扫描件；Offer 里承诺的薪资、职级、汇报关系、年终与补贴，全部要求写进合同或书面确认。

## 二、工资与加班

| 事项 | 要点 |
|------|------|
| 加班费倍率 | 工作日延长工时 **150%**；休息日安排工作且**不能安排补休** **200%**（能补休的应安排补休）；法定节假日 **300%** |
| 日工资折算 | 常用口径为月工资 ÷ **21.75**；小时工资再除以 8。具体以当地规定与合同约定为准 |
| 拖欠与克扣 | 未按时足额支付劳动报酬，属可解除劳动合同并主张经济补偿的情形（见第五节） |
| 常见争议 | 公司若有「加班审批制」，需把**实际加班事实**固定下来：工作群消息时间戳、邮件发送时间、系统工单记录、考勤打卡与门禁记录、同事证言 |

**动作**：把「谁在什么时候要求你做什么」固定成可查证的记录。加班事实的关键不只是你在，而是**有人要求你产出**。

## 三、社保与公积金

- 社保为**法定强制**义务，双方约定「不缴社保」「自愿放弃社保」通常不能对抗法定义务。
- 用人单位**未依法缴纳社保**，属于劳动者可单方解除劳动合同并主张经济补偿的法定情形之一（《劳动合同法》第三十八条）。
- 公积金按《住房公积金管理条例》执行，属强制性缴存范围。

**动作**：定期查询社保与公积金缴纳记录（当地人社 / 公积金 App），断缴、少缴立即留痕并书面提出。

## 四、调岗与调薪

- 变更劳动合同约定内容，原则上应**协商一致**并采用书面形式；用人单位单方调整需有合同或依法制定的规章制度依据。
- 实践中对「调岗合理性」常见考量：是否基于真实经营需要、是否具有侮辱性或惩罚性、薪酬是否大幅下降、工作地点变化是否造成明显不便、是否与本人技能相匹配。
- **单方降薪**通常需协商一致；以「绩效不达标」降薪，需有事先明确的考核制度与真实考核结果支撑。

**动作**：收到调岗 / 调薪通知时，**先书面提出异议并保留送达证据**，不要口头答应也不要沉默签字。沉默容易被理解为默认接受。

## 五、解除与经济补偿

### 补偿口径速查

| 情形 | 口径 | 说明 |
|------|------|------|
| 协商一致解除（由单位提出） | **N** | 需有书面协议 |
| 劳动者因单位违法（未足额付酬、未缴社保、未提供劳动保护等）解除 | **N** | 《劳动合同法》第三十八条情形 |
| 单位依法解除（医疗期满不能工作 / 不胜任经培训调岗仍不胜任 / 客观情况重大变化） | **N + 1** | 未提前三十日书面通知时的**代通知金** |
| 经济性裁员 | **N** | 需符合法定程序 |
| 单位违法解除 | **2N** | 属赔偿金，非补偿金 |
| 劳动者主动辞职 | 一般**无补偿** | 除非因单位违法而解除 |

**N 的计算方式**：按工作年限，每满一年支付一个月工资；六个月以上不满一年按一年计；不满六个月支付半个月工资。

**月工资口径**：解除或终止前**十二个月的平均工资**（一般含奖金、补贴等货币性收入）。若高于用人单位所在地上年度职工月平均工资**三倍**，按三倍封顶计算，且年限最高不超过**十二年**。

### 离职时最容易吃亏的三个环节

1. **离职文件**：写「个人原因 / 自愿离职」基本等于放弃补偿；写「经双方协商一致解除」才对得上 N。
2. **空白与概括性条款**：「双方再无任何争议」「放弃一切主张」在签署前必须逐字看，涉及未结工资、报销、奖金、年假折算、股权或分红的，先谈清再签。
3. **离职证明与手续**：离职证明一般应在解除时出具；交接要留书面清单与签收记录，避免日后被指「未完成交接」。

## 六、竞业限制与保密

- 竞业限制**仅适用于**高级管理人员、高级技术人员和其他负有保密义务的人员，不能对全员无差别适用。
- 竞业限制期间用人单位需**按月支付经济补偿**；未按月支付，劳动者可依法主张相应权利（具体以合同约定与当地裁审口径为准，需专业评估）。
- 竞业限制期限**最长不超过二年**。
- 保密义务与竞业限制是两回事：保密义务通常在劳动关系存续期间及离职后依约定继续履行。

**动作**：签竞业条款前先看清「范围、地域、期限、补偿标准、违约金」五项，补偿标准缺失或明显过低时要提出来。离职时确认是否有单方解除竞业的通知。

## 七、工伤

- 认定核心是**工作时间、工作场所、因工作原因**（含上下班途中法定情形，具体以现行条例与司法解释为准）。
- 用人单位应在规定期限内（通常 30 日）申请工伤认定；单位未申请时，职工或其近亲属可在**一年内**直接提出申请。
- 争议高发点在**证据**：现场记录、就医记录、同行人证言、排班与考勤。

**动作**：受伤后第一时间就医并保留全部票据，同步书面告知单位并要求申报，全程留痕。

## 八、证据留痕清单

| 类别 | 具体材料 | 留存方式 |
|------|----------|----------|
| 关系证明 | 劳动合同、Offer、工牌、入职登记表、社保记录、工资流水 | 原件 + 扫描件，存私人设备与私人邮箱 |
| 薪酬证据 | 工资条、银行流水、个税记录、奖金与提成计算规则 | 按月归档，避免只留截图 |
| 工时证据 | 考勤打卡、加班审批、门禁记录、工作群消息、邮件发送时间 | 截图含时间戳与参与人，必要时录屏 |
| 管理与考核 | 员工手册、绩效制度、考核结果、评分依据、沟通记录 | **必须同时留制度和结果**，只有结果难以对抗 |
| 变动证据 | 调岗 / 调薪 / 处分通知、解除通知、送达记录 | 保留送达与签收过程 |
| 沟通证据 | 微信、钉钉、企业微信、邮件、会议录音（依当地规定合法取得） | **保留原始载体**，不删不改不剪辑 |

**三条纪律**

1. **原始优先**：先保原始文件与原始设备，再谈截图整理；修改过的材料会削弱证明力。
2. **私人渠道**：证据存**私人设备与私人邮箱**，不放在公司设备或公司云盘。
3. **只记事实**：记录写时间、人物、原话、结果，不写情绪评语——情绪评语会让材料看起来像投诉而不像记录。

## 九、官方求助渠道

| 渠道 | 用途 |
|------|------|
| **12333** | 人社服务热线，社保、劳动合同、工时与工资政策咨询 |
| **12351** | 工会职工服务热线，职工权益咨询与协调 |
| **12348** | 公共法律服务热线，法律咨询与法律援助指引 |
| **12338** | 妇女维权公益服务热线，涉性别歧视与骚扰 |
| **12345** | 政务服务便民热线，跨部门事项转办 |
| 当地**劳动人事争议仲裁委员会** | 劳动争议仲裁；**仲裁不收费** |
| 人民法院 | 不服仲裁结果或法定情形下直接起诉 |

**时效提醒**：劳动争议申请仲裁的时效期间一般为**一年**，自当事人知道或应当知道权利被侵害之日起计算。**劳动报酬争议在劳动关系存续期间不受该时效限制**，劳动关系终止的应在终止后一年内提出。时效容易被忽略，发现权益受损应尽早固定证据并咨询。

## 十、六个常见误区

1. 「我是主动辞职，所以什么都没有」→ 若存在单位未足额付酬、未缴社保等法定情形，主动解除也可主张经济补偿。
2. 「签了自愿放弃社保的承诺书，公司就没责任了」→ 法定义务不因约定而免除。
3. 「没有书面合同就没法维权」→ 工资流水、考勤、工作群记录可佐证事实劳动关系。
4. 「仲裁要花钱又慢，算了」→ 劳动仲裁不收费；拖到超过时效才是真损失。
5. 「离职证明公司可以不给」→ 出具离职证明是用人单位的法定义务，拖欠可依法主张。
6. 「口头谈好就行了」→ 所有涉及钱、岗位、职责、期限的约定，一律落到书面。
