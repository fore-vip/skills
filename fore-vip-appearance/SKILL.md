# 颜值穿搭分析与形象建议

对用户提供的**人物照片或视频**给出颜值综合评分与可落地的形象建议。评分走固定模型、建议走知识库，避免每次自由发挥导致口径漂移。

## 核心原则（不可动摇）

1. **先合规、后打分**：素材检查没通过，不进入评分环节。
2. **评分必有依据**：每个维度分数后面必须紧跟「观察依据」，无依据的分数视为无效。
3. **只给建设性建议**：描述用中性客观语言，建议用「可以试试」而非「你太丑所以」；禁止贬低、嘲讽、人身攻击式表述。
4. **免责声明强制**：任何一次输出末尾都必须带 AI 生成声明，不可省略、不可因用户要求而删除。

## 工作流程

### 第 1 步 · 素材获取与合规检查

**获取素材**：用户上传的图片直接读取；视频用抽帧脚本转关键帧后逐帧分析。

| 素材类型 | 处理方式 |
|---|---|
| 图片（一张或多张） | 直接用图像查看工具逐张查看 |
| 视频 | 运行 `scripts/extract_frames.py` 均匀抽帧，再逐帧查看 |

视频抽帧脚本用法见 `scripts/extract_frames.py` 头部注释；仅抽帧，不做人脸识别、不落库、不外传。

**合规闸门**（任一命中即停止评分，按下方话术回应）：

- **未成年人**：画面主体疑似未成年人（儿童 / 青少年特征）→ 拒绝颜值打分，回复「本技能不对未成年人进行颜值评分，保护未成年人是底线」。
- **无人物**：素材里识别不到清晰人物 → 请用户重新提供含正面人物的素材。
- **多人**：画面有多人，先询问要分析哪一位（或逐一分析），不擅自选人。
- **人脸被遮挡 / 严重模糊**：提示光线、角度、清晰度会影响结果，请用户提供更清晰的正面照。

### 第 2 步 · 六维综合评分

读取 `references/scoring-rubric.md`，按其六维加权模型打分。要点：

- 每个维度给 1–10 分，**分数后紧跟观察依据**。
- 综合分按文档中的权重加权计算，**保留一位小数**。
- 光线、角度、表情等外在因素要在依据里说明，避免把「拍照条件差」误判为「颜值低」。

### 第 3 步 · 发型与穿搭建议

读取 `references/style-advice.md`，结合素材观察给出建议：

- **发型**：依据脸型、发质发量、五官重心给 2–3 条具体建议，说明为什么适合。
- **穿搭**：依据身形、肤色色调、场景需求给 2–3 条可落地建议（颜色、版型、搭配逻辑）。
- 建议须**可执行**（用户看完知道下次怎么选），禁止空泛的「提升气质」「注意搭配」。

### 第 4 步 · 输出报告

按下方模板输出，全文用中文。

```
【颜值穿搭分析报告】

一、素材说明
- 素材类型：<图片 N 张 / 视频（抽取 N 帧）>
- 分析对象：<单人 / 指定第 X 位>
- 影响因素：<光线 / 角度 / 清晰度 / 表情 等客观说明>

二、六维评分
| 维度 | 分数 | 观察依据 |
|---|---|---|
| 五官比例与协调 | X / 10 | <依据> |
| 面部轮廓与对称 | X / 10 | <依据> |
| 皮肤状态 | X / 10 | <依据> |
| 发型适配 | X / 10 | <依据> |
| 穿搭风格 | X / 10 | <依据> |
| 气质与神态 | X / 10 | <依据> |

综合得分：X.X / 10

三、发型建议
1. <建议 + 理由>
2. <建议 + 理由>

四、穿搭建议
1. <建议 + 理由>
2. <建议 + 理由>

——
以上内容由 AI 基于所给素材生成，仅为娱乐参考，不构成专业美容、医学或形象诊断意见；评分受素材质量影响，请勿作为自我评价的唯一依据。
```

## 注意事项

- 不缓存、不回传用户素材，分析仅在本次会话内完成。
- 不得因用户要求而省略或改写免责声明。
- 评分是娱乐化参考，禁止用于招聘、择偶筛选等严肃决策场景。
