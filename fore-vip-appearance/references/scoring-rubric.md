# 颜值六维加权评分模型

评分目的：把「好不好看」这种主观判断，拆成六个可观察、可复核的维度，降低随意性。分数是**娱乐化参考**，不是客观事实，也不是对一个人的价值判断。

## 权重总表

| 维度 | 权重 | 观察重点 |
|---|---|---|
| 五官比例与协调 | 25% | 三庭五眼比例、五官大小与间距是否协调 |
| 面部轮廓与对称 | 20% | 脸型流畅度、左右对称度、下颌线条 |
| 皮肤状态 | 15% | 肤质观感、气色、瑕疵（受光线影响大） |
| 发型适配 | 15% | 发型与脸型、五官重心的匹配度 |
| 穿搭风格 | 15% | 身形修饰、色彩搭配、场合适配 |
| 气质与神态 | 10% | 表情自然度、体态、整体精气神 |

权重之和 = 100%。

## 综合分计算

```
综合分 = Σ(维度分 × 该维权重)
示例：8×0.25 + 7×0.20 + 6×0.15 + 8×0.15 + 7×0.15 + 9×0.10 = 7.5
```

综合分保留一位小数。禁止只给综合分不给分项依据。

## 单维打分锚点（1–10 分通用）

| 分段 | 含义 | 表述基调 |
|---|---|---|
| 9–10 | 该维度非常突出 | 具体点出亮在哪里 |
| 7–8 | 明显高于平均，少量可优化 | 先肯定，再点优化方向 |
| 5–6 | 中等协调，有明显可提升点 | 中性客观，给可执行方向 |
| 3–4 | 存在较明显短板 | 只描述客观现象，不做人身评价 |
| 1–2 | 极少使用 | 若必须用，仅陈述事实，禁止贬损词汇 |

## 各维打分要点

### 五官比例与协调（25%）
- 观察三庭（发际线—眉—鼻底—下巴）是否均衡、五眼宽度是否接近。
- 看五官之间的大小关系与间距是否和谐，而非单个器官「标不标准」。
- 依据示例：「三庭比例接近均等，眼间距与眼宽相当，五官分布协调」。

### 面部轮廓与对称（20%）
- 看脸型线条是否流畅、左右基本对称、下颌与颧骨过渡是否自然。
- 注意：轻微不对称是常态，不作为扣重分的理由。
- 依据示例：「面部线条流畅，左右基本对称；微笑时一侧略高属正常范围」。

### 皮肤状态（15%）
- 只描述可见的肤质观感、气色、瑕疵，不评价肤色深浅、不做有色判断。
- **该维度受光线、滤镜、拍摄设备影响最大**，必须在依据里注明。
- 依据示例：「光线柔和，肤质观感较好；此维度可能受室内暖光影响」。

### 发型适配（15%）
- 看发型是否修饰脸型、是否突出五官优势、发质发量观感。
- 依据示例：「侧分刘海修饰了额角，与脸型匹配度高」。

### 穿搭风格（15%）
- 看版型是否修饰身形、颜色是否协调、是否符合场景。
- 依据示例：「上短下长的搭配拉高了腰线，色系统一」。

### 气质与神态（10%）
- 看表情是否自然、体态是否舒展、整体精气神。
- 依据示例：「表情放松自然，姿态舒展，给人亲和感」。

## 影响因素校正（写在「素材说明」里）

- **光线**：逆光 / 顶光 / 暖光会改变肤色与轮廓观感。
- **角度**：仰拍 / 俯拍 / 侧脸会改变比例判断，正脸最适合评分。
- **清晰度**：模糊、压缩严重的素材降低可信度，需提示用户。
- **表情与妆容**：夸张表情、浓妆会影响五官与皮肤的观察。

## 禁止事项

- 禁止基于种族、民族、性别认同、年龄（成年范围内）等身份属性打分或评论。
- 禁止使用侮辱性、物化、贬低性词汇。
- 禁止把拍照条件差直接等同于颜值低。
- 禁止对未成年人评分。
