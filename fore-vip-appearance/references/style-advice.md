# 发型与穿搭建议知识库

给出建议前，先从素材里判断脸型、身形、肤色色调与场景。判断不确定时，用「看起来偏……，如果是这样」的表述，并给 1 条通用兜底建议。

## 一、脸型 → 发型

| 脸型 | 判断特征 | 推荐发型 | 避开 |
|---|---|---|---|
| 圆脸 | 面宽≈面长，下颌圆润 | 顶部蓬松、侧分长刘海、露出下颌线的短发 | 齐刘海贴头皮、蓬松两侧 |
| 方脸 | 下颌角明显，面部线条硬朗 | 柔和层次、八字刘海、微卷中长发 | 齐耳短直发、厚重齐刘海 |
| 长脸 | 面长明显大于面宽 | 有刘海、两侧蓬松的卷发、波波头 | 高马尾、贴头皮长直发 |
| 心形脸 | 额宽、下巴尖 | 中分 / 八字刘海、下巴附近有体积的发型 | 顶部过高过蓬 |
| 鹅蛋脸 | 比例均衡、线条柔和 | 多数发型适配，可按气质与场景选 | 无硬禁忌 |
| 菱形脸 | 颧骨突出、额与下巴窄 | 刘海修饰颧骨、中长卷发 | 暴露颧骨的贴头皮造型 |

补充：发量少选层次感与蓬松度设计；发质细软避免过长过贴；发质粗硬避免过于琐碎的层次。

## 二、身形 → 穿搭

| 身形 | 判断特征 | 推荐 | 避开 |
|---|---|---|---|
| 梨形 | 臀腿宽于上身 | 上浅下深、A 字裙 / 直筒裤、强调肩颈 | 紧身下装、低腰裤 |
| 苹果形 | 腰腹集中 | 高腰线、V 领、直筒 / 阔腿版型 | 腰部收紧、横条纹上衣 |
| 沙漏形 | 腰细、胸臀均衡 | 收腰款式、合身针织、腰带点缀 | 过于宽松的直筒 |
| H 形 | 腰线不明显 | 制造腰线、层次叠穿、有体积感的下装 | 上下同宽的直筒 |
| 倒三角 | 肩宽于臀 | 深色上衣、V 领、下装增加体积 | 泡泡袖、垫肩 |
| 匀称 | 比例均衡 | 按场景与喜好选，注重质感与合身 | 无硬禁忌 |

通用逻辑：**上宽下窄、上短下长、深色的收缩感、高腰线**——用这几个杠杆解释「为什么适合」，而不是甩结论。

## 三、肤色色调 → 配色

只做**色调适配**建议（冷 / 暖 / 中性），不评价肤色深浅、不使用美白或肤色等级类表述。

- 判断不确定时，给「冷暖都相对安全的中间色」兜底（如藏蓝、墨绿、米白、酒红）。
- 冷色调：可多试蓝、紫、翡翠绿、冷灰、银色配饰。
- 暖色调：可多试米色、焦糖、橄榄绿、砖红、金色配饰。
- 中性色调：冷暖皆可，优先看与发色、眼睛颜色的呼应。

## 四、场景 → 风格

| 场景 | 造型方向 |
|---|---|
| 日常通勤 | 合身基础款 + 一点设计感，重舒适与整洁 |
| 职场正式 | 版型挺括、色系克制、细节干净 |
| 约会 / 聚会 | 突出优势部位，适当增加色彩或配饰亮点 |
| 上镜 / 拍照 | 避免强反光与细密条纹，选纯色与有轮廓感的款式 |

## 建议表达规范

- 每条建议 = **具体做法 + 一句理由**，用户看完知道下次怎么选。
- 一次给 2–3 条，按优先级排序，不堆砌清单。
- 用「可以试试」「更适合」「建议优先」等建设性措辞。
- 禁止「你脸太圆」「皮肤太差」「这样穿显胖」等贬低式表述；改用「可以通过……修饰脸型」「选择……会更显精神」。
- 不推荐具体品牌、不引导消费、不声称医疗或医美效果。
